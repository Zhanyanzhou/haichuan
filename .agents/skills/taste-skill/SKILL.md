# 设计品味 — 前端视觉 Skill

> 仅适用于客户前台页面的视觉/布局/响应式/交互/性能/无障碍任务。
> 管理后台仅允许参考信息层级、状态完整性、色彩对比度、响应式、无障碍和性能。
> 本 Skill 不具有产品决策权和自动执行权限。

---

## 一、使用前判断

开始任务前，先判断本轮核心问题是否属于：
视觉设计、页面布局、响应式、交互状态、动画体验、前端性能、无障碍、上线前界面检查。

属于以上范围时，才允许引用本 Skill。

如果任务主要属于后端、API、数据库、权限、环境恢复、路由故障、数据迁移、纯业务逻辑，则本轮不使用本 Skill。

---

## 二、设计分析方法

### 2.1 读取场景信号

1. **页面类型** — 落地页（SaaS / 消费品 / 品牌 / 活动）、作品展示、品牌首页、产品列表/详情、编辑型/博客
2. **氛围关键词** — "极简"、"安静"、"高端消费"、"编辑感"、"奢华"、"中式"
3. **受众** — 高端消费者、设计师、品牌合作方
4. **已有品牌资产** — Logo、品牌色 `#B8944E`、字体（Cormorant Garamond / Noto Serif SC）

### 2.2 对照 UI_GUIDE 检查清单

每次视觉分析按以下顺序进行：

1. **信息层级** — 标题→副标题→正文→辅助信息，层级是否清晰
2. **字体** — 品牌标题用 Cormorant Garamond，中文标题用 Noto Serif SC，正文用系统默认
3. **留白** — 模块间距是否均衡、呼吸感是否足够
4. **色彩** — 品牌金色 `#B8944E` 使用是否克制（主色不超过页面 5% 面积）
5. **图片比例** — 桌面端图片比例保持一致
6. **按钮** — 主按钮用品牌金色，次按钮用边框样式，hover/active 状态完整
7. **布局** — 遵循 12 列栅格或居中最大宽度 1280px
8. **响应式** — 桌面 1440+ / 平板 768 / 手机 390 断点

### 2.3 浏览器视觉验收

修改完成后，在浏览器中对照 UI_GUIDE 检查：

- 品牌色是否正确显示
- 字体是否正确加载
- 间距是否一致
- 响应式是否正常

---

## 三、禁止行为

- 对整个项目做全局视觉大改（只修改当前任务范围内的页面）
- 覆盖 UI_GUIDE 中定义的品牌规范
- 使用默认模板化设计（如标准蓝色链接、灰色边框卡片）
- 在没有产品确认的情况下更改品牌色、字体或 Logo

---

## 四、规则优先级

发生冲突时按以下顺序：

1. 本轮明确的产品目标
2. UI_GUIDE 中的品牌设计规范
3. 当前业务逻辑与技术架构
4. 本 Skill 中的通用建议
