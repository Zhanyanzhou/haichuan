# 流程 · 视觉诊断与设计决策链（Diagnosis & Decision Flow）

> 这是「设计师的眼睛」的可执行版本。核心：**先诊断 → 再定位 → 后动手 → 最后检验**。
> 来源标注：决策链基于「双钻模型（Double Diamond，英国设计委员会，2005）」演绎；
> 下方「视觉诊断清单」为本项目针对珠宝/奢侈品场景的推导，**非权威原文**，可迭代。

---

## 一、强制动作：动手前必须先看图

- 任何视觉任务，**第一步必须获取真实图像**：截图当前页面 / 打开目标图片 / 查看 AI 生成图。
- 没有真实图像时，必须明说「无图，以下诊断为假设」，**不得凭空评价一张不存在的图**。
- 这是设计师思维的第一步，也是本流程的硬性前提。

---

## 二、视觉诊断清单（7 项，逐项判断「合格 / 不合格 / 需改进」）

| 诊断项 | 合格标准 | 常见问题 | 解法 |
| --- | --- | --- | --- |
| 光 | 柔光、方向明确、无过曝/死黑 | 硬光、过曝、死黑 | 换图 / 重生成（加 `soft studio lighting`） |
| 材质 | 金属有光感、珠宝有火彩、翡翠通透 | 塑料感、发闷、假光 | 重生成（加材质术语） |
| 构图 | 主体在焦点、无杂物 | 主体偏、杂物多 | 重新裁切 |
| 空间 | 留白 > 40%、有呼吸感 | 塞满、拥挤 | 删元素、加留白 |
| 色彩 | 白/浅灰底 + 黑 + 一个点缀色 | 脏、饱和度高、撞色 | 压饱和、统一色调 |
| 字体 | 衬线标题 + 无衬线正文、字重 300~500 | 粗黑体、字距乱 | 换字体、调字距字重 |
| 层级 | 第一眼焦点清晰、主次分明 | 主次不分、字一样大 | 重新分主次 |

---

## 三、定位：难看在哪一层（先定位，再动手）

> 定位错了，改 10 遍还是难看。不同层的解法完全不同。

| 难看层 | 表现 | 解法 |
| --- | --- | --- |
| 图本身 | 光 / 材质 / 背景 / 构图问题 | 换图 / 重生成（改提示词） |
| 图文关系 | 文字压焦点、位置打架 | 重排文字位置、留白 |
| 信息层级 | 主次不分、没有焦点 | 重新分主次 |
| 字体 | 字体错、粗黑体、字距乱 | 换字体、调字距字重 |
| 色彩 | 脏、饱和度高、撞色 | 压饱和、统一色调 |

---

## 四、设计决策链（双钻模型演绎）

```
① 发现 Discover：看图 / 接任务，收集全部视觉信息
② 定义 Define：定位问题层，明确「这一张图只传达一件事」
③ 发展 Develop：先文案 → 再骨架 → 再排版 → 再配图
④ 交付 Deliver：退后一步检验
```

---

## 五、交付前检验三问（必答）

1. **眯眼看**：第一眼落在哪？应落在主体 / 珠宝，不是文字。
2. **换尺寸**：缩到手机大小还成立吗？文字看得清吗？
3. **删减**：删掉任何一个元素，画面会更好吗？能删就删。
