# 知识库 · AI 图像生成提示词库（Prompt Library）

> 解决"AI 生成图片难看"的直接工具。生成珠宝/奢侈品图片时，提示词必须含四组术语 + 负向词。

---

## 一、四组必备术语

### 1.1 摄影术语
- `soft studio lighting` 柔和影棚光
- `shallow depth of field` 浅景深
- `macro photography` 微距
- `editorial photography` 编辑级摄影

### 1.2 镜头术语
- `85mm lens` 人像/产品镜头
- `f/1.8 aperture` 大光圈
- `low ISO` 低噪点

### 1.3 材质术语（按珠宝品类）
| 品类 | 术语 |
| --- | --- |
| 黄金 | `polished 18k gold` / `brushed gold` |
| 铂金 | `platinum sheen` |
| 钻石 | `sparkling diamond facets`（火彩） |
| 珍珠 | `pearlescent luster` |
| 翡翠 | `jade translucency`（通透） |
| 宝石 | `vivid gemstone color` |

### 1.4 构图术语
- `centered composition` 居中构图
- `negative space` 负空间
- `single subject` 单一主体
- `high-end luxury brand style` 高端奢侈品牌风格

## 二、负向词（必加）

```
no text, no watermark, no logo, no clutter,
no busy background, no oversaturated colors, no harsh shadows
```

## 三、可直接套用的中文提示词模板

### 3.1 产品图（白底）
> 一枚翡翠吊坠，居中构图，柔和影棚光，浅景深，微距，抛光金链，翡翠通透质感，纯白背景，大量负空间，编辑级摄影，高端奢侈品牌风格；无文字，无水印，无杂乱背景，无过饱和，无硬阴影。

### 3.2 氛围图（真人佩戴）
> 优雅女性佩戴钻石项链，85mm 镜头，f/1.8 大光圈，浅景深，柔和窗光，肤色自然，高级感，编辑级时尚摄影；无文字，无水印，无夸张滤镜。

### 3.3 品牌 Hero 背景
> 珠宝静物与丝绸面料，柔和侧光，大面积负空间，低饱和中性色调，微距细节，高端奢侈品牌风格；无文字，无水印，无杂乱。
