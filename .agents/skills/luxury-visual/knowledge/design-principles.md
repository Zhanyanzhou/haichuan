# 知识库 · 设计原则（有出处的权威方法论）

> 本文件收录**有公认出处**的设计原则，作为「设计师思维」的权威基础，替代凭空编造的描述。
> 每条标注出处；「珠宝场景演绎」见 `process/diagnosis.md`，属本项目推导，非权威原文。

---

## 一、Dieter Rams「好设计十原则」（1970s，德国工业设计大师，Braun 首席设计师）

核心一句：**Less, but better（少，但更好）**。

- 适用：奢侈品极简的根本依据——删到不能再删，剩下的才是有价值的。
- 十原则中与奢侈品最相关的三条：
  1. 好的设计是尽可能少的设计（as little design as possible）
  2. 好的设计是诚实的（honest）——不靠装饰冒充高级
  3. 好的设计是永恒的（long-lasting）——不过时

## 二、双钻模型（Double Diamond，英国设计委员会 Design Council，2005）

**Discover → Define → Develop → Deliver**（发现 → 定义 → 发展 → 交付）。

- 前半段「发散」：收集信息、探索可能（对应「看、诊断」）。
- 后半段「收敛」：定位问题、交付方案（对应「定位、动手」）。
- 适用：本体系 `process/diagnosis.md` 的决策链骨架。

## 三、Paul Rand（现代平面设计大师，IBM / ABC 品牌标识作者）

- **「设计就是关系（Design is relationships）」**——元素之间要对话，不能各自为政。
- **「Don't try to be original, just try to be good」**——先做对，再求新。
- 适用：克制、不做多余装饰的理论依据。

## 四、Robert Bringhurst《The Elements of Typographic Style》（排版圣经）

- 核心：字体排印是「让文字可读且优美」的艺术，层级、字距、行距都有据可依。
- 适用：本体系 `rules/typography-color.md` 的排印依据。

## 五、Josef Müller-Brockmann（瑞士平面设计大师，《网格系统》作者）

- 核心：一切元素落在网格上，**秩序产生高级感**。
- 适用：本体系 `rules/layout-imagery.md` 的网格与对齐依据。

## 六、侘寂（Wabi-sabi）与留白（日本美学）

- 核心：不完美、克制、留白——奢侈品极简的东方美学源头。
- 适用：留白 > 40% 与「单一句主文案」的美学依据。
