## 二、归纳出的规律

1. 底色统一纯白或极浅灰，无暖白、无彩色底。
2. 字体双轨：标题衬线 + 正文无衬线。
3. 中文标题字距 0 或微负；英文全大写才加字距。
4. 标题字重 300~500，无粗黑体。
5. 图片两大类分离：产品图（纯底柔光）+ 氛围图（景深故事）。
6. 色彩克制：白 + 黑 + 一个点缀色（<5%）。
