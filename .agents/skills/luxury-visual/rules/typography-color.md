# 规则 · 字体排印与色彩（Typography & Color）

> 本文件是奢侈品视觉体系的排印与色彩硬性规则。所有数值均有实测出处，标注来源。

---

## 一、字体排印

### 1.1 双轨制（不可混用）
| 用途 | 字体 |
| --- | --- |
| 英文标题 / 品牌名 | Cormorant / Janson Text / ChronicleDisplay（衬线） |
| 中文标题 | Noto Serif SC 思源宋体（衬线） |
| 正文（中英） | Helvetica / Maison Neue / OptimaNova（无衬线） |

> 实测：Buccellati 用 Cormorant，Harry Winston 用 Noto Serif SC。

### 1.2 字距（Tracked，按语言区分）
| 场景 | 字距 |
| --- | --- |
| 中文标题 | `0` 或微负 `-0.2px`，**不加宽** |
| 英文全大写标题 | `+1.5px`（加宽） |
| 正文 | `normal` |

> 实测：Harry Winston 中文标题 `-0.2px`；Buccellati 英文大写标题 `1.6px`。

### 1.3 字重
- 标题：`300 ~ 500`（偏细），**禁止粗黑体**。
- 实测：Bvlgari 300、Harry Winston 400、Buccellati 500。

### 1.4 字号层级（模数比例）
- 主标题 : 副标题 : 正文 ≈ `3 : 1.6 : 1`
- 中文标题常用 24px / 34px（实测 HW、Bvlgari）。

### 1.5 行长与行距（中文排印基本功）
- 行长：海报每行 ≤ 28 字，正文每行 ≤ 45 字。
- 行距（leading）：`1.6 ~ 2.0`。
- 中西文混排：中英文之间留 `1/4 空格`（或用字间距补偿）。

## 二、色彩

### 2.1 底色（三选一，均为极浅中性色）
| 色值 | 场景 |
| --- | --- |
| `#FFFFFF` 纯白 | 默认 |
| `#F5F5F5` 浅灰 | 需要分区时（Graff） |
| `#F3F2F3` 极浅灰 | 需要微妙层次时（Bvlgari） |

> ⚠️ 项目现有 UI_GUIDE 用暖白 `#FBF9F6`，属「待确认」决策点，未拍板前不擅改。

### 2.2 正文字色
- `#222222` ~ `#383838` 近黑深灰，**不用死黑 `#000` 做正文**。

### 2.3 点缀色
- 最多 **1 个**品牌色，面积 < **5%**。
- 示例：Cartier 红 `#C10016`；海川品牌金 `#B8944E`。

### 2.4 对比度
- 正文与底色对比度 ≥ `7:1`（WCAG AAA）。

### 2.5 禁用
- ❌ 高饱和渐变、彩虹色、默认蓝链接、大面积彩色底。
