# 模板 · 详情页头图（Detail Header）

> 产品详情页顶部引导图。

---

## 用途
产品详情页顶部、进入页引导。

## 尺寸与比例
- 宽幅 `16:9` 或 `3:1`。

## 版式
- 产品主体 + 氛围背景，主体突出。
- 引导进入产品，不塞信息。

## 构图
- 产品主体占焦点，背景氛围做衬托（浅景深）。

## 文字
- 产品名 / 系列名 + 极简一行。
- ❌ 价格、参数、促销信息**不放头图**，放正文区。

## 图片要求
- 产品图 + 氛围背景合成或实拍，光感统一。

## 验收点
- [ ] 产品主体突出，背景衬托
- [ ] 无价格/参数/促销信息
- [ ] 文字极简
