# 模板 · 多比例骨架框架（Ratio Framework）

> 这是素材库的**框架层**——8 个比例，每个一张「骨架卡片」。
> 用法：先定比例 → 套骨架 → 填产品与文案。
> **骨架钉死结构，细节保留可变项**，避免"套模板"变流水线廉价感。

---

## 使用前提（模板起点）

> 下列比例和百分比是单张视觉物料的近似构图提示，不是网页、功能页面或所有品牌素材的硬性规则。最终以内容任务、真实素材、目标媒介和 `docs/UI_GUIDE.md` 验收。

1. **产品图先统一**：套骨架前，产品图必须是白底/浅灰底、同系列同比例、影棚柔光。
2. **文字层级默认**：主标题 → 必要说明 → 1 个主要 CTA；复杂信息按任务扩展。
3. **项目规范优先**：留白、点缀色、字重与例外以 `docs/UI_GUIDE.md` 为准，不把模板数值升级成全局硬规则。

## 骨架卡片速查（8 个比例）

| # | 比例 | 场景 | 一句话骨架 |
| --- | --- | --- | --- |
| 1 | `1:1` | 产品主图 / 社媒卡 | 居中单一主体 |
| 2 | `4:5` | 小红书 / 朋友圈竖图 | 上图下文 |
| 3 | `3:4` | 电商主图 / 竖版海报 | 上 2/3 图 + 下 1/3 字 |
| 4 | `2:3` | 模特 editorial / 时尚大片 | 纵向主体 + 大留白 |
| 5 | `4:3` | banner / 详情页图 | 左右分栏（图一侧字一侧） |
| 6 | `16:9` | Hero / 专题封面 | 三分法，主体偏一侧 |
| 7 | `9:16` | 移动端 Hero / 开屏 | 上 2/3 图 + 下 1/3 字 |
| 8 | `21:9` | 专题大横幅 | 横向大留白，主体一端 |

## 骨架卡片（详细）

### 1. `1:1` 方形（1080×1080）
- **场景**：产品主图、社媒卡、头像
- **网格**：单一中心
- **产品区**：居中，占 **60%~70%**（可变）
- **文字区**：无，或底部极小 logo（≤3%）
- **留白**：四周均衡，合计 ≥30%
- **实测参考**：Graff 产品图 1080×1080

### 2. `4:5` 竖版（1080×1350，小红书主图）
- **场景**：小红书、朋友圈竖图
- **网格**：上下 **3:2**（图:字）
- **产品区**：上部 50%~70%（可变）
- **文字区**：下方，主标题 + 一句话卖点 + 品牌名
- **留白**：≥30%
- **可变项**：图/字比例可调（3:2 或 2:1）

### 3. `3:4` 竖版（750×1000）
- **场景**：电商主图、竖版海报
- **网格**：上下 **2/3 + 1/3**（图:字）
- **产品区**：上部 2/3 或居中，占 60%~70%
- **文字区**：下部 1/3，主标题 + 副标题 + 1 个 CTA
- **留白**：≥40%
- **可变项**：文字左对齐 / 居中对齐二选一
- **实测参考**：Harry Winston 750×900（≈5:6，同族）

### 4. `2:3` 修长竖版（1200×1800）
- **场景**：模特佩戴 editorial、时尚大片
- **网格**：纵向主体 + 大留白
- **产品区**：主体占 70%，偏上部
- **文字区**：底部 1/4，或顶部一句意境文案 + 极小 logo
- **留白**：≥40%
- **可变项**：文字位置（底部 / 顶部）二选一

### 5. `4:3` 横版（1200×900）
- **场景**：banner、详情页图
- **网格**：左右分栏 **1/3 + 2/3**
- **产品区**：左侧或右侧 1/3
- **文字区**：另一侧 2/3，主标题 + 副标题
- **留白**：≥30%
- **可变项**：图在左 / 图在右互换
- **实测参考**：Bvlgari 横幅 336×252

### 6. `16:9` 宽屏（1920×1080）
- **场景**：品牌 Hero、专题封面、视频封面
- **网格**：三分法，主体偏一侧（1/3）
- **产品区**：左 1/3 或右 1/3
- **文字区**：另一侧，主标题 + 副标题 + 1 个 CTA
- **留白**：≥40%
- **可变项**：左右互换

### 7. `9:16` 竖版全屏（1080×1920）
- **场景**：移动端 Hero、开屏、短视频封面
- **网格**：上下 **2/3 + 1/3**（图:字）
- **产品区**：上部 2/3
- **文字区**：下部 1/3，主标题 + 副标题 + CTA
- **留白**：≥30%
- **可变项**：产品占比 60%~70%
- **实测参考**：Cartier 超长竖图（同族，更修长）

### 8. `21:9` 超宽（2560×1080）
- **场景**：专题大横幅、全宽 banner
- **网格**：横向大留白，主体一端（1/4）
- **产品区**：左端 1/4
- **文字区**：右端 3/4（或反向），系列名 + 一行描述
- **留白**：≥50%
- **可变项**：左右互换

---

## 使用流程（三句话）

1. **选比例**：按媒介和主体形状，从 8 张卡片里选一张。
2. **套骨架**：产品放进「产品区」，文案放进「文字区」，遵守占比范围。
3. **自检**：留白、字重、点缀色、主焦点、真实性与可读性，对照 `docs/UI_GUIDE.md` 和模板验收点逐项检查。
