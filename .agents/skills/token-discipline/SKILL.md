# Token 成本诊断（Token Discipline）

> 依据：2026-08-19 全链路审计（转录取证 + 代理缓存实测），结论存档于 DECISIONS A.11 与用户记忆 token-cost-audit-20260819。计费走智谱按量，省钱靠纪律不靠砍配置。
>
> **定位（勿改回）**：本技能是咨询/诊断型，只靠用户显式话题触发——技能加载匹配发生在用户消息层，模型自身行为（批量读文件、连续快照等）不会触发加载。行为纪律的常驻精简版在 CLAUDE.md「Token 成本纪律」节；不要把行为类触发词塞回 description。

## 一、事实基线（实测，勿凭感觉推翻）

1. **代理 prompt caching 正常工作**：`cache_control` ephemeral 实测命中（2405 token 前缀二发 `cache_read=2368`）。固定注入（系统提示、技能清单、MCP 清单）走缓存价，不是大头。
2. **消耗大头 = 回合数 × 上下文体积**：单会话转录曾达 9.8MB；`[1M]` 上下文使 auto-compact 阈值极高，会话滚到几十万 token 后每回合新增内容 + 思考输出全价计费。
3. **缓存过期重写**：TTL 约 5 分钟。构建/测试/长命令超过 TTL 后，整段前缀按全价重写——重前端验证型会话高发。
4. **思考输出按输出价计费**：EFFORT_LEVEL=max 时显著放大，现已调 high。
5. **大工具结果是上下文增长主源**：浏览器全页 snapshot（5-20K token/次）、整读大文件、超长命令输出。
6. **水位口径（2026-08-19 定稿）**：状态栏与 Stop hook 以 200K token 为预算显示水位——60%（120K）⚠收尾、80%（160K）‼红线——不按 1M 窗口算百分比（窗口口径把 160K 显示成 16%，严重低估告急）。200K 同时是 autoCompactWindow 与每回合成本敏感线。

## 二、硬规则（How to apply）

- **会话纪律**：一个任务闭环即 `/clear`；同一会话出现第 3 个不相关任务 = 立即拆新会话；上下文超 100K 且当前任务接近完成 → 先收尾再清。
- **大读取隔离**：批量读文件、全仓搜索、连续快照交给子代理（Explore / general-purpose），主对话只收摘要；子代理的庞大上下文不进主会话。
- **精准读取**：Read 带 `offset`/`limit` 只取需要的行段；已知目标文件时不用 Grep 撒网；不重复读已读文件。
- **浏览器取证**：优先 `evaluate_script` 精准取值/断言；全页 snapshot 仅在需要 DOM 结构时用；截图按需，不循环截图。
- **长命令（预计 >5 分钟）**：`run_in_background` 或拆出会话执行；等待期间不要发无关请求白烧缓存。
- **模型档位**：日常问答/机械改动用 haiku 档（=glm-5.2），设计/复杂调试才升 sonnet/opus（=glm-5.3，更贵）。
- **输出压缩**：用户明确要省 token 时，caveman 技能可压输出约 65%（全中文场景用 wenyan 变体）。

## 三、诊断流程（用户来问成本时按序排查）

1. 看会话形态：本会话/近期会话是否长会话、回合数多、上下文大；必要时经用户同意查 `~/.claude/projects/g------2/` 下转录体积佐证（用户目录，查询前知会）。
2. 看工具模式：是否连续浏览器快照/截图、整读大文件、"以防万一"式撒网搜索。
3. 看时间线：是否穿插 >5 分钟命令导致缓存反复过期。
4. 对症给建议：

| 症状 | 建议 |
| --- | --- |
| 会话内 >20 工具回合且无收尾迹象 | 分阶段交付 + /clear |
| 单个工具结果 >20K token | 同类操作改子代理或缩小范围 |
| 连续 3 次以上快照/截图 | 改 evaluate_script，向用户说明成本 |
| 等待长命令期间插入无关请求 | 停；结果回来后任务闭环即收尾 |
| "以防万一"式读文件/列目录 | 停，按需取用 |

## 四、与既有技能分工

- caveman：输出文字压缩（省输出 token）
- ponytail：代码最少化（省代码与后续维护）
- 本技能：消耗结构认知 + 会话级纪律（省输入/缓存/回合总量）
- 三者互补，可叠加使用。

## 五、边界

- 本技能不改任何计费/代理/MCP 配置；配置类治理见 DECISIONS A.11。
- 自动护栏（`autoCompactWindow` 200K 自动压缩、hook 计数提醒、状态栏）在 `.claude/settings.json` 与 `.claude/hooks/`，与本技能解耦；上下文被自动压缩属正常行为，勿当故障排查。
- 节省不能以牺牲 PROJECT_RULES 第 13 节"修改后必须验证"为代价；验证命令该跑就跑。
- cache_read 计费折扣以智谱账单为准，未确认前不要向用户承诺具体节省比例。
