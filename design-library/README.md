# 设计素材库（Design Library）

> 奢侈品 / 高级珠宝品牌网站设计的知识素材库，供设计师与 AI 查阅参考。
> 本库是**通用参考资料集**，收集编辑式版面设计、奢侈品设计原则、量化数据、品牌案例与设计师学习路径；不绑定任何具体项目。
> 本库提供理论与证据，不提供项目约束：用于具体项目时，该项目自身的设计规范优先于本库数值。
> 数据均标注来源与采集日期，外部网站会变化，复用前需重新核验；品牌专有字体、素材与文案不得复制。

---

## 定位与边界

### 本库是什么

- 通用设计理论与外部证据库，按「原则 → 数值 → 证据 → 能力 → 体系」五层组织（`01`/`02` → `03` → `04` → `05` → `06`）；`06` 为海川珠宝语境的模板体系应用层，其余为通用层。
- 供设计任务开始前查阅，把「凭感觉调」换成「有依据地判断」。
- 本项目 luxury-visual 技能已将本库引用为理论与证据层（其 `knowledge/` 内只保留指针与项目侧结论，见 `docs/DECISIONS.md` A.10）。

### 本库不是什么

- **不是项目规范**：颜色、字体、间距等硬规则以具体项目的规范文件为准；本库数值与项目规范冲突时，一律以项目规范为准。
- **不是流程手册**：诊断、验收、看图审查等流程由使用方（人或项目技能）定义，本库只提供依据。
- **不是素材仓库**：不含图片、字体文件或提示词；品牌专有素材不得复制。

## 使用建议

- **找方法**：先读 `01` 和 `02`，理解「编辑式版面」和「奢侈品克制」的原则。
- **查数值**：做具体构图时读 `03`，把原则落到像素级基线。
- **看对标**：读 `04`，对比国际与国内珠宝品牌的两种路线。
- **补能力**：读 `05`，缺哪项补哪项，不靠「凭感觉调」。
- **做模板**：读 `06`，从角色、三设备构图、槽位语义到可编辑权限把模板设计完整走通。

## AI 使用指引

设计任务开始时按任务读取对应文件（参照「使用建议」路由），不要全量加载；遵循以下规则：

1. `03` 的数值用于诊断与论证，是参考基线不是机械像素标准；与所在项目的设计规范冲突时，以项目规范为准。
2. `04` 的品牌数据为 2026-08-15 快照，可用于论证方向，不得复刻版式、商标、文案或受保护素材；引用时保留来源与快照日期。
3. 把原则（`01`/`02`）落地为具体方案前，先确认所在项目的品牌方向与适用边界。
4. 本库解决「知道」；「看到」依赖实现后的截图审查闭环，不靠读库完成。

## 核心方法论（一句话）

> **排版驱动+ 摄影驱动+ 极简+ 艺术指导**

来自设计平台分类体系（SiteInspire 分类 + Awwwards 奢侈类目），与顶级珠宝品牌官网实测规律互相印证。
