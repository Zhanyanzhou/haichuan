# 05 · 设计师学习清单（Learning Path）

> 做奢侈品 / 高级珠宝品牌设计需要具备的能力基线，缺哪项补哪项，不靠「凭感觉调」。

---

## 一、八项核心能力

1. **字体排印（Typography）**：层级、字号模数、字重、字距、行长、行距、中西混排。
2. **网格与构图（Grid & Composition）**：12 列栅格、对齐关系、对称/不对称平衡、单一焦点。
3. **留白与节奏（Space & Pacing）**：把留白当构图元素，控制区块节奏与停顿。
4. **视觉层级（Visual Hierarchy）**：标题/副题/正文/辅助的主次关系。
5. **摄影与艺术指导（Photography & Art Direction）**：产品图与编辑图分轨、景深、光感、裁切、焦点。
6. **色彩克制（Color Restraint）**：白/中性底 + 一个点缀色，不用渐变与大面积彩色。
7. **响应式设计（Responsive Design）**：桌面/平板/手机的焦点重排、裁切与阅读顺序。
8. **无障碍与性能（Accessibility & Performance）**：对比度、键盘焦点、减少动态效果、替代文本、加载稳定性。

> 以上八项能力在模板中的落地（角色 / 槽位 / 权限三档 / 构图顺序）见 `06-jewelry-template-system.md`。

## 二、必读的大师与经典

| 大师 / 著作 | 学什么 |
| --- | --- |
| Dieter Rams《好设计十原则》 | 极简、诚实、永恒 |
| Paul Rand | 设计就是关系；先做对，再求新 |
| Josef Müller-Brockmann《网格系统》 | 瑞士网格与秩序 |
| Robert Bringhurst《The Elements of Typographic Style》 | 字体排印圣经 |
| 双钻模型（英国设计委员会） | 发现 → 定义 → 发展 → 交付的设计流程 |
| 侘寂美学 | 克制、留白、单一主叙事 |

## 四、字体资源（用于理解「奢侈品字体语言」）

| 类别 | 示例 | 气质 |
| --- | --- | --- |
| 衬线（标题） | Cormorant、Didot、Bodoni、Canela、ChronicleDisplay | 经典、底蕴、编辑感 |
| 无衬线（正文/界面） | Helvetica Neue、Neue Haas Grotesk、Avenir、Inter、SF Pro | 现代、清晰、克制 |
| 中文标题 | 思源宋体（Noto Serif SC）、宋体 | 中文语境的衬线气质 |

> 上线使用前必须核对字体许可、字符覆盖、字重文件、回退效果与加载成本；不得假定拥有商用授权。

## 五、关键术语速查

| 术语 | 含义 |
| --- | --- |
| 编辑式版面（Editorial Layout） | 杂志/画册式排版，强调层级、节奏、留白与叙事 |
| 网格系统（Grid System） | 把元素落在可解释的对齐线上，建立秩序 |
| 视觉层级（Hierarchy） | 通过字号、留白、位置区分信息主次 |
| 模数比例（Modular Scale） | 用固定比率（如 1.25/1.333）派生字号序列 |
| 行长（Measure） | 一行文字的字符数/宽度，影响可读性 |
| 留白（White Space / Negative Space） | 主动的构图元素，不是「没填满」 |
| 产品图 / 编辑图 | 纯底柔光的产品素材 vs 有叙事景深的氛围素材 |
| 排版驱动（Typographic） | 以字体与排版为视觉主体的设计方向 |
| 艺术指导（Art Direction） | 对影像、风格、氛围的整体统一把控 |
