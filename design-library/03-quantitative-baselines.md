# 03 · 量化数据基准（Quantitative Baselines）

> 把「高级感」落到可测量数值。均标注来源，用于快速诊断，不是机械像素检查；视觉结果和用户任务优先。
> **2026-08-19 增补第八节：奢侈站排印与配色实证基线**——来自十家顶级奢侈品官网 CSS 数值级实测（证据表见 `04-case-studies.md` 第六节），优先级高于本文件其余章节的通用参考值。

## 八、奢侈站排印与配色实证基线（十家实测 · 2026-08-19）

### 8.1 配色

| 项 | 实测值 | 依据 |
| --- | --- | --- |
| 页面底色 | `#FFFFFF` 纯白（首选）或 `#F5F5F5`/`#F3F2F3` 冷浅灰 | 9/10 家；Hermès `#FCF7F1` 为唯一暖底且极浅 |
| 文字色 | 标题 `#1A1A1A`–`#000`；正文 `#333`–`#383838` | Cartier/HW/Chanel 实测 |
| 灰阶 | 冷灰 `#9B9B9B`–`#8C8C8C`；**禁暖棕灰** | Chanel/通用 |
| 金色 | **仅 logo 与极小元素；不用于标题、正文、CTA 线、大面积** | 十家无一例外 |
| 叠字 | 仅限暗图白字；白底页文字独立成带 | Bvlgari/Rolex/HW 首屏 |

### 8.2 排印

| 项 | 实测值 | 依据 |
| --- | --- | --- |
| 标题字重 | **300–400**（细体为共识，禁 500+） | Tiffany 325 / Chanel、Bvlgari、Graff、Hermès 300 |
| 标题字号 | **14–36px**；奢侈感来自密度克制，不来自尺寸 | Chanel 14px 极致样本 |
| 中文字距 | 标题 **0 至 -0.4px 微负**；正文 normal | Tiffany -0.4 / HW -0.2 |
| 大写规则 | 全大写仅用于 CTA 与导航小字（11–16px），配 0.05–0.22em 宽字距 | VCA/Hermès |
| 字体路线 | 衬线或定制无衬线皆可——共性是细与克制 | 04 第六节两路线表 |

### 8.3 CTA 形态

- 首选**纯文字链接**（6/10 家）：全大写小字 11–14px + **黑色 1px 细底线**（Hermès 实测）或下划线（Tiffany）或无装饰（Cartier/Chanel）。
- 按钮式仅限暗底场景（Rolex）；**禁金线 CTA、禁按钮框、禁大字号 CTA**。

### 8.4 图与构图

| 项 | 实测值 |
| --- | --- |
| 图比例收敛集合 | **1:1、3:4、4:5、3:5、4:3、16:9**（Tiffany/Hermès 全站 1:1；Rolex 3:5 竖） |
| 图主导 | 首屏全视口；内容区大图 + 大留白；素材 2K–5K（Chanel 实测 5760px） |
| 文字量 | 一屏一行标题 + 一个链接为典型；文字是签名，不是标题墙 |

## 一、网格与容器

| 项 | 数值 | 来源 |
| --- | --- | --- |
| 栅格 | 12 列（12 可被 2/3/4/6 整除） | 行业标准 |
| 列间距（gutter） | 固定 24px | Gridmaker |
| 容器最大宽 | 1200 ~ 1280px | 行业标准 |
| 正文文字栏 | ≤ 720px（不拉满全宽） | 排版最佳实践 |
| 常用断点 | 1440 / 1024 / 768 / 390 | 响应式最佳实践 |
| 框架断点参考 | Bootstrap 1200/992/768/576；Tailwind 640/768/1024/1280/1536 | 框架默认 |

## 二、字号层级（极简网页设计 2025 方法论）

| 层级 | 数值 |
| --- | --- |
| 巨型主标题 | 60 ~ 80px+ |
| 章节标题 | 32 ~ 48px |
| 副标题 | 24 ~ 32px |
| 正文 | 16 ~ 18px |
| 模数比例 | 1.25（major third）或 1.333（perfect fourth） |
| 行长 | 正文 50 ~ 75 字符（约 10~15 词） |
| 行距 | 标题 1.2 ~ 1.4；正文 1.5 ~ 2.0 |

> 层级靠**字号与留白**建立，不靠颜色和边框。主标题/副标题/正文之间必须拉开强烈级距。

## 三、留白与构图

| 项 | 数值 | 来源 |
| --- | --- | --- |
| 留白对阅读理解力提升 | 约 20% | Chaparro et al., 2005（Wichita State University） |
| 品牌叙事区留白 | 约 40%（诊断参考） | 奢侈品方法论 |
| 字卡/海报纯净留白 | 40% ~ 60% | 排版指南 |
| 文字占画面 | < 30% | 奢侈品方法论 |
| 黄金分割 | 主图约 61.8% 宽 + 文字留白 38.2%（1.618 : 1） | Ad Design Guidebook |
| 黄金分割相对大小 | 标题是副题的 1.618 倍，副题是正文的 1.618 倍 | 同上 |

> 段落间距至少是行距的 1.5 倍以上（一行 24px 时，段落间至少 36px）。元素越重要，周围留白越大。

| 项 | 数值 |

## 五、Hero 尺寸与结构（Shopify 2026）

| 端 | 尺寸 / 比例 |
| --- | --- |
| 桌面 | 1600 × 500px（宽幅横幅约 3.2 : 1），可放大到 1800px 宽 |
| 手机 | 800 × 1200px（2 : 3） |
| 结构 | 全屏编辑特写 + 5 词级短标题 + 单个 CTA |

> Hero 的关键：图是主视觉焦点，标题与 CTA 是引导，不与图竞争；移动端重新确定焦点与裁切，不是桌面缩小版。
> 注意：1600 × 500px 是宽幅横幅（约 3.2 : 1），不等于 16 : 9；若采用 16 : 9 全屏 Hero，1600px 宽对应约 1600 × 900px。

## 六、字体策略数据（Monotype《A Type of Luxury》，30 个高奢品牌实测）

| 项 | 数据 |
| --- | --- |
| 网站主字体用无衬线 | 豪车 89% / 美妆 81% / 时尚 71% |
| 全大写策略 | 普遍用于关键位置（Logo、短标题），仅 3% 用于正文 |
| 定制 / 重命名字体 | 约一半品牌使用 |

> 启示：标题可用衬线保留「经典与底蕴」，但正文与界面以无衬线为主；全大写只用于品牌名与短标题，正文绝不使用。

## 七、间距与节奏参考（Swiss Design）

- 间距刻度只用固定值：4 / 8 / 16 / 24 / 32 / 48 / 64px。
- 组件内给足内边距，区块之间留呼吸空间。
- 动效默认 160 ~ 240ms；编辑型入场可 400 ~ 800ms 低幅度淡入/位移。
- 支持 `prefers-reduced-motion`，减少动态效果时仍完整传达内容与状态。
