# 「静谧光庭」模板预览影像

本目录的图片只服务于模板组件库和自动化视觉验收，用来检查图槽比例、主体位置、留白方向、文字落点与桌面/移动重排。

## 使用边界

- 图片不会写入模板 `defaultProps`，不会随模板拖入 PageDocument，也不是商品或媒体库数据源。
- 当前工作区没有随这些文件提供可追溯的原始来源、版权或商用授权记录，因此一律按内部概念预览素材处理。
- 不得将图片描述为真实在售珠宝、真实材质、真实工艺、真实门店、真实顾客或已经取得商用授权的品牌摄影。
- 正式公开前必须由运营或品牌负责人用来源明确、完成授权和内容审核的素材替换，并重新检查桌面与移动裁切。

模板库通过 `templatePreviewContent.ts` 注入 WebP 预览值；PNG 文件保留为内部母版，不能由公开页面直接加载。该文件的值不得成为页面默认内容或发布事实来源。
