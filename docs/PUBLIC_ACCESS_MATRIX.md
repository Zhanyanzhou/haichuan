> 决策日期：2026-08-13；最近校正：2026-08-23
> 职责边界：本文件只定义身份、可执行行动和可读取字段，不是项目方向文档；产品定位、品牌原则与页面职责只认 `docs/PROJECT_GUARDRAILS.md`，视觉与交互细则只认 `docs/UI_GUIDE.md`。

## 1. 身份与总边界

- 游客无需登录即可读取允许公开的作品字段并提交允许匿名提交的咨询；
- 普通客户（目标态称 `RETAIL`）可读取本人资料、选款与咨询记录，并只看到适用的公开零售价或高级定制报价流程；
- 只有人工审核为 `APPROVED` 的合作客户才可查看其本人的客户专属红蜡/紫蜡克价和创建合作订单；合作申请中、需补资料、驳回或暂停状态不得获得这些新权限；
- 合作资格暂停后立即禁止读取新的客户专属克价和创建新合作订单，但客户仍可只读查看本人暂停前形成的报价、价格快照和订单历史；
- 购物车、结算和支付能力当前默认关闭；`commerceEnabled / cartEnabled / paymentEnabled` 均以服务端安全默认 `false` 为准，路由或代码存在不代表真实交易可用；

### 交易与资金边界

- 当前零售购物车与直接下单路径只允许 `DIRECT_PURCHASE` 商品；其余四种 `SalesMode` 在现有零售路径中只能展示、选款、预约或咨询。已批准的高级定制与合作蜡模能力须在报价确认后通过尚未实现的独立报价状态机生成订单，不得通过改变 `SalesMode` 绕过当前零售门禁。
- `ProductSKU.price` 是直购成交价事实源；`Product.price` 仅为有效且有价 SKU 的最低价派生缓存。可售库存只认 Inventory。
- 当前零售 `DIRECT_PURCHASE` 的 0 库存商品可以发布并展示为售罄，但不得加入购物车、进入零售结算或直接下单。高级定制与合作蜡模订单须按各自的报价确认状态及后续获批的产能、材料门禁判断，不直接套用成品零售 Inventory。
- `/cart`、`/checkout` 等地址或后台付款页面可被路由识别，不等于购物车、结算、支付或外部网关已经开放；真实可用还需服务端开关、接口放行、有效数据、凭据、真实联调和独立上线批准同时满足。
- 在真实资金处理另行获批前，客户和后台员工均不得发起支付宝、微信等外部网关收款。当前源码以 `PAYMENT_GATEWAY_TRANSACTIONS_ENABLED` 作为安全默认关闭的服务端总门禁，并保留暂停前有效交易的回调处理；这只是代码级门禁证据，不代表目标环境配置、真实通道或资金闭环已经验收。

### 五种 `SalesMode` 主行动与合作报价

`SalesMode` 只决定作品面向公开客户的主行动，不承载客户身份、客户专属价格或合作资格：

| `SalesMode` | 公开主行动 | 当前交易限制 |
| ----------- | ---------- | ------------ |
| `DISPLAY_ONLY` | 咨询品牌顾问 | 不进入零售购物车或直接下单 |
| `SELECTION` | 加入选款并提交选款咨询 | 不进入零售购物车或直接下单 |
| `APPOINTMENT` | 预约到店或顾问联系 | 不进入零售购物车或直接下单 |
| `DIRECT_PURCHASE` | 在价格、库存、身份和交易开关均允许时直接购买 | 当前交易开关关闭时拒绝购物车、结算与支付 |
| `CUSTOM_INQUIRY` | 提交高级定制需求，等待后台报价并由客户本人确认 | 报价状态机和可支付订单目标尚未完成 |

合作蜡模报价与上述主行动正交：审核通过的合作商可以在适用设计上读取本人的有效合作克价、请求合作报价并在目标流程中创建合作订单，但不得修改该作品的 `SalesMode`，也不得获得其他客户的价格或订单。

本矩阵重点管理客户前台访问。后台员工不是单一权限主体；`SUPER_ADMIN / ADMIN / EDITOR / CUSTOMER_SERVICE / WAREHOUSE / SALES_CONSULTANT / FINANCE` 的具体接口权限以当前服务端 `@Roles` 白名单为代码事实。本文只固化下列高风险不变量，不复制所有 Controller 形成第二套 RBAC：`WAREHOUSE` 不查看或审核付款，`CUSTOMER_SERVICE` 不因售后职责获得付款审核权，员工禁用仅 `SUPER_ADMIN` 可执行；任何角色范围变化仍按 `AGENTS.md` 单独审批。

### 身份判定规则

- 游客：无有效客户令牌；
- 注册会员：有效客户令牌，且不满足合作商家通过条件；
- 合作商家：`accountType=PARTNER` 且 `partnerStatus=APPROVED`；
- 合作状态为 `PENDING`、`NEEDS_SUPPLEMENT`、`REJECTED`、`SUSPENDED` 或 `NONE` 时，一律按注册会员处理；
- 页面隐藏不能代替服务端鉴权，所有权限必须由服务端再次校验。
- `WAREHOUSE` 不得进入付款审核；可按授权进入库存和履约范围。
- `CUSTOMER_SERVICE` 保留售后查看、登记、审核与推进权限，但不因此获得付款审核权限。
- 后台员工“删除”实际为禁用账号，只有 `SUPER_ADMIN` 可执行；不得物理删除员工记录。

### 客户合作状态目标边界（已确认目标，尚未实现）

现有代码仍以 `CustomerAccountType.MEMBER/PARTNER + PartnerStatus` 表达部分身份。产品界面和运营口径按以下目标态收敛，落地时必须由服务端实时鉴权，不得只依据前端标签或旧令牌：

| 产品状态 | 新访问能力 | 必须拒绝 | 历史可见性 |
| -------- | ---------- | -------- | ---------- |
| `RETAIL` 普通客户 | 公开零售价、选款、预约和高级定制报价流程 | 客户专属红蜡/紫蜡克价、合作下单 | 本人普通/定制咨询与订单历史 |
| 合作申请中（含 `PENDING` / `NEEDS_SUPPLEMENT`） | 与 `RETAIL` 相同，并可在“我的账户”查看申请状态或补资料 | 客户专属双克价、合作下单 | 本人既有普通/定制历史和申请记录 |
| `REJECTED` | 与 `RETAIL` 相同；按审核说明重新申请 | 客户专属双克价、合作下单 | 本人既有历史和审核结果 |
| `APPROVED` | `RETAIL` 能力 + 本人当前有效合作克价（专属价优先，否则系统默认价）+ 合作订单 | 其他客户价格、订单或内部成本 | 本人普通、定制和合作历史 |
| `SUSPENDED` 暂停 | `RETAIL` 能力；只读本人暂停前历史 | 新客户专属价格、新报价、新合作订单 | 保留本人已形成的价格快照、报价和订单，不回写或删除 |

暂停与恢复必须经人工审核并写入审计；暂停应在服务端立即生效。历史订单继续显示成交时的价格快照，不能用当前价格重算。

### 合作申请入口与材料（已确认目标，尚未实现）

- 合作申请只能出现在登录后的“我的账户”中；不得在公开导航或独立公开页面形成第二申请入口。旧 `/partner` 如保留，只能作为登录校验后的兼容跳转，不能维护另一份表单或状态事实源。
- 申请字段至少包括：公司/商户名称、联系人、手机、地区、主营业务、预计月用量、营业执照/资质、合作说明。
- 营业执照和资质属于受控私密材料：不得进入公开媒体接口、客户商品响应或通用素材库公开地址；后台仅批准角色可查看，并应记录访问与审核操作。
- 提交后只进入人工审核流程；客户请求体、前端状态或文件上传均不得直接授予 `APPROVED`、客户专属价格或合作下单权限。

### 客户专属双克价与订单（已确认目标，尚未实现）

- 红蜡克价和紫蜡克价分别按客户维护，具有明确生效区间；同一客户的调价记录必须保留历史，不能覆盖旧值。
- 只有 `APPROVED` 客户可读取本人当前有效的两类合作克价：有效专属双克价优先，没有有效专属价时回退 `docs/DECISIONS.md` D.19 已批准的系统默认价；本矩阵不复制具体数值。不得展示其他客户价格或内部成本。
- 合作订单创建时固化客户、价格类型、适用克价、生效区间和成交快照；后续调价不得改写历史订单。
- 后台客户管理的目标范围包括：合作申请人工审核、客户专属红蜡/紫蜡克价、生效区间、调价历史、普通订单、定制订单、合作订单及完整审计。上述目标当前不得写成已完成。

## 3. 游客公开商品数据契约

公开接口只返回完成发布审核且同时满足以下条件的商品：

- `status=PUBLISHED`；
- `visibility=PUBLIC`；
- `deletedAt IS NULL`。

### 3.1 列表允许返回

| 字段                                                       | 规则                                                                                                   |
| ---------------------------------------------------------- | ------------------------------------------------------------------------------------------------------ |
| `id`                                                       | 允许作为当前响应中的不透明关联键和旧路由兼容引用；不得解释为业务编号或长期稳定合同                     |
| `code`                                                     | 规范公开作品引用；新公开链接与 Puck/CMS 持久化引用优先使用，发布前必须确认不是供应商或内部敏感编号       |
| `name`、`shortDescription`                                 | 允许，只能展示已审核内容                                                                               |
| `category.id`、`category.name`                             | 允许                                                                                                   |
| `materialType`、`goldWeight`、`weight`、`size`             | 允许，但必须来自已核验商品资料                                                                         |
| `salesMode`                                                | 允许，用于决定咨询、选款、预约、直接购买或高级定制报价主行动                                           |
| `price`                                                    | 仅 `DIRECT_PURCHASE` 且派生最低价有效时允许返回；它是 SKU 最低价摘要，不是成交价事实源；其他模式返回 `null` |
| `isHot`、`isNew`、`isRecommended`、`isLimited`、`isCustom` | 允许，用于公开展示标签                                                                                 |
| `images`、`primaryImage`、`listingImage`                   | 只返回下方定义的安全媒体描述，不返回原始文件路径                                                       |

公开价格筛选和排序只能作用于允许公开价格的 `DIRECT_PURCHASE` 商品；不得使用未公开的非直购 SKU 价格影响结果命中、数量或相对顺序，从而泄露价格区间或制造“筛选命中但价格为空”的矛盾体验。

### 3.2 详情可额外返回

本节是获准公开字段白名单，不是对当前序列化器已经合规的声明。当前实现如额外返回 `inventoryPolicy`、`isAvailableForPurchase`、结构化属性、详情内容或履约说明，必须逐项确认属于公开事实并补入本矩阵，否则视为待修实现缺口；`isAvailableForPurchase` 即使获准公开，也不得等同于真实库存数量。

| 字段                        | 规则                                                                                                          |
| --------------------------- | ------------------------------------------------------------------------------------------------------------- |
| `description`               | 允许，只能展示已审核内容                                                                                      |
| `gemInfo`、`craftTechnique` | 允许，但必须符合固定数据形状且内容真实                                                                        |
| `skus`                      | 只返回公开规格；允许 `id`、`material`、`size`、`goldWeight`、`isActive`，当前阶段不得返回库存、仓库或安全库存 |
| `skus.price`                | `DIRECT_PURCHASE` 成交价事实源；非 `DIRECT_PURCHASE` 返回 `null`                                              |

### 3.3 公开媒体允许返回

每张图片或视频只返回：

- `id`；
- `type`；
- `sortOrder`；
- `isVideo`；
- `width`、`height`；
- 指向公开媒体读取端点的 `mediaUrl`。

以下字段不得进入游客或客户响应：

- `storageKey`、本机磁盘路径和原始上传目录；
- 旧 `/uploads` 真实地址；
- `sourceImageId`、`cropData`、`fileSize` 等内部素材处理信息；
- 任何付款凭证、内部附件或仅供合作商家的原始资料。

### 3.4 所有前台身份均禁止返回

- 成本价、采购价、供应商信息；
- 真实库存数量、安全库存、仓库和库位；
- 销量、内部浏览统计和内部排序策略；
- 草稿、下架、归档、软删除状态及发布时间等运营字段；
- 内部备注、审核备注、员工信息和操作日志；
- 未发布图片、原始文件存储信息；
- 其他客户的咨询、选款、订单或联系方式。

## 5. 咨询数据与操作闭环

### 表单最小字段

- 必填：姓名、手机号、咨询类型、需求描述、服务隐私同意；
- 选填：偏好联系方式、方便联系时间、预算区间、电子邮箱；
- 从商品或选款入口进入时，前端自动携带可见商品 ID 和来源页面，不要求用户重复输入作品信息；
- 营销订阅必须与本次服务联系分开同意，默认不勾选。

### 后台状态建议

`NEW -> UNASSIGNED -> CONTACTED -> QUALIFIED -> APPOINTMENT_CONFIRMED -> COMPLETED`

无效或重复线索进入 `INVALID` / `DUPLICATE`，不得直接删除。后台还需要负责人、首次响应时间、最近跟进时间和结果备注；涉及数据库结构时另行审批，本阶段不擅自修改。

## 6. 联系信息与隐私字段规则

- 联系电话、邮箱、地址和营业时间以 `SiteSettings` 为唯一来源；
- 前台不得使用看似真实的硬编码电话、邮箱或地址作为失败兜底；
- 网站发布前必须校验必要联系信息完整，否则阻止发布或明确显示“暂未提供”；
- 服务隐私同意与营销同意分开记录，并保存同意版本与时间；
- 只收集完成咨询所需的最少数据。保存期限、访问角色、导出审计、删除或匿名化流程及法律、安全例外仍须形成明确决定；完成前不得声称应用数据生命周期已经形成合规闭环；
- 未经单独授权和脱敏，不得把真实咨询内容发送给外部人工智能服务。

## 7. 访问边界验收标准（按状态）

### 7.1 当前门禁验收

- 无登录状态只能执行游客矩阵允许的读取与匿名咨询行动；
- 游客只能收到 `PUBLIC + PUBLISHED` 数据，无法通过猜测标识获取其他可见级别商品；
- 公开响应和媒体响应不包含未批准字段或真实存储路径；
- 普通会员无法读取、加入购物车或购买 `PARTNER`、`INTERNAL` 商品；商品可见性必须在读取、加购、购物车刷新、结算和订单事务中复核；
- 合作商家权限暂停后，旧令牌也不能继续读取新的合作资料或创建新业务；
- 在当前交易冻结期间，前台不能创建购物车、订单、支付或退款，直接调用接口同样被拒绝；
- 后台员工不能绕过交易冻结发起支付宝、微信等外部网关收款；历史查看、人工审核和售后按角色继续可用；
- `WAREHOUSE` 无付款查看或审核入口和接口权限，`CUSTOMER_SERVICE` 可进入售后但不能据此审核付款；员工禁用仅 `SUPER_ADMIN` 可执行且不物理删除记录；
- 游客可以提交携带稳定公开作品引用的咨询；服务端会重新校验这些作品对提交者可见；
- 联系信息缺失时不显示编造内容；隐私说明可实际访问；
- 身份、操作和字段白名单必须分别覆盖服务端成功、拒绝、越权引用、旧令牌与暂停状态；Mock/隔离测试和真实接口验证分开报告。

### 7.2 已批准目标的完成验收

- 普通客户及合作申请中、需补资料或驳回客户只看到公开零售价或高级定制需求流程，不得读取客户专属红蜡/紫蜡克价或创建合作订单；
- 只有 `APPROVED` 客户能读取本人当前生效的双克价并创建合作订单；`SUSPENDED` 立即拒绝新价格和新订单，但仍可查看本人暂停前历史；
- 合作申请只在“我的账户”出现，包含已批准的最小业务与资质字段，并经过人工审核；
- 后台客户管理可按明确角色审核申请、维护客户专属双克价及生效区间、查看调价历史和普通、定制、合作订单，所有变更均有审计；
- 合作订单能力必须经独立实现、真实验收和交易开放批准后才可用；报价确认、事务转单和订单快照满足 `docs/DECISIONS.md` D.19。
