# 海川珠宝公开访问、数据与操作权限矩阵

> 状态：产品负责人已确认方向，待分批实现
> 决策日期：2026-08-13
> 适用阶段：品牌展示、作品浏览、选款咨询与顾问转化阶段

## 1. 产品决策

海川珠宝前台采用“公开展示 + 轻会员 + 顾问转化”模式：

- 游客可以浏览公开珠宝作品、公开详情、公开搜索和选款中心，不以登录作为浏览门槛；
- 注册会员获得跨设备选款记录、咨询记录和个人资料等持续服务，不用注册换取基础浏览权；
- 审核通过的合作商家可以访问合作商家专属商品资料，但合作资料不得对游客或普通会员公开；
- 购物车、结算已开放（需登录，线下转账+凭证付款）；线上支付待商户凭据接入；
- 公开前台的主要转化目标是提交选款咨询或预约顾问联系，不是直接下单。

## 2. 用户层级与操作权限

| 能力                                       | 游客                   | 注册会员               | 审核通过的合作商家 | 后台员工           |
| ------------------------------------------ | ---------------------- | ---------------------- | ------------------ | ------------------ |
| 浏览 `PUBLIC` 商品                         | 允许                   | 允许                   | 允许               | 允许               |
| 浏览 `MEMBER` 商品                         | 不允许                 | 允许                   | 允许               | 允许               |
| 浏览 `PARTNER` 商品                        | 不允许                 | 不允许                 | 允许               | 允许               |
| 浏览 `INTERNAL` 商品                       | 不允许                 | 不允许                 | 不允许             | 按后台角色允许     |
| 搜索和筛选可见商品                         | 允许                   | 允许                   | 允许               | 允许               |
| 临时选款                                   | 允许，保存在当前设备   | 允许                   | 允许               | 不适用             |
| 提交选款咨询                               | 允许，填写最少联系信息 | 允许，自动带入账户资料 | 允许               | 不适用             |
| 提交通用咨询                               | 允许                   | 允许                   | 允许               | 不适用             |
| 跨设备保存选款                             | 不允许                 | 允许                   | 允许               | 不适用             |
| 查看个人咨询记录                           | 不允许                 | 允许                   | 允许               | 按后台角色允许     |
| 申请合作商家身份                           | 需先注册或登录         | 允许                   | 已完成             | 不适用             |
| 创建购物车、结算、支付                     | 不允许（需登录）       | 允许（线下转账）       | 允许（线下转账）   | 仅保留内部管理能力 |
| 查看成本、供应商、真实库存、仓库、内部备注 | 不允许                 | 不允许                 | 不允许             | 按后台角色允许     |

### 身份判定规则

- 游客：无有效客户令牌；
- 注册会员：有效客户令牌，且不满足合作商家通过条件；
- 合作商家：`accountType=PARTNER` 且 `partnerStatus=APPROVED`；
- 合作状态为 `PENDING`、`NEEDS_SUPPLEMENT`、`REJECTED`、`SUSPENDED` 或 `NONE` 时，一律按注册会员处理；
- 页面隐藏不能代替服务端鉴权，所有权限必须由服务端再次校验。

## 3. 游客公开商品数据契约

公开接口只返回完成发布审核且同时满足以下条件的商品：

- `status=PUBLISHED`；
- `visibility=PUBLIC`；
- `deletedAt IS NULL`。

### 3.1 列表允许返回

| 字段                                                       | 规则                                                                                                   |
| ---------------------------------------------------------- | ------------------------------------------------------------------------------------------------------ |
| `id`                                                       | 允许，用于前台路由与查询                                                                               |
| `code`                                                     | 允许作为公开作品编号；运营发布前必须确认不是供应商或内部敏感编号                                       |
| `name`、`shortDescription`                                 | 允许，只能展示已审核内容                                                                               |
| `category.id`、`category.name`                             | 允许                                                                                                   |
| `materialType`、`goldWeight`、`weight`、`size`             | 允许，但必须来自已核验商品资料                                                                         |
| `salesMode`                                                | 允许，用于决定“咨询 / 选款 / 预约”按钮                                                                 |
| `price`                                                    | 仅 `DIRECT_PURCHASE` 且价格有效时允许返回；当前阶段其他模式返回 `null`，页面显示“咨询顾问”而非虚假价格 |
| `isHot`、`isNew`、`isRecommended`、`isLimited`、`isCustom` | 允许，用于公开展示标签                                                                                 |
| `images`、`primaryImage`、`listingImage`                   | 只返回下方定义的安全媒体描述，不返回原始文件路径                                                       |

### 3.2 详情可额外返回

| 字段                        | 规则                                                                                                          |
| --------------------------- | ------------------------------------------------------------------------------------------------------------- |
| `description`               | 允许，只能展示已审核内容                                                                                      |
| `gemInfo`、`craftTechnique` | 允许，但必须符合固定数据形状且内容真实                                                                        |
| `skus`                      | 只返回公开规格；允许 `id`、`material`、`size`、`goldWeight`、`isActive`，当前阶段不得返回库存、仓库或安全库存 |
| `skus.price`                | 与商品价格规则一致；非 `DIRECT_PURCHASE` 返回 `null`                                                          |

### 3.3 公开媒体允许返回

每张图片或视频只返回：

- `id`；
- `type`；
- `sortOrder`；
- `isVideo`；
- `width`、`height`；
- 指向公开媒体读取端点的 `mediaUrl`。

以下字段不得进入游客或客户响应：

- `storageKey`、本机磁盘路径和原始上传目录；
- 旧 `/uploads` 真实地址；
- `sourceImageId`、`cropData`、`fileSize` 等内部素材处理信息；
- 任何付款凭证、内部附件或仅供合作商家的原始资料。

### 3.4 所有前台身份均禁止返回

- 成本价、采购价、供应商信息；
- 真实库存数量、安全库存、仓库和库位；
- 销量、内部浏览统计和内部排序策略；
- 草稿、下架、归档、软删除状态及发布时间等运营字段；
- 内部备注、审核备注、员工信息和操作日志；
- 未发布图片、原始文件存储信息；
- 其他客户的咨询、选款、订单或联系方式。

## 4. API 目标边界

| 接口                                                  | 身份               | 返回或行为                                                 |
| ----------------------------------------------------- | ------------------ | ---------------------------------------------------------- |
| `GET /api/products/public`                            | 游客可访问         | 仅 `PUBLIC + PUBLISHED` 的安全商品列表                     |
| `GET /api/products/public/:id`                        | 游客可访问         | 仅 `PUBLIC + PUBLISHED` 的安全商品详情；不可见统一返回 404 |
| `GET /api/products/public/:productId/media/:imageId`  | 游客可访问         | 仅公开商品媒体；校验商品和图片归属；不可见统一返回 404     |
| `GET /api/products/catalog`                           | 注册会员           | `PUBLIC + MEMBER` 的安全列表                               |
| `GET /api/products/catalog/:id`                       | 注册会员           | `PUBLIC + MEMBER` 的安全详情                               |
| `GET /api/products/catalog`                           | 审核通过的合作商家 | `PUBLIC + MEMBER + PARTNER` 的安全列表                     |
| `GET /api/products/catalog/:productId/media/:imageId` | 会员或合作商家     | 校验可见范围；合作资料按现有策略加水印                     |
| `GET /api/products` 及管理端 CRUD                     | 后台员工           | 继续按后台角色鉴权                                         |
| `POST /api/inquiries`                                 | 游客可访问         | 提交通用咨询；限流、校验、记录隐私同意版本                 |
| `POST /api/selection-inquiries`                       | 游客可访问         | 提交选款咨询；服务端校验隐私同意，商品 ID 必须再次校验为提交者可见 |
| 客户购物车、结算、支付、退款写接口                    | 前台用户           | 当前阶段由服务端业务开关拒绝，不依赖前端隐藏               |

## 5. 前台路由目标

| 路由                 | 当前阶段目标                                        |
| -------------------- | --------------------------------------------------- |
| `/products`          | 游客公开；未登录只加载公开商品                      |
| `/products/:id`      | 游客公开；越权或未发布统一显示“当前暂不可浏览”      |
| `/catalog`           | 游客公开；可以临时选款并提交咨询                    |
| `/search`            | 游客公开；搜索范围与当前身份可见范围一致            |
| `/customer`          | 公开入口；未登录显示登录/注册，登录后显示个人服务   |
| `/partner`           | 需要注册会员登录                                    |
| `/cart`、`/checkout` | 当前阶段不出现在前台导航，也不作为可用业务路由      |
| `/privacy`           | 必须提供真实可访问的隐私说明，不得使用 `#` 占位链接 |

## 6. 咨询数据与运营闭环

### 表单最小字段

- 必填：姓名、手机号、咨询类型、需求描述、服务隐私同意；
- 选填：偏好联系方式、方便联系时间、预算区间、电子邮箱；
- 从商品或选款入口进入时，前端自动携带可见商品 ID 和来源页面，不要求用户重复输入作品信息；
- 营销订阅必须与本次服务联系分开同意，默认不勾选。

### 后台状态建议

`NEW -> UNASSIGNED -> CONTACTED -> QUALIFIED -> APPOINTMENT_CONFIRMED -> COMPLETED`

无效或重复线索进入 `INVALID` / `DUPLICATE`，不得直接删除。后台还需要负责人、首次响应时间、最近跟进时间和结果备注；涉及数据库结构时另行审批，本阶段不擅自修改。

## 7. 联系信息与隐私规则

- 联系电话、邮箱、地址和营业时间以 `SiteSettings` 为唯一来源；
- 前台不得使用看似真实的硬编码电话、邮箱或地址作为失败兜底；
- 网站发布前必须校验必要联系信息完整，否则阻止发布或明确显示“暂未提供”；
- 服务隐私同意与营销同意分开记录，并保存同意版本与时间；
- 只收集完成咨询所需的最少数据，并定义保存期限、访问角色、导出审计和删除或匿名化流程；
- 未经单独授权和脱敏，不得把真实咨询内容发送给外部人工智能服务。

## 8. 实施顺序与边界

### P0-A：公开商品浏览闭环

1. 恢复公开商品列表、详情和公开媒体端点，但严格使用本文件的数据白名单；
2. 前端按身份选择游客公开接口或会员目录接口；
3. 解除 `/products`、`/products/:id`、`/catalog`、`/search` 的登录墙；
4. 保留 `/partner` 登录保护；
5. 增加游客、会员、合作商家和越权 ID 的接口测试与端到端测试。

注意：本批次不修改真实商品数据。若数据库中尚无 `visibility=PUBLIC` 的已发布商品，游客列表应正确显示空状态；运营人员需另行审核并手动决定哪些商品公开。

### P0-B：开放前台交易

1. 购物车、结算、付款凭证上传入口已开放（需登录）；
2. 服务端客户购物车、结算、支付写入口由 `CUSTOMER_COMMERCE_ENABLED` 控制（默认 true）；
3. 后台历史订单、报价、履约和售后管理保持可用；
4. 线上支付（微信/支付宝）接入需完成商户凭据与回调验证。

### P0-C：联系信息与隐私

1. 移除联系页硬编码的虚假兜底信息；
2. 增加真实 `/privacy` 页面并连接所有同意入口；
3. 为表单控件补齐程序化标签、必填状态、错误关联和键盘焦点；
4. 提交成功后说明预计响应方式和时间，不承诺尚未建立的服务等级。

## 9. 验收标准

- 无登录状态可以进入公开作品列表、公开详情、选款中心和搜索；
- 游客只能收到 `PUBLIC + PUBLISHED` 数据，无法通过猜测 ID 获取其他可见级别商品；
- 公开响应和媒体响应不包含内部字段或真实存储路径；
- 普通会员无法读取 `PARTNER` 或 `INTERNAL` 商品；
- 合作商家权限暂停后，旧令牌也不能继续读取合作资料；
- 前台不能创建购物车、订单、支付或退款；直接调用接口同样被拒绝；
- 游客可以提交携带商品上下文的咨询；服务端会重新校验这些商品对提交者可见；
- 联系信息缺失时不显示编造内容；隐私说明可实际访问；
- 桌面端和 390 像素移动端均有 loading、empty、error 状态，并可完成键盘操作；
- 模拟端到端测试与真实接口集成测试分开执行，测试结果不会因数据源切换而产生假失败。
