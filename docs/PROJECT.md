# 海川珠宝 — 项目导航（兼容入口）

> 本文件保留旧入口，避免历史引用失效；它不保存项目方向、当前状态、技术版本、启动命令或开关事实。
> 最近核对：2026-08-23。

## 按问题读取

| 需要了解什么 | 现行来源 |
| --- | --- |
| 产品定位、品牌原则、公开网站与页面职责 | `docs/PROJECT_GUARDRAILS.md` |
| 视觉、交互、响应式与无障碍 | `docs/UI_GUIDE.md` |
| 当前实现、运行与上线状态 | `docs/CURRENT_STATE.md` |
| 技术实现不变量 | `PROJECT_RULES.md` |
| 开发运行方式 | `docs/DEVELOPMENT_WORKFLOW.md` 与当前 `package.json` 脚本 |
| 身份、操作与字段边界 | `docs/PUBLIC_ACCESS_MATRIX.md` |
| 已批准决定、原因、失效与待决事项 | `docs/DECISIONS.md` |
| 安全审批、执行与验收 | `AGENTS.md`、`WORKFLOW.md` |

涉及产品定位、品牌表达、公开网站或客户旅程的任务先读取 `docs/PROJECT_GUARDRAILS.md`；其他任务按 `WORKFLOW.md` 路由读取必要的专项文档。历史聊天、计划、审计报告和本兼容入口均不得成为新的项目方向来源。
