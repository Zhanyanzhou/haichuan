# 海川珠宝端到端旅程与验收路径

> 本页只定义稳定旅程、成功结果和应取得的证据，不维护完成状态。当前状态统一记录在 `feature-completion-matrix.md`，实际验收以当次环境和新鲜证据为准。

## 旅程矩阵

| 旅程 | 关键步骤 | 成功结果 | 证据入口 |
| --- | --- | --- | --- |
| 发现品牌与作品 | 进入公开首页 → 理解品牌 → 浏览作品/系列 → 打开详情 | 正式内容和媒体权利可追溯；桌面、移动端信息清晰且无测试数据 | [PROJECT_GUARDRAILS](../PROJECT_GUARDRAILS.md)、[UI_GUIDE](../UI_GUIDE.md)、公开页面验收 |
| 选款与咨询 | 浏览/筛选 → 选择作品 → 提交需求 → 后台领取与跟进 → 客户收到合规反馈 | 请求只属于提交者；后台可追踪状态；通知失败可恢复且不泄露隐私 | [PUBLIC_ACCESS_MATRIX](../PUBLIC_ACCESS_MATRIX.md)、选款咨询目标测试、真实接口与投递证据 |
| 商品维护与公开 | 后台创建/编辑 → 完成媒体、SKU 与公开资料 → 通过发布门禁 → 公开目录/详情回显 | 后台写入和公开读取一致；不可公开、已归档或下架内容不会泄露 | 商品合同、真实数据库 CRUD、公开回显和权限证据 |
| 页面装修与发布 | 选择页面 → 编辑草稿 → 保存/重载 → 预检 → 发布 → 公开回显 → 必要时回滚 | 草稿、发布快照和公开 Renderer 一致；并发冲突不覆盖；回滚不破坏草稿 | [页面装修文档导航](../page-builder/README.md)、页面发布合同和获批环境验收 |
| 客户账户与售后 | 注册/登录 → 查看本人资料与订单 → 发起允许的售后 → 后台处理 → 客户查看结果 | 两个身份域隔离；客户只见本人数据；状态机、金额和隐私字段正确 | [PUBLIC_ACCESS_MATRIX](../PUBLIC_ACCESS_MATRIX.md)、真实身份/权限/失败路径证据 |
| 报价转单与交易 | 发起正确报价通道 → 后台出价 → 客户本人确认 → 资源复核 → 事务转单 → 支付/退款/对账 | 报价、确认、库存/产能、金额和订单快照不可变；失败不留下部分状态 | [DECISIONS](../DECISIONS.md) D.18–D.20、交易合同、真实数据库与获批渠道证据 |
| 正式发布与持续运行 | 冻结候选 → 验证制品 → 迁移/恢复演练 → 部署 → 公网验收 → 告警与回退 | 唯一环境、不可变版本、负责人和回退点完整；故障可发现、可恢复 | [PRODUCTION_RELEASE_RUNBOOK](../PRODUCTION_RELEASE_RUNBOOK.md) 与目标环境证据包 |

## 通用验收规则

每条旅程都必须记录：

1. 精确版本、环境、身份和数据来源。
2. 成功、失败、权限、空状态、重试或并发等实际存在的边界。
3. 桌面与移动端或其他受影响视口。
4. 可以证明的层级，以及不能外推的更高层级。
5. 未完成项、责任人、下一动作和必要回退。

代码、Mock、路由、页面、构建、历史 PASS 或单个截图都不能单独证明端到端旅程完成。
