## 4. 正式作品录入表

建议首发 8–12 件、2–3 个有效分类，但以每个公开分类都有完整有效内容为准。

每件作品一行：

| 字段 | 填写要求 |
| --- | --- |
| 作品编号/code | 唯一、稳定、非测试编号 |
| 中文名称 | 正式公开名称 |
| 分类 | 必须指向已确认的公开分类 |
| 展示模式 | 仅非交易模式；不得为 DIRECT_PURCHASE |
| 简介/详情 | 可核实，不含价格、库存、配送或购买承诺 |
| 材质 | 由事实负责人确认 |

| 详情主图 | 有授权记录且可读取 |

## 9. 推荐交付顺序

1. 先交正式主体、联系方式、隐私责任人与客服负责人。
2. 再交分类、作品事实和逐媒体授权记录。
3. 通过现有后台逐项录入、预检和发布；不直接批量写真实数据库。
4. 完成桌面 1440×900 与手机 390×844 的正式内容浏览器验收，关闭 CONTENT_READY 缺口。
5. 明确唯一目标环境后，另行提交 migration、配置、部署、备份恢复和回滚批准包。
6. 仅当 CODE_READY、CONTENT_READY、PRODUCTION_READY 全部通过后，才生成正式 release manifest 并判定 RELEASE_READY。
