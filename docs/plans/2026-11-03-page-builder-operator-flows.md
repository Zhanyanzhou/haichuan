## 依赖

1. 目录辨认不依赖新字段，可以先做。
2. 「视觉不显示」需要页面实例上的显示方式，再改渲染和撤销。源合同改动另一次授权，本计划不执行 `contracts:generate`。
3. 手机图和恢复继承先核对现有 `mobileImage` 与背景图「恢复继承」能覆盖哪些槽位，缺的再补，不新开一套设备状态。
4. 布局确认只加在模板设计的兼容切换上。页面仍停在规格卡。
5. 保存、冲突和迟到回包接在现有保存事务上，不新建状态库。
6. 有效布局的读取链在预览、保存检查和 Renderer 上对齐后，再写旧模板的画面回归。不要用「JSON 没变」代替。
7. 不重开 D.48，不回填历史 JSON。

## 批次

### 1. 选用时能认出模板

- 卡片：辨认图、名称、一句状态。宽高和校验值不在卡片上。
- 「预览」「插入」「设计此模板」分开。只插入已发布版本。
- 有封面时标明「封面」。放大预览用「模板示例」「中性结构」或「页面实际内容」，名称和画面一致。
- 验收：PB-FLOW-001 的选用半段。预览不写页面；草稿不能插入。

### 2. 换图改字，并收起点名的重复文字

- 页面属性按图片和文字列出中文名称。勾选只收起这一句，原文保留，不留空高。
- 不收起未点名的正文、按钮和 Logo。图里的按钮不是链接。
- 验收：只含标题的图，正文和按钮仍在；完整海报在手机上没有空文字带；取消勾选后原文回来。

### 3. 双端连续

- 切设备保留模板、选中、输入和未保存修改。
- 普通图可沿用桌面原图。手机图和焦点可选。
- 「恢复继承」和「清空内容」两个入口、两种结果。桌面后续修改不盖掉已有手机值。
- 横版含字图进竖框时提示，不静默裁字。
- 验收：PB-FLOW-002。中间宽度和矮视口能解释，且不产生第三套文案。

### 4. 模板设计里的布局切换

- 兼容切换保留图文、链接、双端图源、焦点、显隐和仍适用的覆盖，一步撤销。
- 不兼容变化先说明影响；取消后与确认前一致，包括未保存输入。
- 不重跑创建配方。页面运营仍只用规格卡上不超过 4 项的设置。
- 验收：左右互换、取消、撤销三条都留下可核对的定义快照。

### 5. 保存身份和失败恢复

- 保存按钮写明写页面还是写母模板草稿。
- 保存失败留输入。冲突可选恢复，后写不静默覆盖。
- 迟到回包不覆盖后来选中的模板、设备和内容。
- 模板发布后，有未保存修改的页面会话不被整页刷新盖掉。目录刷新成功不等于页面已同步。D.43 只沿用能无损保留的已保存草稿。
- 验收：PB-FLOW-003。

### 6. 同一套有效布局，并保护旧画面

- 预览、保存检查和公开渲染走同一读取链：配方只作初值，已保存定义为设计事实，页面设置为实例，设备覆盖和几何规则得到最终画面。
- 旧定义不改 JSON。回归用同一视口下的画面语义，而不只比文件。
- 新规则只在此后写明相应字段的版本上启用。

## 设计推演（不是已执行测试）

| 场景 | 运营要能 | 开发要能核对 |
| --- | --- | --- |
| 选用已有模板并换图改字 | 找到、插入、改完、不进向导 | 写入的是页面草稿，母模板版本不变 |
| 图里只有标题 | 正文和按钮还在，只收起被点名的标题 | 原文仍在实例里，渲染高度不含空带 |
| 完整海报到手机 | 没有无意义文字带 | 收起的是显式选择，不是角色特例 |
| 手机独立图，再改桌面 | 恢复继承与清空分得开；桌面新图不盖掉手机图 | 缺值继承，显式覆盖和显式空值三者不同 |
| 左右布局 | 取消回到原状；确认后可一步撤销 | 槽位身份、类型和行动含义不变才算兼容 |
| 长文、缺图、比例不合、窄屏、矮视口 | 看得到溢出或空态，字不被裁、图不变形 | 端点看视口宽，分栏看节宽，矮视口按 R-3，缩放不参与 |
| 模板已发布，页面有未保存修改 | 会话还在，公开页未变 | D.43 不改公开快照，也不用刷新盖会话 |
| 保存失败、冲突、迟到请求 | 输入还在，能选恢复 | 回包绑定请求时的模板、设备和内容 |
| 读取旧模板和历史页面 | 原来的画面含义还在 | 未写 `geometryPolicy` 的仍按 D.46、D.47；不回填 |

## 两边检查

运营：五条流程都写了入口、默认、范围、反馈、保存和失败。封面、草稿和正式版本能分开。做不到的布局会说明去模板设计，而不是留一个空项。

开发：事实来源写成一条链。显示方式是页面字段，不是第二套内容系统。旧数据不改写。本计划的批次可以单独验收，后一批不推翻前一批的规则。
