# 店铺装修界面增量修复记录（2026-09-19）

本记录是本轮实现与验证证据，不替代现行模板产品规则，也不代表上线或内容发布完成。

## 本轮改动

| 问题 | 实现结果 |
| --- | --- |
| 图层都显示“动态模板实例”，不同模板混在同一编号组 | 使用实例保存的模板名称；只对同一模板的重复实例编号。画布操作栏与删除确认沿用同一显示名。 |
| 已有发布错误时仍显示绿色“图片已添加” | 发布错误优先展示；明确区分“当前实例有 N 项发布阻断”和“页面有 N 项发布阻断”。整页检查继续保留所有阻断。 |
| 属性区次要内容与说明占用过多空间 | 补充内容使用可展开分组；必填字段、锁定覆盖残留或当前实例有错误时首开可见。选中具体字段仍直接显示该字段。未选择可调整对象时不显示大段编辑边界说明。 |
| 页面模板卡片的预览、添加、升级同等突出 | 预览与主要操作并排；另一操作单独成行。刚发布且已有旧实例时，升级仍为主要操作，添加继续独立可用。 |
| 模板工具栏重复入口 | 停靠布局以组件库新建入口为主，“更多”保留入口；已命名模板的设置从“更多”进入，未命名模板仍显示命名提醒。设置打开与窄屏焦点恢复复用既有路径。 |

保留七步创建流程、模板结构与画布联动、页面与母模板的数据边界，以及 UI_GUIDE 规定的 `<1440` 叠层 / `>=1440` 停靠规则。未迁移或修改页面、模板的实际内容。

- 以下 6 个 Playwright 场景分批通过，均为真实编辑器组件 + 自有 API 夹具，不算真实后端保存或发布验收：

  - 390px 键盘实例操作、边界状态与无横向溢出。
  - 字段任务分组、必填组展开、收起后字段定位及实例内容保护。
  - 当前实例 / 整页错误范围、节点 / 设备 / 内容字段精确定位。
  - 页面装修和模板设计共享目录预览比例、操作页脚及非覆盖布局。
  - 1440px 新建入口与设置入口、设置后的输入焦点、草稿状态。
