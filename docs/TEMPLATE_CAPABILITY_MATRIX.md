# 店铺装修模板能力矩阵

> 目标：统一模板的业务边界、可编辑能力与固定规则。内部类型用于兼容历史数据，运营端只展示通俗名称。

## 统一规则

- 预览图、编辑画布和发布页面必须使用同一结构与比例。
- 桌面和移动素材独立时，焦点也必须独立保存；缺少移动素材时允许安全复用并显示警告。
- 跳转只允许“不跳转、商品详情、站内页面”等模板契约明确开放的目标，不开放任意外链。
- 字体、品牌色、关键比例、最大数量和安全区属于固定规则，不允许自由拖拽或任意输入。
- 草稿允许不完整；发布前必须显示完成度、错误和降级提醒。
- 图片、商品或接口内容必须覆盖加载、空值和失败状态；旧草稿字段必须继续安全读取。

## 批次执行顺序

1. 基础视觉：首屏展示、单张海报、双图展示。
2. 动态视觉：图片轮播、视频展示、可点击图片。
3. 商品导购：作品陈列、单品主推、分类导航。
4. 场景导购：佩戴灵感、场景选款、礼赠选款。
5. 品牌内容：单图介绍、图文介绍、分栏介绍。
6. 服务信任：服务保障、资质与证书、定制流程、顾客评价、门店信息。
7. 活动引导：预约引导、引导横幅、限时活动。
