# 海川珠宝 — UI 规范

> 最后更新：2026-08-07
> ⚠️ 本文档是**目标设计规范**。当前实际代码中存在内联样式与 Tailwind 混用的情况，正在逐步统一中。

## 样式方案现状

⚠️ 两种方式并存（非规范，是历史遗留）：

| 方式                 | 使用量  | 典型文件                        |
| -------------------- | ------- | ------------------------------- |
| Tailwind `className` | ~241 处 | CategoriesBlock, Cart, About    |
| 内联 `style={{}}`    | ~250 处 | ImageTextBlock, Catalog, Search |

**建议**：新代码优先使用 Tailwind。内联样式仅用于动态计算值（如 `style={{ width: iframeWidth }}`）。

## 颜色体系

### 品牌色

| 名称   | 色值      | 用途                       |
| ------ | --------- | -------------------------- |
| 金色   | `#B8944E` | 品牌主色、按钮、链接、价格 |
| 金色浅 | `#D4B87A` | hover                      |
| 金色深 | `#9F7941` | active                     |

### 中性色

| 名称     | 色值                  | 用途         |
| -------- | --------------------- | ------------ |
| 标题     | `#2C2C2C`             | 标题、正文   |
| 辅助文字 | `#8A7F72`             | 描述、提示   |
| 背景     | `#F5F2ED` / `#FBF9F6` | 页面背景     |
| 边框     | `#E8E7E3` / `#F0F0F0` | 分割线、卡片 |

### 状态色

| 名称 | 色值      | 用途       |
| ---- | --------- | ---------- |
| 成功 | `#52C41A` | 完成、正常 |
| 警告 | `#FAAD14` | 待处理     |
| 错误 | `#FF4D4F` | 取消、异常 |
