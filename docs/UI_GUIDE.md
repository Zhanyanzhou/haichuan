# 海川珠宝 — 网站设计标准（文字 / 间距布局）

> 版本：专业版 v4 · 最后更新 2026-08-15
> 理念：**静奢（Quiet Luxury）**——衬线标题、细字重、大留白。对标 VCA / Cartier / Tiffany。
> 依据：6 家顶级珠宝品牌官网实测 + 桌面《设计师知识库》17 份。
> 本文件定两个标准：**① 网页文字　② 网页间距与布局**。颜色 / 组件 / 图片 / 动效 / 响应式 / 文案语气留待后续再定。

# 标准二 · 网站如何用文字

### 2.1 一句话原则

> 衬线做标题（细字重），无衬线做正文；中文不加宽，英文大写加宽；层级靠字号和留白区分，不靠颜色和边框。

### 2.2 字体双轨（衬线配衬线、无衬线配无衬线）

| 用途 | 字体栈 |
| --- | --- |
| 英文标题 / 品牌名 | Cormorant Garamond, Garamond, serif |
| 中文标题 | Noto Serif SC, Songti SC, SimSun, serif |
| 正文（中英） | -apple-system, PingFang SC, Helvetica, sans-serif |

> 禁止：英文衬线 + 中文黑体（气质打架）。数字、英文一律用西文字体，中文用中文字体。

### 2.3 排印 Scale（模数比例 3 : 1.6 : 1）

| 层级 | 桌面 px | 移动 px | 用途 |
| --- | --- | --- | --- |
| 展示标题 Display | 68 | 40 | 品牌大标题、Hero |
| 主标题 H1 | 34 | 28 | 页面主标题 |
| 区块标题 H2 | 24 | 20 | 区块标题 |
| 系列名 / 副标题 | 18 | 16 | 系列名、副标题 |
| 正文 | 15 | 14 | 正文 |
| 辅助 | 12 | 11 | 注释、辅助 |

### 2.4 字重

| 场景 | 字重 |
| --- | --- |
| 标题（前台） | 300 ~ 500，偏细，禁止粗黑体 |
| 正文 | 400 |
| 后台标题 | 600（无衬线） |

### 2.5 字距（4 场景）

| 场景 | 字距 |
| --- | --- |
| 中文标题 | `0` 或 `-0.2px`（不加宽） |
| 英文全大写标题 | `+1.5px`（加宽） |
| 大字号 | 收紧，可微负 |
| 小字号 | 放宽，可 `+0.5px` |

### 2.6 行距与行长

| 项 | 数值 |
| --- | --- |
| 标题行距 | `1.2 ~ 1.4`（字越大越紧） |
| 正文行距 | `1.6 ~ 2.0`（字越小越松） |
| 正文行长 | 每行 ≤ 45 字 |

### 2.7 对齐三法

| 对齐 | 适用 | 感觉 |
| --- | --- | --- |
| 左对齐 | 默认、正文、多行标题 | 舒适、现代 |
| 居中 | 短标题、产品图下方 | 庄重、对称 |
| 两端对齐 | 正文段落 | 整齐 |

### 2.8 中西混排

- 中英文之间留 1/4 空格。
- 标点统一：中文语境用全角，英文语境用半角。
- 数字、英文用西文字体，中文用中文字体，不混用。

### 2.9 前台 vs 后台（文字分界）

| 项 | 前台 | 后台 |
| --- | --- | --- |
| 标题 | 衬线，字重 300 ~ 500 | 无衬线，字重 600 |
| 正文 | 无衬线，字重 400 | 无衬线，字重 400 |

### 2.10 文字禁用

- ❌ 粗黑体大标题、中文标题加宽字距、衬线正文
- ❌ 促销腔、感叹号堆砌、价格轰炸、长段落
- ❌ 靠颜色和边框区分层级（应靠字号和留白）

# 标准三 · 网站如何用间距与布局

### 3.1 一句话原则

> 留白是奢侈品最贵的元素——信息删到不能再删，空白留到最大；布局只允许左对齐或居中，一屏一个焦点。

### 3.2 间距 Scale（统一 8pt 网格，8 的倍数）

| 档位 | 值 | 前台用途 | 后台用途 |
| --- | --- | --- | --- |
| xs | 8px | — | 紧凑内边距 |
| sm | 12px | — | 表单项间距 |
| md | 16px | — | 卡片内边距 |
| lg | 24px | 卡片网格间距 | 模块间距 |
| xl | 32px | 卡片网格间距 | 大模块间距 |
| 2xl | 48px | 图文间距 | — |
| 3xl | 64px | 区块内模块间距 | — |
| 4xl | 80px | 页面左右边距 | — |
| 5xl | 96px | 区块垂直间距 | — |

### 3.3 栅格

- 12 列栅格；容器最大宽度 1280px，居中。
- 正文文字栏更窄（≤ 720px），不拉满全宽。
- 一切元素落在网格上——秩序产生高级感（Müller-Brockmann）。

### 3.4 版式与留白铁律

- 一屏只允许 1 个视觉焦点，其余元素为它服务。
- 留白 ≥ 40%，文字 ≤ 30%，文字集中在角落或一侧，绝不居中堆砌。
- 两种合法版式：**对称**（产品居中，庄严经典）/ **不对称但平衡**（图一侧、文字反向留白，现代编辑感）。

### 3.5 响应式断点（布局随断点变化）

| 断点 | 行为 |
| --- | --- |
| 桌面 ≥ 1440 | 12 列，边距 80px |
| 平板 768 ~ 1440 | 边距 32px，网格可并 2 列 |
| 手机 ≤ 390 | 单列，边距 20px，留白 ≥ 20% |

### 3.6 前台 vs 后台（间距布局分界）

| 项 | 前台 | 后台 |
| --- | --- | --- |
| 间距 | 大留白（48 ~ 96px 为主） | 8pt 网格、紧凑 |
| 布局 | 12 列、留白驱动、单一焦点 | 高信息密度 |
| 对齐 | 左对齐 / 居中 | 左对齐为主 |

### 3.7 间距与布局禁用

- ❌ 满屏信息堆砌、模块挤在一起无呼吸感
- ❌ 左一个右一个散乱对齐、多焦点
- ❌ 移动端把留白挤没、强行多列
- ❌ 正文文字栏拉满全宽（超过 720px）
