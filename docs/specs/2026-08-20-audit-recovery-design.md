# 海川珠宝审计恢复设计

## 目标

把 2026-08-20 全产品审计中的已确认风险，按安全、客户信任、品牌体验、运营效率和工程可维护性收敛为可验证的交付；不把测试通过或局部页面效果误报为生产就绪。

## 业务与体验原则

- 访客先看到真实、完整、可理解的作品与服务，不看到测试商品、破图、私域商品占位或伪造承诺。
- 运营操作默认安全：新商品先草稿，离开编辑页先保护，后台状态必须有合法流转与明确反馈。
- 前台以作品、摄影、排版与顾问服务建立高级珠宝信任；后台以信息密度、可读性和低误操作为先。
- 所有写入入口、权限边界、客户隐私与交易路径以服务端为最终门禁。

## 自主决策记录（2026-08-20）

### D-1：新建商品默认 `DRAFT + MEMBER`

**决定：采用。**

- 用户视角：新建中的空商品绝不应进入游客目录或被截图、索引。
- 产品视角：商品资料、媒体和价格通常分步填写，草稿是符合实际工作流的默认状态。
- 工程视角：创建 API 不接收媒体，若默认发布，每次创建都会被发布门禁拒绝；草稿消除这一自相矛盾。
- 品牌视角：宁可作品暂不出现，也不能让未完成、无图或测试内容承担品牌第一印象。

### D-2：公开页面只能引用 `PUBLIC + PUBLISHED` 商品

**决定：恢复 PUBLIC 门禁。**

- 用户视角：公开页面不应因身份不同出现缺块、空壳或不连续的作品叙事。
- 产品视角：如需会员专属内容，应设计页面受众机制，而不是在同一公开文档中隐式混入私域商品。
- 工程视角：恢复门禁消除受限商品数字 ID 留在公开文档的残余暴露，并使发布校验与游客渲染目标一致。
- 品牌视角：高级品牌页面必须保持完整构图，不能依赖“优雅降级”掩盖内容策展错误。

### D-3：视频桌面比例回退至 `16:9 + 21:6`

**决定：回退。**

- 用户与运营视角：沿用已经批准、已存在于其他模板中的受控比例，避免突然出现另一套素材要求。
- 产品视角：`16:9` 覆盖常规作品影像，`21:6` 保留当前模板体系的电影感横幅位；两者足够，不增加 `4:3`。
- 工程视角：`21:6` 已在共享比例令牌及多个合同槽位中使用。改成 `21:9` 会升级为全局比例迁移，而非局部视频修复。
- 品牌视角：比例只服务构图职能；未经真实素材与双端视觉证据，不引入新的桌面视频语言。

## 交付程序

1. **在途方向收敛**：落实 D-1/D-2/D-3，修正合同外视频能力，建立结构化发布错误契约，并完成编辑器发布流验收。
2. **后台可靠性**：处理商品编辑离开保护、咨询状态机、金价真实状态、库存和图片排序防误操作。
3. **客户旅程与数据卫生**：客户会话错误分流、咨询幂等、页面页脚、首页安全回退；真实商品与媒体数据只形成清理清单，不擅自改库。
4. **可访问性与性能**：键盘路径、语义标题、替代文本、移动首屏、商品列表分页与候选集上限，逐页真实浏览器验收。
5. **上线门禁**：真实域名、联系信息、资产授权、SEO 元数据、真实交易闭环、日志脱敏和部署验证全部具备证据后，才允许建议发布。

## 不可自动替代的外部输入

- 生产部署、域名、真实联系信息、商户/短信/第三方凭据与资产商业授权。
- 真实客户、订单、支付或商品数据的删除、批量变更和迁移。
- 交易功能从关闭到对外开放。

这些事项可以准备代码、清单和验收脚本，但不能用推测代替真实业务事实或授权。
