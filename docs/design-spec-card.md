## 3. 构图决策（方法，不规定数值）

数值规范只保证"不错"，构图决策才决定"好不好"。写代码前必须先定这四件事：

1. **唯一主焦点**：一个视口只有一个。作品、工艺或本页任务成为焦点，装饰、口号、按钮不能抢。
2. **基本型**：中轴对称 / 左图右文 / 右图左文 / 全幅影像+下缘文字 / 编辑错位双图 / 纯排印无图。写下选择理由（素材形态、阅读顺序、页面任务），没有理由就是套模板。
   正例与画法见 `design-library/06-composition-patterns.md`：只读它的 §0 选型表 + 选中的那一型 + §7 成页规则 + §9 方向卡样例，不要六种全读。方向卡按 §9 的颗粒度填，写"品牌形象、高端大气"等于没填。
3. **差异化**：写出本页与站内其他页**不同的 3 个版式决定**。写不出来，说明在复制上一页。
4. **节奏**：组内距离明显小于组间距离；区块之间有呼吸、有松紧变化，不是等距堆叠。

反默认解：居中 Hero + 副标题 + 按钮 + 三列卡片 + 底部 CTA 是最常见的平庸输出，默认不采用；确需采用要写出本页非此不可的理由。

方向卡字段（≤25 行，写代码前填完）：页面任务与唯一主焦点 / 构图（12 列落位、图文比例、首屏高度与裁切，基本型＋理由）/ 3 个差异化版式决定 / 排印（引用 UI_GUIDE 层级数值与中英文字体分工）/ 节奏（组内距与组间距、容器宽度与边距）/ 影像（比例、光线、背景、材质焦点、裁切安全区；无真实素材用中性几何占位并标注，不用生成图掩盖结构）/ 色彩落点（只列实际用到的语义令牌）/ 不做清单 3 条。填写颗粒度照 `design-library/06-composition-patterns.md` §9 样例，字段空着不动手。

表达纪律："高级、克制、大气、呼吸感"不是方案，必须翻译成构图、比例、位置或 UI_GUIDE 中已有的数值层级。

## 4. 可观察验收（替代主观自评）

- **缩略图检**：缩到 25% 仍能一眼指出唯一主焦点。
- **删减检**：还能删一个元素而不损失信息，就删。
- **首屏清单**：列出标题、正文、操作、图片的数量与位置；无重复层级、无并列主行动。
- **双端检**：按 `WORKFLOW.md` §5 选受影响视口（局部改动至少一个桌面 + 一个移动），无横向溢出、无被裁文字、焦点与阅读顺序正确。
- 结论只覆盖实际检查过的视口与状态，未检查的写"未验证"。
