# 海川珠宝 · 模板风格总纲（白盒画册）

> 状态：风格总纲（2026-08-19）
> 依据：`design-library/04-case-studies.md` 十家品牌实测 + `template-design-framework.md`
> 定位：23 个模板共用的统一设计语言；各模板具体答案见 `design-cards/<key>.md` 设计卡
> 一句话：**纯白画布 + 亮调摄影 + 近黑细字 + 图绝对主导 + 文字签名化 + 点缀色趋近于零**

---

## 一、风格定调

高级珠宝品牌的「简约、克制、大气」来自十家实测共识，不是堆砌：

1. **底色**：9/10 纯白或冷浅灰 + 近黑字；点缀色趋近于零，无大面积金色。
2. **字重**：标题 300–400 细体，无粗黑体。
3. **字号**：标题 14–36px、正文 11–16px——奢侈感来自密度克制，不是字号。
4. **CTA**：纯文字链接（下划线/无装饰），非按钮。
5. **图绝对主导**：白底页面文字独立成带，叠字仅限暗图。
6. **金色纪律**：金只出现在 logo 与极小元素，正文/标题一律黑灰。

## 二、三大系统

### 1. 排印系统

| 用途 | 规格 |
|------|------|
| 标题 | 衬线细体 300–400，微负字距（-0.2~-0.4px） |
| 正文 | 无衬线 14–16px，行高 1.8 |
| 眉题 / 编号 | 11px 无衬线，全大写，字距 0.18–0.24em |
| 英文全大写 | 仅限眉题与 CTA，配宽字距 |
| 层级 | 靠字号与留白，不靠颜色和边框 |

### 2. 色彩系统

| 角色 | 色值 |
|------|------|
| 画布 | `#FFFFFF`（默认）/ `#FCF7F1`（叙事暖白，仅少数叙事区） |
| 主文字 | `#1D1C1C` |
| 次文字 | `#5C5C5C` |
| 点缀金 | `#B8944E`（仅编号、细线、极小元素，<5%） |

### 3. 构图与槽位系统

- **分栏基线**：38/62 黄金分割（图 62% 主导）；海报式模板图 ≥75%。
- **两种合法构图**：对称居中（庄严经典）/ 不对称平衡（现代编辑感）；禁图文各半僵化等分。
- **图槽四要素**：语义命名 + 比例建议 + 焦点裁切（安全区 15%–85%）+ 设备继承。
- **文字槽**：签名化（贴角、窄束 ≤440–720px）。
- **行动槽**：≤1 个主 CTA，纯文字下划线形态。
- **留白槽**：叙事区 ≈40% 诊断参考；间距只用 4/8/16/24/32/48/64 刻度。

## 四、编辑区交互通用规范

所有模板的 Inspector 遵循固定分组顺序与三档权限（固定 / 受控 / 内容可编辑）：

```text
状态栏（模块名）
→ 图片素材（桌面图 / 移动图 / 焦点 / 替代文字）
→ 文字内容（眉题 / 编号 / 标题 / 副文，附字符+行数预算）
→ 商品关联（有业务对象的模板）
→ 行动与关联（CTA 文字 + 链接选择器）
→ 构图与设备（镜像 / 对齐 / 列数 / 遮罩等受控预设）
→ 颜色与文字（tone 预设，成对切换）
→ 模板专属功能（画廊数量 / 轮播参数 / 热区编辑等）
→ 保存栏
```

通用交互铁律：

1. 无素材模板隐藏「图片素材」组；纯文字模板直接从「文字内容」开始。
2. 未选商品时隐藏商品展示选项并给完成提示；隐藏 CTA 时同时隐藏文字与链接。
3. 没有字段的分组整组隐藏，禁止「高级设置」当杂物抽屉。
4. 文字溢出：超字符/超行数时画布预警，不静默截断关键信息。
5. 移动素材默认继承桌面；裁切风险超门槛才提示独立上传。
6. 焦点编辑：安全区 15%–85%，换图不得误用旧焦点。
