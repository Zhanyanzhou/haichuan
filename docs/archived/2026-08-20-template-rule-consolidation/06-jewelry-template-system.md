# 06 · 珠宝模板设计体系（Jewelry Template System）

> 定位：模板设计的**方法论与构图知识层**——回答「一个珠宝模板包含什么、可编辑性怎么设计、槽位怎么排才高级」。
> 层级声明：项目实施约束以 `docs/UI_GUIDE.md`（品牌规范）与 `contracts/page-builder/`（机器合同）为准；本文档不创建第二套项目规则，数值均为方法论参考。
> 本文档取代已删除的 luxury-visual `templates/` 8 比例骨架（2026-08-18 判定错误并清理）。

---

## 〇、为什么有这份文档：旧规则的错误定性

被删除的旧模板规则错在**比例先行**，三条病根：

1. **把摄影物料画布比例当模板结构**——1080×1080、1080×1350 是单张图片物料的画布；网页模板的高度由「宽度策略 + 高度策略 + 内容」共同决定，不存在固定画布。
2. **顺序颠倒**——先选比例再填内容；正确顺序是角色 → 构图 → 槽位语义。图片槽位比例仅作该槽素材的裁切建议，不得替代模板整体比例——模板比例（根模块宽度档、高度策略、分栏结构）独立声明，两类比例分别作答（见框架规则 3.1）。
3. **没有编辑性设计**——只讲静态构图，没有槽位语义、权限边界、素材状态与合同；而「可编辑」正是模板区别于一张海报的本质。

---

## 一、模板的本质

> **模板 = 视觉角色 + 三设备完整构图 + 语义槽位 + 受控可编辑性**

- 模板是可插入、复制、排序、删除的完整构图单元；图片、文字、按钮是模板内部的**角色**，不是可自由拖动的独立模块。
- 模板插入后立即形成可识别骨架；运营替换任何内容都**不破坏视觉角色、阅读顺序与跨设备结构**——这是「可编辑」的全部意义。

---

## 二、知识点全景（9 层地图）

| 组 | 层 | 知识点 | 一句话 |
| --- | --- | --- | --- |
| 设计 | 1 角色层 | 视觉角色（primary / feature / support-stage）、页面位置、适用与不适用场景 | 先回答「我在这页扮演什么」；每页只有一个主舞台 |
| | 2 构图层 | 桌面、平板、手机三套完整构图 | 不是一张比例图；平板是独立验收视口，不是缩小版桌面 |
| | 3 槽位层 | 图片槽、文字槽、行动槽、留白槽 | 模板 = 一组有语义的槽位（详见第五章） |
| | 4 美学层 | 比例、留白、排印层级、配色克制、节奏 | 高级感的直接来源 |
| 编辑 | 5 权限层 | 固定结构 / 受控预设 / 内容可编辑三档 | 可编辑性的核心模型（详见第四章） |
| | 6 数据层 | 业务对象（商品/门店/活动/证书）引用单一事实来源 | 模板不复制第二份价格、库存、地址 |
| | 7 状态层 | 素材全生命周期状态与失败保护 | 状态保护决定编辑器是工具还是地雷 |
| 系统 | 8 合同层 | 单一机器合同、区块级版本、迁移 | 缩略图/编辑面板/画布/前台/服务端同源，五端一份规则 |
| | 9 验收层 | 三层完成度、真实浏览器验收 | 构建通过 ≠ 视觉验收通过 |

## 三、设计顺序（决策链）

```text
需求与使用场景
→ 视觉角色与品牌/商业模式
→ 桌面、平板、手机完整构图
→ 素材与业务对象角色（槽位语义）
→ 文字层级与内容预算
→ 固定项与受控选项（权限三档）
→ 编辑面板与字段依赖
→ 保存、发布与迁移合同
→ 真实浏览器验收
```

**禁止**：先堆字段、先定单张图片比例、或先复用现有组件，再反向解释模板用途。
**设计顺序 ≠ 编辑顺序**：设计师从需求与构图出发；运营按「素材 → 文字 → 行动 → 构图」的实际操作顺序编辑——「素材优先」只是编辑器操作顺序，不是设计起点。

## 四、可编辑性设计

### 4.1 权限三档

| 档 | 内容 | 例子 |
| --- | --- | --- |
| 固定结构（合同钉死） | 视觉角色、根宽度/高度策略、三设备构图与阅读顺序、槽位数量与语义、文字层级、CTA 上限、无障碍与发布门禁 | 单图文永远是编辑式分栏，不能变自由画布 |
| 受控预设（有限选项） | 左右镜像、文字对齐、图片焦点、留白档位、列数/数量范围、构图预设 | 每个选项声明六要素：改变内容、不变内容、设备作用域、持久化字段、兼容版本、回退值 |
| 内容可编辑（自由替换） | 素材、替代文字、标题/副标题/正文、行动文字、合法链接、内容项 | 文字约束三件套：字符预算 + 预期行数 + 溢出行为，不能只限字符数 |

> 禁止自由布局、自由字号、自由颜色、任意 HTML。**高级感的本质是约束下的控制**——自由度越大，一次误操作就能把页面拉回「电商后台感」。

### 4.2 设计卡（每个模板一张，14 项）

运营名称/类型/版本 → 目的与不适用场景 → 视觉角色 → 三设备根构图 → 槽位角色/数量/比例建议/焦点规则 → 文字层级与预算 → CTA 数量/位置/链接范围 → 权限三档划分 → 编辑分组与条件显示 → 五态（空/加载/失败/完成/发布）→ 缩略图与渲染要求 → 性能无障碍门禁 → 合同版本与迁移 → 自动检查与浏览器验收。未完成设计卡的模板不得加零散字段或样式补丁。

### 4.3 编辑面板信息架构（固定顺序）

```text
状态栏 → 图片素材（桌面/移动/焦点/替代文字）→ 文字内容 → 商品关联
→ 行动与关联 → 构图与设备 → 颜色与文字 → 专属功能 → 保存栏
```

三铁律：素材组用具体名称（「对比图片」不是「媒体」）；字段依赖由合同执行（未选商品→隐藏商品选项并给完成提示；隐藏 CTA→同时隐藏文字与链接）；没有字段的分组整组隐藏，**禁止「高级设置」当杂物抽屉**。

## 五、构图与槽位（核心章）

### 5.1 构图：非对称 > 等分

| 手法 | 用法 | 依据 |
| --- | --- | --- |
| 38/62 分栏基线（≈黄金分割 61.8/38.2） | 单图文：文字 38% / 影像 62%，允许镜像互换 | 项目基线 + Ad Design Guidebook |
| 非对称三角 | 双图文：主横图 + 次竖图 + 文字构成三角关系，禁止等分双卡 | 「设计就是关系」Paul Rand |
| 非对称画廊节奏 | 大图 → 双图 → 大图，间距统一 | 作品画廊基线 |
| 单一焦点 | 一个模板一个视觉焦点；两个 feature 模块不得连续同密度，用纯文字/通栏图做呼吸点 | 页面节奏原则 |
| 两种合法构图 | 对称居中（庄严经典）或不对称但平衡（现代编辑感）；禁止图文各半的僵化等分 | 详见 `01-editorial-layout.md` |

### 5.2 比例：三档用法（旧规则栽的地方）

| 档 | 含义 | 例子 |
| --- | --- | --- |
| 视口舞台 | 根模块占可用视口 88%–100%，高度随视口 | 首屏——不固定 16:7；16:7 只是桌面素材裁切建议 |
| 素材建议比例 | 只约束槽内素材的裁切建议，不决定模板整体结构（模板比例独立声明） | 通栏图桌面 21:6、视频 16:9、单图文 4:5、双图文 3:2+4:5、热区 16:9/4:3/4:5、手机竖图普遍 4:5 |
| 内容高度 | 根高度由文字+行动+留白共同撑出 | 纯文字、品牌要点、服务承诺 |

配套机制：**焦点裁切**（每素材每设备持久化焦点点，裁切围绕焦点，换图不得误用旧焦点）+ **设备素材继承**（移动默认继承桌面，裁切风险超门槛才提示换独立素材）。

### 5.3 留白：第四种槽位

- 叙事区留白 ≈40%（诊断参考）；文字占画面 <30%。
- 间距刻度只用 4/8/16/24/32/48/64px（8px 主节奏）——间距不允许刻度外魔法数字。
- 段落间距 ≥ 1.5 倍行距；**元素越重要，周围留白越大**（CTA 的留白就是它的气场）。
- 正文栏 ≤720px、行长 50–75 字符；满宽文字行是廉价感最快来源。

### 5.4 图片槽位：六要素 + 分轨

1. **语义命名**：主影像/细节图/证书材料/热区底图/前后对比图——不是 image1/image2。
2. **数量上下限**：轮播 2–5、画廊 3–7、品类入口 2–4（数量是合同边界）。
3. **比例建议 + 焦点规则**：每槽声明建议比例与焦点持久化策略。
4. **主次独立校验**：双图文的主图与细节图互不覆盖。
5. **设备继承与回退**：继承状态明确标记。
6. **状态保护**：上传失败保留原图、取消不产生脏数据、删除前核对引用。

**分轨铁律**：产品图（纯底、柔光、主体稳定）与氛围图（叙事、景深、佩戴关系）是两条轨道，混用是廉价感第一来源；图片是感知价值的第一信号——糊图与随意裁切直接摧毁高级感。

### 5.5 文字槽位：五要素

1. **三级层级制**：主标题 → 必要说明 → 1 个主 CTA。
2. **双预算**：字符数 + 预期行数 + 溢出行为（截断/撑开/预警）。
3. **级距拉开**：标题 60–80 / 章节 32–48 / 正文 16–18px，模数 1.25 或 1.333；**层级靠字号与留白，不靠颜色和边框**。
4. **排印语气**：标题可衬线（经典底蕴）、正文无衬线；全大写只给品牌名与短标题，正文绝不。
5. **文案克制**：标题 2–10 个中文字；CTA 用「探索/查看/预约」，禁「抢购/最后机会」。

### 5.6 行动槽位

每个模板最多 **1 个主行动**（预约入口可加 1 个次级联系方式作为唯一例外）；CTA 文字与跳转目标同组编辑；颜色遵循 60/30/10，点缀色 <10% 且一屏只选一种主要用途。

## 六、双载体分工

共用同一套槽位与构图方法论，边界如下：

| 维度 | Puck 页面模板（为主） | 可编辑图片物料（为辅） |
| --- | --- | --- |
| 形态 | 编辑器内可插入的页面区块（23 模板体系） | 单张可编辑图文物料（海报/banner/社媒卡） |
| 比例约束力 | 三档用法（5.2），素材比例仅裁切建议 | 画布即物料本身，比例约束力强（4:5 小红书、3:4 电商主图等按媒介定） |
| 数据 | 引用业务单一事实来源（商品/门店/活动系统） | 素材与文字自持，发布前人工核查真实性与授权 |
| 结构 | 由机器合同钉死三设备构图 | 单画布结构，仍需权限三档（固定构图/受控预设/可编辑内容） |
| 验收 | 五宽度浏览器验收 + 发布门禁 | 输出前按「高级 vs 廉价」对照 + 检验三问自检 |

## 七、高级感来源（对照表）

| 维度 | 廉价模板 | 高级模板 |
| --- | --- | --- |
| 构图 | 等分网格、卡片墙 | 非对称构图 + 单一焦点 + 呼吸节奏 |
| 比例 | 比例当结构、统一 16:9 硬套 | 三档分治，比例只是素材建议 |
| 留白 | 填满、怕浪费 | 留白即构图，≈40%，间距刻度化 |
| 文字 | 满屏说明、自由字号 | 三级制、少字、级距拉开 |
| 编辑性 | 自由布局，一改就崩 | 三档权限，换什么内容骨架不塌 |
| 裁切 | 随意裁、糊图 | 语义焦点 + 精确裁切 + 高分辨率 |
| 配色 | 大面积金、渐变 | 60/30/10，点缀 <10% |
| 一句话 | 用装饰冒充高级 | 用控制和克制建立自信——**奢侈不喧哗** |

## 八、验收

1. **三层完成度**：素材完成 → 内容完成 → 发布完成（真实性、授权、链接、响应式、性能、无障碍门禁）。
2. **检验三问**：眯眼看焦点是否唯一；换尺寸看构图是否成立；删减看还能不能再删。
3. **浏览器验收**：1920/1440/1024/768/390 五宽度，检查完整比例与视觉权重、文字真实行数与对比度、裁切焦点与继承、重排、键盘与减少动态效果。构建成功、契约通过或截图不能单独证明视觉验收通过。
