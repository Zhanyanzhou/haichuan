# 历史审计与设计验收证据

本目录保存 2026 年 8 月至 9 月的审计、设计 QA、V1 本地候选和运行时所有权处置快照。它们保留当时的问题推导、截图和代码锚点，但不再属于活跃状态、架构或执行入口。

使用前必须重新核对当前代码、合同、工作树和目标环境。旧分支、旧 HEAD、旧端口、旧容器、旧测试数量、旧数据库数量和旧命令不得直接重放。

现行入口：

- 当前状态：`../../CURRENT_STATE.md`
- 动态工作包：`../../AI_PROGRAM_LEDGER.md`
- 总体验收：`../../acceptance/feature-completion-matrix.md`
- 前台规则：`../../PROJECT_GUARDRAILS.md` 与 `../../UI_GUIDE.md`
- 当前代码所有权：运行 `npm run test:runtime-ownership` 或在明确候选下重新生成对应审计证据

目录中的图片与报告作为同一历史证据包保留；移动归档不表示报告中的问题仍存在或已经关闭。
