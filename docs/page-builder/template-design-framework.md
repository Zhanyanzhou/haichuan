# 模板编辑与页面交接细则

> 本文从属于[模板设计唯一标准](template-creation-rules.md)，只展开编辑操作、四区、响应式与页面交接。创建步骤、操作次数、预设数值、内容版本边界和最低验收均由总标准定义；本文不得另立产品规则。

> 2026-09-11 统一标准后保留的目标细则；当前实现、差距和验证层级见 [CURRENT_STATE](../CURRENT_STATE.md)。本文的编辑、页面消费与版本交接验收是总标准的展开，不以旧创建流程或旧测试数量判定完成。
> 四区布局只认 [PROJECT_RULES](../../PROJECT_RULES.md) §7；视觉、响应式、交互与文案只认 [UI_GUIDE](../UI_GUIDE.md) 附录 A 和 [ADMIN_COPY_GUIDE](../ADMIN_COPY_GUIDE.md)；源码与接口入口见[实现边界](../architecture/page-builder-boundary.md)。

## 1. 产品模型

店铺装修包含两个相互衔接、彼此独立的工作空间：

- **模板设计**是上游生产工具，回答“页面结构怎样组织、怎样呈现、允许页面人员改什么”。它编辑母模板定义，保存模板草稿，发布不可变模板版本。
- **页面装修**是下游使用工具，回答“当前页面具体展示什么、使用哪个模板版本、何时对外发布”。它编辑 `PageDocument`，保存真实内容与受控实例覆盖，发布页面版本。

两种模式的关系是“发布版本交接”，不是同一份草稿的两个页签：

```text
用途、尺寸、布局、图片、内容、风格配置
  → Template Recipe → Generator → 母模板初稿
  → 精修结构、槽位、布局、响应式与页面开放范围
  → 保存模板草稿
  → 发布不可变模板版本
  → 页面装修从目录选择该版本
  → 填写真实内容与业务引用
  → 保存、预检并发布页面
```

同一个运营人员可以连续完成两种任务，但模式切换不得合并历史、自动保存、自动插入、自动升级或自动发布。顶部必须持续说明当前模式、当前对象和保存状态，使用户能回答“我正在改母模板，还是当前页面”。

主流程通过七步选择与实时方案预览自动生成完整基础模板，再由画布和属性编辑精调。新增母模板不依赖旧固定模板的名称、数量、构图、内置 key 或批次进度；模板列表管理新建、切换、复制、删除和重命名，持久化目录与未保存会话分开。页面装修的内置测试目录仍仅保留 `hero`。页面根内容、固定业务区、首屏与导航角色仍遵守 [PROJECT_GUARDRAILS](../PROJECT_GUARDRAILS.md) 和现行合同。

完整模板设计按总标准第 1 节分为“创建基础模板 → 按对象微调 → 检查并保存”。七步仅属于第一阶段；第二阶段的必备功能及“快捷值 + 精确输入 + 即时反馈”统一见[总标准第 9.2～9.4 节](template-creation-rules.md#92-第二阶段微调功能清单)。本细则只展开对象、事务、设备和交付实现边界，不能将微调改为另一套强制步骤，也不能把创建通过当作精调通过。

## 2. 编辑对象与事实来源

| 对象 | 保存什么 | 不保存什么 | 权威来源 |
| --- | --- | --- | --- |
| 母模板定义 | 完整根构图、节点、槽位、设计规则、响应式规则、页面开放范围 | 页面真实文案、媒体、商品、链接和经营事实 | `TemplateDefinitionV2` 与 [template-definition.schema.json](../../contracts/page-builder/template-definition.schema.json) |
| 模板草稿与版本 | 模板身份、目录状态、可继续编辑的草稿、不可变发布版本 | 页面草稿和页面发布结果 | `DynamicTemplate` Repository 与服务端合同 |
| 页面实例 | 精确模板身份与版本、真实内容、业务引用、允许的实例覆盖 | 母模板内部结构改写、任意 HTML/CSS | Puck `PageDocument` |
| 首屏测试合同 | 唯一 `hero` 测试样例和页面级规则 | 从零创建的未来母模板目录、模板设计路线图、退役模板的新建入口 | [content-templates.contract.json](../../contracts/page-builder/content-templates.contract.json) |
| 系统示例 | 短文、长文、缺图和媒体比例等临时压力状态 | 可编辑默认内容、公开内容、经营数据 | 运行时生成并只读展示 |

目录、编辑器、Inspector、Renderer 和校验器都是上述来源的消费者，不能自行维护模板结构、字段开放范围或版本状态的平行副本。模板能力由注册节点与受控配置构成，不接受任意 HTML/CSS、可执行组件上传或绕过品牌规则的自由脚本。

## 3. Shared Editor Core 与隔离边界

### 3.1 可以共享

- 固定四区外壳及面板标题组件。
- 模板 Repository 的读取能力和目录基础数据。
- 同源 Renderer、设备预览和系统示例生成能力。
- 选择、聚焦、画布定位、撤销命令、字段控件和基础校验组件。
- 权限能力的表达方式、错误展示、未保存保护和恢复组件。

共享表示复用基础设施，不表示两种模式必须呈现相同控件，也不表示两种模式可以写同一个对象。

### 3.2 必须隔离

| 隔离项 | 模板设计 | 页面装修 |
| --- | --- | --- |
| 当前编辑对象 | 母模板草稿 | 当前页面草稿及其实例 |
| 会话与历史 | 模板 undo/redo、dirty、selection | 页面 undo/redo、dirty、selection |
| 完整结构权限 | 可在合同允许范围内编辑根构图、容器和槽位 | 不可改写母模板内部树 |
| 内容权限 | 编辑新版本允许的默认图文；系统示例与压力试排独立 | 填写真实内容和稳定业务引用，按版本默认值规则解析 |
| 保存 | 保存当前模板草稿；新建与复制产生独立新身份 | 保存当前页面草稿 |
| 发布 | 创建不可变模板版本并进入可用目录 | 创建页面发布版本并更新对应语言指针 |
| 失败与恢复 | 恢复当前模板保存基线或把历史版本载入同一模板草稿 | 恢复页面草稿、线上版本或处理并发冲突 |

任何异步回包都必须继续绑定发起请求时的模式、对象和版本；切换模式、对象或发生后续修改后，迟到回包不得覆盖新会话或把新修改误标为已保存。

## 4. 模板设计：从点击入口到可交付版本

本节是目标交互规格，不表示当前界面已经具备全部能力。首次创建按七步组织选择并允许返回修改；生成后的编辑允许反复调整和主动保存，不以步骤完成率锁定工具。模板的闭环包含“能通过预设生成可用结果、能精调、能保存重开、能发布、能被页面正确使用”，实际页面内容仍在页面装修中填写。

### 4.1 先明确作品单位与界面层级

一个母模板是一个可插入页面的完整可复用构图，可以含一个或多个内容区域；不等于整站主题，也不强制包含导航、页脚或多个区域。用途与页面角色按合同判断，工艺图文只是验收样例。

运营界面用“区域、布局分组、图片、标题、正文、按钮”等名称。“图片”等内容元素对应槽位；“布局分组”对应已有合法容器能力，不创建新的数据模型。必要根节点由系统管理，技术上的 Section 根与根下内容区域不能都显示成同一种可任意新增的区域。用户添加区域时无须再套一层容器才能开始放内容。

功能点击按以下四种方式呈现，保持四区和工作上下文：

| 任务 | 打开方式 | 操作与退出 |
| --- | --- | --- |
| 选中、改尺寸、排版、命名、开放字段 | 画布按对象能力直接操作，第四区原位同步并提供精确控制 | 设计值共用同一来源，命名和开放字段在第四区编辑；切对象前妥善处理未提交输入 |
| 添加元素、移动到分组、选择布局预设 | 当前触发入口旁的临时浮层，可由第二区或画布就近打开 | 先显示作用对象与合法选项；Esc 关闭并还原焦点，不丢已完成操作 |
| 模板设置、页面字段查看、预览检查、发布检查 | 第四区临时视图，配合第三画布区 | 显示标题与“返回编辑”；返回保存原对象、设备、缩放和滚动位置 |
| 处理未保存切换、保存冲突、版本差异 | 复用现有短对话框或版本抽屉 | 写明目标与后果；支持取消；历史恢复不产生新模板身份 |

持续编辑不依赖右键、双击或悬停；这些只能作为快捷入口。只读预览中，画布交互与编辑命令分开，退出后恢复上下文。

### 4.2 新建与继续：先选择方案，再生成可编辑模板

模板组件库的“新建模板”是主入口；顶部快捷入口调用同一创建流程。全部选项和数值只维护于[模板创建规则](template-creation-rules.md)，点击后：

- 显示类型、画布尺寸、布局结构、图片配置、内容配置、视觉样式、确认生成七步；每步选预设即更新临时方案画布，允许返回修改，不创建空白模板要求用户自行搭建。
- 类型、根画布和基础样式是模板级单一设置，区域、图片和文字可重复添加；“设置/添加/修改”明确区分。摘要展示用户选择，推荐不能强制覆盖。
- 确认生成完整基础模板后进入现有四区：列表标识当前未保存草稿，结构展示生成节点，画布展示可用结果，属性编辑负责精调。生成不调用保存、发布或页面插入。
- 已有未保存修改时提供“继续编辑 / 保存草稿并新建 / 放弃修改并新建”；保存失败、冲突或期间继续修改时留在来源会话。
- 进入模式时恢复仍存在的会话；跨会话的“继续草稿”明确显示保存位置、名称和时间，用户主动打开；不自动打开历史首屏模板或来源不明的恢复方案。

`hero` 首屏测试样例只保留在页面装修的显式测试入口，用于验证首屏合同与 Renderer；它不得进入模板设计目录、自动打开或初始化新母模板。新建生成器使用合法节点与配方；普通模板复制按独立身份和来源保护规则执行，不恢复退役模板。

第四区在整体设计中直接显示模板名称、整体尺寸和页面视觉职责。视觉职责采用合法默认值即可开始；选择主舞台时说明页面可重复添加，首个可见主舞台承担页面级标题、首图优先级和页头语境。首屏构图可就近检查导航兼容，不能将自由文本“用途”当成行为开关。分类、用途、推荐页面、描述和标签放在有摘要的模板资料中，发布前补齐必要信息；推荐页面仅用于目录推荐，不宣称已构成页面准入校验。slotSummary 等可推导信息自动展示，不能要求重复手填。名称允许暂时清空以便替换，提交时校验；不将每个字符更改变成一条撤销历史。预览宽度的默认值复用当前项目配置，不要求运营先选设备型号。

目录中的浏览/聚焦项与正在编辑的模板身份分开标识。搜索、筛选、列表重试不切换编辑会话，不清空画布；当前模板被筛选掉时仍保留“正在编辑”身份与返回定位入口。首次未保存作品只显示为当前会话提示，不伪造已持久化目录记录。目录读取失败、无模板和筛选无结果分别呈现，失败时保留当前草稿并只重试目录读取。

打开另一模板沿用上述未保存保护；目标加载成功后才切换四区，加载失败保留来源会话。目录明确区分“编辑草稿”和“查看已发布 vN”，查看历史版本只读，载入草稿必须走明确的恢复动作；不能用一个未注明版本的“打开”悄悄覆盖当前草稿。归档、回收站和恢复仅在 Repository 与当前权限真实支持时出现，不能用空入口暗示已具备能力。

### 4.3 添加区域、分组和元素：让落点看得见

第二功能区保留“添加区域”“添加元素”两个入口；模板默认图文在属性中编辑，页面实例真实内容在页面装修中填写。仅在需要区分两者时就近提示，不用“内容只能在页面装修中填写”限制默认图文编辑。不得把第一模板目录改成节点工具箱，也不把全部技术注册项一次性列给运营。

画布选中区域后提供“之前添加区域 / 之后添加区域”，选中合法区域或布局分组后提供“添加到此处”。这些是第二区同一添加命令的就近入口，复用目标、合法项、连续添加游标和事务；浮层持续显示父级名称与插入位置。第二区入口始终可用，不能依赖悬停加号才能完成添加。

| 点击的功能 | 出现什么 | 确认后的结果 |
| --- | --- | --- |
| 添加区域 | 空白时直接添加；已有区域时显示当前区域前/后或模板末尾的落点 | 新建合法根下容器，选中“内容区域 N”，画布边界与第四区区域设计同步 |
| 添加元素 | 有名称的浮层，顶部显示“添加到：工艺区 / 文字组”，并可改目标 | 选择图片、标题、正文、按钮或适用业务元素后插入可见落点；选中新增元素 |
| 添加布局分组 | 同一浮层中的布局类，展示上下排列、左右排列、分列示意与“空分组” | 复用 Container/Grid 等合法节点生成可编辑结构；每个子组在树中可见、可命名 |
| 添加局部布局 | 生成后在目标区域的添加浮层选择适用布局，展示将添加的分组/槽位和设备排列；完整创建布局清单见创建细则 | 通过同一命令组合原生节点，一次提交、一次撤销；保留当前模板其他设计，不重新生成全模板 |
| 移动到… | 对象菜单打开目标树，只列合法、未锁定容器并显示前/后/末尾位置 | 一次移动保留节点和槽位身份，校验父子关系、循环和顺序；一次撤销还原 |
| 组合为布局分组 | 选择同一父级的对象后，在菜单显示将包含的对象与顺序 | 只在可无损表达时生成包装组；不替换槽位或猜测内容语义；不支持的选择说明原因 |

浮层目标判定顺序明确：选中合法区域/组时插入该对象；选中叶元素时显示其后同级位置；选中模板根且有多个区域时由用户选区域。无合法容器时提供“先创建区域并添加”，将包装层公开显示并合为一次操作。不能静默寻找树中第一个容器，也不能让第二次添加跑到别的区域。

连续添加沿用用户确认的目标组与插入游标，不因新元素自动被选中而跳组。关闭浮层后选中最后添加的对象；撤销只撤销对应添加事务。拖拽给出同样的目标提示与非法原因。

每次添加前重新校验会话、目标是否存在、锁定状态及合法嵌套；目标被撤销删除、锁定或会话切换后，旧游标失效。仍在原会话时保留浮层并提示重新选目标，切换会话时关闭旧浮层；失败零结构写入，不自动改投其他容器。

常用项优先图片、标题、正文、按钮；业务、媒体与复杂元素在有名称的分类中按需展开。只有定义、设计控件、页面字段、同源 Renderer 和校验都接通的能力才可用；仅有 Schema 注册不等于可供运营使用。商品槽位说明应为“页面装修时选择商品”，模板设计不打开真实商品选择器。旧固定模板不得以兼容分类或其他标签重新进入目录。

常用布局负责降低初次搭建成本：上下排列和左右两栏提供具名待填区域；左图右文提供图片组及标题/正文/按钮文字组；三列卡片提供三个独立卡片组。生成物与手动添加使用同一结构合同，可继续增删和调整。新内容槽位同步初始化页面字段、稳定标识及现行可编辑/可隐藏默认值；必填由运营明确决定，不根据名称猜测。新增字段和对应节点同属一次操作，失败不留下空壳或孤立字段。选中首个待编辑组后，后续添加仍显示明确落点。

### 4.4 构图：先分组，再排列，再调整细节

以“图片在左，标题、正文、按钮在右”为例，应能直接走通：

1. 添加一个工艺区域；
2. 在区域内建立图片组和文字组；
3. 把图片放入图片组，把标题、正文、按钮放入文字组；
4. 选区域，在第四区设“左右排列”和两组比例；
5. 选文字组设“上下排列”、间距和对齐；
6. 切移动端，区域改“上下排列”，文字组和槽位身份不变。

不能把图片、标题、正文和按钮四个同级元素一键设为横排，就声称完成了左图右文。快捷构图要显示实际参与的组；对已有复杂结构，只调整已选择且合法的组，不猜测“哪个是文案”。

普通改变排列只写设计规则，不创建或重建槽位；需要分组的动作单独说明结构影响。布局能力必须在自建原生容器上可用，不能只在旧固定模板几何覆盖上成立。

宽度、预览宽度和缩放必须分清：

- 模板/元素宽度：参与公开渲染的布局值；
- 预览宽度：模拟浏览器尺寸，普通切设备与适合画布不修改定义；若修改持久化预览元数据，放在模板设置并标出修改影响；
- 缩放：仅改变看图倍率；高度优先随内容增长，不用固定高度掩盖文字溢出。

模板整体尺寸采用以下规则，复用现有根节点响应式字段，不建立另一份画板尺寸：

- 结构区固定提供“模板整体”选择入口；选中后，属性区优先显示“模板整体尺寸与比例”。整体宽度适应页面可用空间，预览宽度不等于公开页面的固定宽度。
- 初次生成按已确认的画布宽高建立设计基准和可用的响应式规则；不得用空白模板默认值或某个局部骨架覆盖创建选择。后续局部添加保留整体高度与比例；已有草稿、已保存版本不因新默认值自动转换。
- 整体“按比例”表示优先比例，内容和最小／最大尺寸仍可能改变实际高度；界面明确“内容可增高”，不承诺严格锁定。画布按真实根高度展示，尚未测量时才使用比例参考高度；固定高度保留实际越界反馈。
- 编辑预览内的 `vh` 使用宿主提供的稳定视口参考高度，不使用随内容变化的 iframe 实测高度，避免尺寸反馈循环；公开页面没有该参考变量时遵循浏览器原生视口。
- 比例预设与自定义宽高比共用现有字段事务、校验和响应式继承；预设预览取消零提交，确认一次撤销。无效比例保留输入并就近报错，不改写定义。
- 整体比例不会自动把子区域拉伸填满。父级负责排列、空间和留白，子级按合法的尺寸方式参与布局；同轴随内容与填满空间的冲突沿用统一约束与修正提示。
- 短模板从画布顶部开始展示。窄结构栏通过减小缩进步长保留父子区别，不抹平真实层级；完整名称仍可通过名称提示与可访问标签读取。

三端共用稳定结构；新增和删除节点影响共同结构，设计操作写入明确的目标断点，实际影响按 4.4.3 的继承链计算。移动端内容顺序优先与语义阅读顺序一致，不用视觉顺序掩盖键盘/读屏顺序问题。自由叠放仅显示给支持该能力的对象，并提供边界提示；不作为普通图文制作的默认路径。

#### 4.4.1 整体边界、内部布局与图片内容

上述整体尺寸规则向内部对象延伸时，模板整体、内容区域、布局分组、内容槽位各自承担独立职责；简单构图不强制套齐全部层级。

- 比例计算使用受父布局约束后的实际宽度，缩放不参与；固定高度或尺寸上限导致内容越界时，提示被限制的对象及原因，不能通过默认裁切正文掩盖问题。
- 父级可用空间、对象尺寸方式、比例和尺寸限制共同决定结果。冲突时给出对象、约束来源及定位入口；不静默改变父级高度或清除限制。父级同轴空间不确定时，“填满”不能承诺一个确定高度；没有有效作用的选项按能力规则禁用并说明原因。
- 图片外框比例、完整显示/裁切填满和图片焦点分别表达；模板整体比例不强迫所有图片使用同一比例。必要文字被裁切与图片裁切分别检查。
- 画布根边界以实际根对象为准，越界子项参与问题提示，不反过来扩大根边界掩盖溢出。属性区区分“设置值/生效规则”与“实际渲染尺寸”；未取得测量时显示待测量或不可测量，不能用 0 或估算值冒充实测。
- 显示取整不改写原始精度；仅聚焦、失焦、缩放或测量更新不产生模板修改。空容器辅助命中区属于编辑覆盖层，不进入保存数据或公开布局尺寸。

#### 4.4.2 画布选择、直接操作与取消

画布通过鼠标表达构图意图，属性区提供相同规则的精确控制。只有当前对象、父布局、断点及权限确实支持的操作才显示手柄或命令；不得因显示了选择框就暗示全部对象可自由移动、旋转或编辑内容。模板设计的中性示例保持只读，选择文字或图片不进入真实内容填写。

| 场景 | 画布反馈与结果 |
| --- | --- |
| 选择与嵌套定位 | 悬停显示当前编辑范围内明确命中的边界与对象名，单击选择该对象；悬停或展开树不改选中。提供可见的“进入内部”、可点击父级路径和返回入口；双击/Enter 只作进入内部的快捷方式，文字叶节点不因此进入内容填写。重叠对象能经结构区或明确目标选择器定位；隐藏对象不参与画布命中，锁定对象不抢占编辑手势，但仍能从结构区定位锁定来源 |
| 移动、重排与跨组 | 松开前同时显示目标名称、容器边界/插入线及“放入此组”或“放在此对象前/后”，非法目标显示原因，无合法落点则取消。流式移动写父子关系/同级顺序，支持叠放的移动才写相对父容器的位置。坐标换算考虑画布缩放与嵌套；不把普通拖动自动转换成另一种布局或改投最近容器 |
| 尺寸、间距与图片焦点 | 预览使用真实布局约束，同步属性显示；达到尺寸上限或操作不适用时说明原因。布局转换或清除其他覆盖需提前展示关联影响 |
| 提交与取消 | 普通尺寸、间距、重排手势合法松开提交一次；图片取景、比例或布局转换的显式预览中，松开仅结束拖动，仍需“完成 / 取消”。Esc、指针取消、窗口失焦或目标失效撤回未完成预览；工具内部切焦点到选择器或完成按钮不算窗口失焦，不误取消。取消不留下半次写入、保存标记或撤销记录，此前已完成操作保留 |
| 缩放、平移、设备预览 | 只改变观察状态；不修改对象坐标和尺寸，不进入模板历史。短模板默认靠近画布顶部且水平居中，长模板顶部与底部均可到达；普通属性修改不反复触发自动居中或适合画布 |
| 进入只读预览再返回 | 临时关闭所有模板写入入口，包括结构菜单、快捷键和属性命令；允许切设备和系统场景。返回恢复对象、断点、倍率和合理滚动位置；对象已失效时定位仍存在的父级或模板整体 |

所有写入遵循同一链路：输入 → 校验对象、布局、断点和作用范围 → 操作中预览 → 提交统一模板状态 → 同步结构区、画布与属性 → 一次撤销事务 → 标记未保存。拖动期间不保存中间预览；保存、切换对象或断点前先完成或明确取消当前操作。点击、键盘和属性输入走同一校验，不维护平行结果。

空白处普通拖动用于当前编辑层的框选；进入画布平移需先激活可见的平移工具，快捷方式不能覆盖输入控件和浏览器常用操作。画布平移、框选、对象移动和尺寸调整同一时刻只运行一种操作，未达到拖动阈值不改结构；阈值按交互实现与测试校验，不写成模板属性。选中屏幕外的可见对象时才按需滚入视野，悬停和反复调属性不引发自动跳位。

多选显示实际参与对象；同一父级及其后代不能在一次结构移动、复制或删除中重复处理。组合为布局分组沿用 4.3 的同父级条件，跨父级的共同属性编辑仍按 4.5 判断。框选或属性批量设置不等于支持整体移动、旋转或缩放；只有变换规则、约束、撤销与 Renderer 同时接通的能力才显示对应手柄。

画布上的手柄表达以下设计意图，与第四区共享字段、适用范围和校验；不得另存一份仅在画布生效的几何值：

| 操作位置 | 写入含义与反馈 | 操作边界 |
| --- | --- | --- |
| 对象边框 | 调整该对象支持的宽/高，显示尺寸和单位；若从随内容/填满改为固定，操作中明确提示方式变化 | 不批量改写字号、边框粗细或子对象尺寸；子对象按原父子约束自然响应和回流。不擅自删除 min/max；取消恢复尺寸及原方式 |
| 两列分隔线 | 调整所选父组内的列宽分配，显示两侧分配及实际结果 | 保留父组宽度、间距、槽位身份和内容；不能把分隔线当成整张模板比例柄，不支持的列模式说明原因 |
| 同级对象间隙 | 调整父组对应轴的对象间距，提示影响哪些同级对象 | 不能通过偷偷移动单个对象模拟 gap；自动分配、不同单位或不适用模式有明确处理，不能静默转成 px |
| 容器内侧边缘 | 调整该边内边距，标出上/右/下/左及联动范围 | 向内拖动增加留白；无四边联动时不改其他边；不得混同子对象外边距 |
| 预览画面外边缘 | 改变承载模板的预览宽度，并显示当前内容断点 | 不修改模板根宽度、历史或未保存状态；画板边缘与对象尺寸柄必须有不同标签 |

图片使用独立的“调整画面”操作：进入后保持外框不变，提供完整显示/裁切填满、适用焦点及完成/取消；调整写图片展示规则，不裁切源文件，不替换真实内容。无图时仍可改外框和适配规则，但焦点不可伪装为已有可见效果；焦点仅在当前适配与图片几何确实产生作用时启用。确认一次撤销恢复整个取景操作，内部切换适配方式不拆成多条历史。

画布覆盖层只展示当前对象和当前操作所需的控件。手柄视觉大小与可点击热区分开处理，缩放到 50% 时热区仍按编辑器屏幕上的 CSS 像素满足 UI_GUIDE；热区不能吞掉相邻选择、插入和完成按钮。对应的数值输入、步进或移动菜单必须可点击且键盘可达，不以快捷键代替全部非拖拽路径。

普通选中先显示对象尺寸和支持的边/角柄；边柄分别表达宽或高，角柄表达宽高，悬停或键盘聚焦时提前说明固定尺寸及作用范围。流式对象的移动说明为排序或移入容器，自由叠放对象说明为位置调整，沿用真实落点和取消反馈。列分隔线显示相邻两列各占总可分配列宽的百分比，比例随预览更新，细线之外保留可命中的拖动区域。

间距通过画布现有操作栏的“调整间距”显式进入；该状态显示四边内边距与适用的同级间距，暂时隐藏尺寸、移动、列分隔线和取景控件。标签常显名称、数值、单位和方向；靠近画布边缘时不能被滚动容器裁切。悬停、聚焦或拖动突出对应留白区域，向内拖动增加该边留白，键盘只处理当前轴。单击标签可输入精确值，复用统一数值校验与提交保护：应用一次提交，取消保留原值；切换对象、断点、比较视图或完成间距前先处理输入，非法值阻止切换并返回输入焦点。选中对象或设备改变后回到普通选择，不把间距工具状态存进模板定义。

#### 4.4.3 三端继承与结构作用范围

V2 沿用当前响应式解析规则：Desktop 为基础，Tablet 叠加自身覆盖，Mobile 在 Desktop 与 Tablet 的结果上叠加自身覆盖；字段按合同规定的属性粒度合并，不保存三份独立完整模板。旧版本按其版本规则读取，不因本节自动迁移。

字段说明必须区分“继承自桌面/平板”“本端独立设置”“系统默认”和“尚未保存”。改桌面基础会影响没有独立覆盖的下游设备，改平板可能影响继承它的手机；单项“恢复继承”只移除该项本端覆盖，按当前解析链重新取值。跨端复制列出目标设备、属性组及覆盖移除范围，预览和确认实际写入完全一致，一次撤销恢复全部关联变化。

“恢复系统默认”仅对允许清除的桌面基础属性取合法默认值；“恢复最近保存值”读取当前模板对应范围的成功保存基线并保留继承意图；两者不能统称“恢复”。复制另一端设置写入当时所选属性的有效值，不建立持续关联。同值不同来源的多选显示“多个来源”，不能伪称统一继承。

新增、删除、改父级及结构树排序改变共同结构；仅本端布局顺序调整必须使用明确的本端命令，并继续满足阅读与键盘顺序规则。预览宽度用于解析当前内容断点，与编辑器四区转为抽屉的界面断点是两套用途，不可混淆。

默认聚焦一个设备编辑，三端并排用于只读比较同一模板与同一系统场景；视图容量不足时允许在画布区内滚动查看，不能改变四区比例或把三个画面压缩到无法辨认。比较态允许选择对象，所有画面与属性均不写设计值。从编辑态进入比较可用“聚焦该端编辑”，明确退出比较、激活该端并保留对象；从顶部只读预览进入比较则使用“聚焦该端查看”，继续保持只读，进入编辑须明确退出预览。进入比较前按 7.2 处理输入，取消/返回恢复原设备与合理滚动位置；主动聚焦另一端则保留用户新选择。

拖动预览宽度跨过内容断点时，当前断点提示与属性作用范围同步更新。进行中的设计手势以开始时的对象和断点为准，不能在途中偷偷改投新端；预览宽度切换需先完成或取消该手势。手机上的结构移动仍提示影响共同结构，不为实现“仅本端”自动增加其他端的隔离覆盖。

### 4.5 第四区：选中什么，就显示什么

生成后的微调按[总标准功能清单](template-creation-rules.md#92-第二阶段微调功能清单)验收：默认文案、默认图片与常用视觉参数是第二阶段的直接入口；更多参数按对象展开。下表说明设计属性与页面开放范围的分工，不限制总标准要求的默认图文编辑，也不另立一组微调预设值。

属性面板固定保留对象名称、路径、当前设备、作用范围；正文使用“设计”和“页面开放范围”两项任务入口。“页面开放范围”不得藏在“模板资料”或不相关的错误详情中；模板元资料从“模板设置”进入。常用字段不需要二次展开，精确项只使用一层有名称的展开组。

| 当前对象 | “设计”默认显示 | “页面开放范围”显示 |
| --- | --- | --- |
| 模板根 | 画布尺寸与比例、背景、整体留白、模板设置入口 | 全部字段摘要、页面字段查看、缺项与冲突定位 |
| 区域/布局分组 | 排列、分列比例、对齐、内容间距、内边距、宽高 | 下属开放字段摘要与该容器已有的适用覆盖；不生成虚假的区域正文 |
| 图片 | 默认图片、填充与比例、适用取景入口及外框属性 | 页面字段名称、必填/可选、可隐藏、图片适配与焦点等适用覆盖 |
| 标题/正文 | 默认文案、字号、字重、颜色及适用文字排版 | 页面字段名称、必填/可选、当前合同支持的长度限制和字体覆盖 |
| 按钮/商品等 | 按钮默认文案、文字色/背景色和尺寸策略；业务对象只显示其支持的设计属性 | 页面行动或业务引用要求、适用字段摘要；不选择真实链接或商品 |
| 锁定/隐藏对象 | 显示现状、锁定来源与解除锁定/定位上级入口 | 可读规则；可否修改仍由对象锁与权限决定 |

“设计”首屏及后续分组统一按[总标准第 9.5 节](template-creation-rules.md#95-功能区域默认呈现就近操作与返回路径)排序：布局组先排列、对齐与间距；图片先默认图片、填充与比例；文字先默认文案、字号与颜色；按钮先默认文案、颜色与尺寸策略。当前设备和修改范围保持可见，但只占一条紧凑状态区；断点显隐、继承说明、跨设备复制、尺寸限制、背景边框和结构锁定放在适用对象的高频组之后，并以摘要按需展开。不得让响应式说明、重复来源文字或试排内容挡住当前对象的第一组常用控件。

控件按真实能力出现：流式对象不显示无效的 X/Y；图片焦点只在该适配方式有作用时启用；列宽只在分列状态出现；多选只编辑共同属性并显示混合值。连续编辑值、取消、恢复和历史语义按第 8–9 节。

多选先显示总数、可修改数及排除原因；锁定或不支持的对象不能悄悄混入批量写入。共同属性还须满足所有参与对象的单位、枚举与数值约束交集；没有合法交集时禁用并说明。混合值不是空值或 0；未修改的字段保持各自原值。按已展示范围一次校验、原子提交和撤销，提交前对象或约束变化则重新计算，不能悄悄部分成功。

“不适用”属性可隐藏；当前本可适用、但因上级锁定或约束冲突暂不可编辑的属性，保留必要的值、原因与修正入口。同一种对象的常用组顺序稳定，不因刚改过某字段自动重排；高级组仍显示错误和未保存变更摘要。

### 4.6 页面开放范围：让设计者看到交付给运营的表单

“页面字段名称”是实际页面 Inspector 的标签，例如“工艺主图”“工艺标题”。内部 nodeId、slotId、key 由系统维护；改标签不改身份，复制生成新身份。节点名称用于结构管理，字段名称用于页面填写；只有用户主动修改时才分别覆盖，不在每次更名时偷偷同步另一者。

普通新内容槽位推荐“页面可填写、可选、结构及布局受控”的起点；需要必填、可隐藏或开放额外样式时在这里明确设置。已有模板按其版本读取，不能通过新默认值改写旧规则。

每项规则提供可操作的关联反馈：

| 规则或冲突 | 处理方式 |
| --- | --- |
| 设为必填但不可填写或可隐藏 | 显示冲突项及“允许填写并关闭隐藏”动作；说明并原子应用，不悄悄改其他开关 |
| 内容只读且没有合法来源 | 说明槽位将无法获得有效内容，定位到对应规则；新版本合法默认内容按模板设计标准 9.1 解析，系统示例不能补空 |
| 可选内容为空 | 按现有空策略隐藏/折叠并检查父组留白；不回填模板示例 |
| 修改长度、尺寸或媒体约束 | 同时展示作用端和限制单位；最小值不得大于最大值；条件消失不丢合法值 |
| 想删除自建必填槽位 | 必填约束用于页面内容，不等于永不可改模板；提供“取消必填并删除”的明确影响确认，两步作为一次原子操作、一次撤销恢复；仍按操作合同检查锁定与固定角色，取消零写入 |
| 内置固定角色或上级锁定 | 显示真实来源与限制；普通“取消必填”不能解除固定业务角色或越过权限 |

“查看页面字段”在第四区显示只读表单形态：按实际页面适配器顺序列出字段标签、控件类型、必填与限制、是否开放设计覆盖；点击字段定位模板对象。该视图复用页面字段模型，但不创建真实页面、不保存样例输入，也不与页面独立会话合并。可编辑填充测试在专用页面草稿执行。

“内容可编辑”“页面可隐藏”“设计时结构锁定”和“本端是否显示”是四个不同概念，文案不能共用一个“锁定/隐藏”开关。解除自己设置的锁和定位上级锁必须始终可达；锁定不能造成不可解锁的死路。

结构树命令使用“全局隐藏 / 取消全局隐藏”，注明影响所有设备；断点属性使用“当前断点显隐设置”，并按 4.4.3 展示写入设备及可能继承此设置的下游设备。二者不清除对方的合法设置，取消一层隐藏不承诺已经可见。对象最终不可见时显示真实来源，全局或上级隐藏优先；树中保留隐藏对象的定位与恢复路径，操作前说明是否影响子树。页面人员是否可隐藏内容继续由槽位开放规则决定，不能被设计时显隐开关替代。

### 4.7 预览检查：分别检查结构韧性与页面内容

点击顶部“预览”后进入当前模板的只读预览状态，第三画布区保留设备与缩放；第四区显示场景选择和返回入口。系统场景包含正常短文、长文、可选内容缺失、必填内容缺失、不同媒体比例。场景切换不写入定义、不进入编辑历史，也不改变保存状态。

**必填内容缺失的场景用于检查空态和提示，不能因为模板没有真实内容就阻止模板发布。** 模板发布检查结构、槽位与可编辑声明是否可用；页面发布才检查具体实例必填内容、业务引用与链接是否有效。长文超出声明最大值时测试页面校验，长文在声明范围内却被裁切时检查设计；两类问题不能混为一条“内容不合格”。

自动检查只报告当前确实运行的规则；设备切换一次不等于已检查响应式，看到截图不等于内容符合全部无障碍要求。人工检查项目显示“待核对”，不能自动变绿。Schema 3 的合法默认图文在属性中编辑并随定义保存，系统示例和临时压力试排不得混入默认内容；旧版本按其兼容规则读取，具体见 [模板设计标准 9.1](template-creation-rules.md)。

系统场景、临时压力试排、模板默认图文和页面真实内容分别标明来源与写入范围。修改默认图文是正常属性编辑，进入当前模板历史；临时试排只是检查，不更新默认内容或页面。图片外框、适配和焦点是可保存的设计规则，不能与替换默认图片混为一次无说明的操作。

### 4.8 保存、发布与下一次修改

保存与发布入口使用动作名称：“保存草稿”和“发布模板”。不把执行发布的按钮命名为“用于页面”；“去页面装修使用”只出现在发布成功之后。

| 点击与状态 | 出现的视图/反馈 | 写入结果与下一步 |
| --- | --- | --- |
| 保存草稿 | 原位保存状态；首次必要资料在第四区定位补齐 | 基础结构与安全校验通过即可保存未完成创作；保存成功保留当前选择，显示保存位置与时间 |
| 发布模板 | 第四区进入“模板发布检查”，列模板名、保存状态、目标版本与适用范围；问题可定位 | 首次点击只检查，不直接发布；已有合法草稿不因打开检查而被改写 |
| 检查有问题 | 按对象显示“问题—影响—去修改”；返回后保留检查上下文 | 结构非法等真实阻断禁用确认；质量建议与待人工核对分开，不私自提升门禁 |
| 检查可提交 | 末端显示“保存并发布模板”或“发布模板新版本”，说明现有页面仍锁原版 | 明确确认后保存必要修改，再针对同一保存版本执行发布；保存失败停止发布 |
| 保存成功、发布失败 | 分开显示“草稿已保存 / 模板未发布”，保留错误与重试入口 | 不把部分成功写成已发布；可继续编辑或重试 |
| 请求期间又有修改/对象变化 | 显示“本次检查已过期，请重新检查”，保留新输入 | 不发布新输入未核对的版本，不把其标成已保存 |
| 发布成功 | 显示服务端确认的版本、保存结果、“继续设计”和“去页面装修使用” | 更新目录可用性，不自动插入页面；目录刷新失败标记重试，不伪报发布失败 |
| 发布响应不确定 | 显示“正在核对发布结果”，查询当前身份和版本 | 未确认前不盲目重复创建版本；保留草稿 |
| 编辑已有已发布模板 | 显示“基于 vN 编辑草稿 / 已发布 vN”，版本目录同时保留 | 新改动只属于模板草稿；只有下一次明确发布才产生新版本 |

模板设计能力保持当前权限约束，前端隐藏命令不能代替服务端授权。只有本机测试存储时显示“保存本机草稿”，不得冒充可供其他运营人员选用的服务端模板，也不能显示发布成功。

模板设置与命名是可回访的普通编辑。新建按七步生成，列表复制普通模板产生独立身份并保护来源；不增加导入旧格式或从页面提取真实内容生成新身份的旁路。重开证明保存闭环，目录可选和页面实际字段可用共同证明交付闭环。

### 4.9 从预设生成到可使用模板的运营流程

第一阶段按七步完成必要选择，点击预设即在方案画布中呈现。第二阶段按需选择对象、使用快捷值或精确输入、增补或删除元素；第三阶段预览检查并保存，可返回第二阶段继续修正。发布时再按独立交付流程检查页面填写方式、补齐必要资料并明确发布；普通微调与保存不以完成发布准备为前提。后续编辑不强制重走创建步骤，也不要求为简单内容建立无用途分组。

运营负责布局意图、字段含义、必填要求和实际效果；系统负责稳定身份、合法嵌套、字段初始化、派生摘要、响应式继承和机器校验。模板设计中的样例继续遵守 4.7 的只读边界。

保存草稿入口在生成后的编辑阶段持续可用，只按基础结构、输入和当前事务状态判断是否可以保存；创建阶段的临时方案不冒充已保存模板。制作建议、人工检查完成度与发布门禁分别显示。设备查看、选中和缩放不形成内容修改，发布检查不因新流程而跳过校验。

工艺图文样例的最终结构为：

```text
模板根（系统管理）
└─ 工艺介绍区域
   ├─ 图片组
   │  └─ 工艺主图
   └─ 文字组
      ├─ 工艺标题
      ├─ 工艺说明
      └─ 咨询按钮
```

运营制作按下列意图组织，可反复调整、随时保存，不按步骤完成率锁定工具：

| 运营意图 | 主要入口与反馈 | 得到什么 |
| --- | --- | --- |
| 开始构图 | 七步选择类型、画布、布局、图片、内容、样式并确认 | 先看到完整基础结果，区域、组与槽位可选；不依赖逐个拖入元素才能使用 |
| 添加图片与文字 | 第二区或画布就近入口持续显示目标组与位置 | 新对象自动选中，连续添加不跳组；真实内容不在这里填写 |
| 调整构图 | 拖列分隔线、对象尺寸、间距或留白；第四区精确输入 | 看到被修改的规则、影响对象及实际结果，可取消和撤销 |
| 调整图片取景 | 进入图片“调整画面”，完成后返回普通选择 | 外框与图片显示分别可控，取消恢复原取景 |
| 适配不同设备 | 单端聚焦调整，三端比较检查 | 共享结构稳定，覆盖来源和下游影响清楚 |
| 检查运营填写结果 | 页面开放范围、只读页面字段查看、系统长文/缺图场景 | 字段可理解，问题能定位；返回后保留原对象继续修正 |
| 保存与交付 | 保存草稿、重开、发布检查与明确发布；页面侧显式选用版本 | 保存、发布和页面使用结果分别可确认，失败不丢编辑内容；验证仍分轨道执行 |

制作成功要看到正确分组、连续添加目标稳定、三端构图成立、字段可理解、空态不崩、草稿重开一致、发布目录可选和页面消费一致。这个例子不能变成所有模板必须具备图片、文字、按钮、两组结构或两区域的固定标准；具体运营走查见 10.5。

交付检查至少呈现页面装修使用者将看到的字段名称、阅读顺序、必填、可编辑和可手动隐藏状态；描述符与页面实际表单共用来源。这里的“页面不可手动隐藏”不等同于永远可见，模板设计显隐、设备显隐与内容缺失仍分别处理。查看和定位表单不修改样例或模板定义。

## 5. 页面装修工作流

页面装修以一个具体页面和语言为上下文，目标是使用已发布模板完成真实页面。普通换图、改字、选商品和调整已开放属性不要求切回模板设计。

### 5.1 打开页面与恢复上下文

进入页面装修后持续显示页面名称、语言、页面草稿状态和当前设备。打开页面时区分：

- 已保存草稿；
- 线上版本；
- 没有草稿；
- 读取失败；
- 并发冲突或无权限。

系统不得用 seed、旧缓存或线上副本悄悄替代读取失败的草稿。用户主动查看线上版本后，返回时恢复原编辑上下文。

### 5.2 选择并插入模板版本

页面模板目录的可插入项只包含当前身份可使用的系统项和已发布版本。目录项说明名称、用途、版本和可用性；同一模板有新草稿时，仍可插入其已有发布版本。无发布版本的草稿若展示，应明确不可插入，不将管理状态当成可用版本。

“预览”和“添加”是两个动作。预览不写页面；添加前需要明确插入位置，完成后在图层中新增一个页面实例并立即选中。点击添加与拖入画布消费同一合法性和固定业务区校验，拖拽不能成为唯一完成方式。

页面实例锁定精确 `templateId + templateVersion`。插入不得复制模板的系统示例或旧默认内容；真实内容按槽位保持为空或按兼容合同处理。

### 5.3 填写真实内容与业务引用

页面属性面板按当前模板的运营任务组织，内容优先于设计覆盖。以下是分组清单，显示顺序沿用实际页面适配器，按当前内容任务确定，不强制所有模板使用同一种媒体/文字顺序：

1. 当前实例与模板版本；
2. 图片、视频等媒体；
3. 标题、正文等文字；
4. 商品、系列、门店等稳定业务引用；
5. 链接、按钮与转化目标；
6. 显隐和模板允许的设计覆盖；
7. 模板版本状态与升级入口。

字段名称来自模板开放声明，不能暴露 nodeId、Schema 路径或内部类型作为主要标签。业务引用保存稳定身份，价格、库存、订单、支付和客户数据继续由各自业务源解析，不能复制进模板或页面正文。

字段因条件、设备或选择暂时隐藏时保留合法输入；重新显示后恢复。必填、推荐和真实发布阻断使用不同严重级，不以“未填写”统一阻止保存草稿。

### 5.4 管理页面实例

页面图层以页面区块和模板实例为结构操作对象，提供选择、排序、显隐、复制和移除；母模板内部对象只用于定位开放字段，不允许改写内部树。

页面级“恢复模板值”只删除对应实例覆盖并读取当前锁定版本，不清空真实内容、不升级模板版本。固定业务区、页面根角色和权限限制必须同时作用于图层菜单、快捷键、画布和 Inspector。

### 5.5 预览、保存与发布

- 当前编辑预览包含本会话未保存修改，切设备与预览不触发保存。
- 独立草稿预览读取服务端已保存草稿；没有草稿和读取失败分开反馈。
- 查看线上版本只读，不把线上副本自动保存为草稿。

页面可以随时保存合法草稿。发布前检查页面身份、语言、模板引用、必填内容、业务引用、固定区域、链接和适用质量门禁；问题能跳回对应实例或字段。`EDITOR` 只保存、预览和提交，`ADMIN` 与 `SUPER_ADMIN` 才能发布。

发布失败保留输入并说明恢复动作；并发冲突不能自动覆盖他人修改。发布成功只更新当前页面与语言的发布指针，不改变母模板或其他页面。

## 6. 模板版本交接与升级

模板发布与页面发布之间只有以下受控交接：

1. 模板草稿发布为不可变 v1；
2. v1 进入页面可用目录；
3. 页面插入 v1 并锁定身份与版本；
4. 模板继续编辑并发布 v2；
5. 使用 v1 的页面保持原渲染；
6. 页面明确发起升级，查看差异；
7. 确认后只修改页面草稿；
8. 页面重新发布后才对外使用 v2。

升级预览至少区分：

- 能按稳定槽位身份保留的真实内容；
- 新增、删除或无法映射的内容槽位；
- 桌面与移动布局变化；
- 页面开放范围变化；
- 将被删除、保留或重新校验的实例覆盖；
- 阻断、警告和不受影响项。

不能凭显示名称相同迁移内容。取消升级保持原版本、真实内容和覆盖完全不变；确认升级只产生页面草稿和一条可撤销历史，不自动保存或发布。

版本检查必须区分“已核实为最新”“发现新版本”“目录当前未提供可升级版本”和“检查失败”。目录没有当前模板不等于已是最新，也不等于精确历史引用已经失效；归档模板仍按历史读取和公开门禁处理。

有权限的“把页面设计覆盖应用到母模板草稿”只更新当前实例所引用的同一 Repository 模板，不创建新身份。它只能提取当前合同能无损表达的设计字段，先展示可应用、保留、冲突和排除项；真实内容和业务引用永不进入母模板。结果是该模板的一次未保存草稿修改，不自动保存、发布、升级页面或更新线上结果。

## 7. 固定四区的模式化分工

模板设计各区默认内容、对象属性顺序、添加后的去向及空态/锁定/检查返回等行为以[总标准第 9.5 节](template-creation-rules.md#95-功能区域默认呈现就近操作与返回路径)为准。本节只展开既有外壳和页面装修差异，不另立一套编辑入口或属性排序。

桌面 `>=1200px` 保持唯一固定比例：模板组件库 `12%`、图层/结构面板 `8%`、画布 `60%`、属性面板 `20%`。不得按模式改变比例、允许拖拽改宽、持久化个性宽度或收起面板。`<1200px` 按现有覆盖式抽屉合同处理，不写回桌面布局。

| 区域 | 模板设计 | 页面装修 | 必须保留的边界 |
| --- | --- | --- | --- |
| 模板组件库 12% | 模板列表：新建、切换、复制、重命名、删除、搜索、状态与回收站恢复 | 使用目录：浏览、筛选、预览、点击或拖入已发布版本；草稿不可插入 | 第一区管理模板身份，不混入区域与槽位节点工具；未保存会话不冒充目录记录 |
| 图层/结构面板 8% | 模板结构：添加区域/槽位、查看树、定位问题、排序、缩进、复制、锁定、显隐、删除 | 页面图层：页面实例顺序、显隐、固定区保护；内部对象只定位 | 模板节点工具位于结构区；页面不能改母模板内部树 |
| 画布 60% | 生成结果查看、选择、移动、缩放、对齐、复制、删除、层级与布局微调；同源预览 | 真实页面内容、页面实例选择、插入位置与编辑/只读预览 | 画布承担查看与调整；编辑态不误触公开链接，预览态不写入 |
| 属性面板 20% | 主要精调入口：所有适用生成值、对象身份、默认图文、布局、响应式和页面开放范围 | 页面属性：真实内容、业务引用、显隐、受控设计覆盖和版本升级 | 选中对象决定调整范围；预设外合理值可输入，不适用项隐藏 |

区域正式标题沿用 UI_GUIDE 的“模板组件库、图层面板、属性面板”，不按模式改名。模板结构、页面图层、模板属性和页面属性作为标题下的上下文、副标题或首个分组呈现，不能替换区域名、另造第五种区域或暗示错误写入对象。

### 7.1 顶部工具栏

顶部是共享外壳中的模式化命令区，不是第五个功能区，也不是一套混合命令：

- 公共信息：模式切换、当前对象、设备、未保存/保存中/失败/已保存状态。
- 模板常驻命令：模板撤销/重做、设备、预览、保存草稿、发布模板；“新建模板”统一打开七步流程，可在模板组件库和响应式顶部入口呈现。复制、重命名和删除位于明确对象的列表菜单，模板设置与版本历史从“更多”进入；不增加旧格式导入或页面内容反向提取旁路。示例场景位于预览检查中，不把所有能力挤成一排按钮。
- 页面命令：页面撤销/重做、页面预览、保存草稿、查看线上、页面历史、预检、发布页面。

切换模式后不属于当前对象的命令必须消失或明确禁用，不能仅更换按钮文字却复用错误保存对象。顶部不放字号、间距等对象属性；拥挤时按 UI_GUIDE 处理分组和断点，不能挤掉对象身份与保存状态。

### 7.2 选择、焦点与窄面板

结构树、画布和属性面板共享当前模式内的同一选择。点击树行选择对象，展开箭头只处理展开；新增、定位错误和返回预览后恢复合理焦点。切换对象、设备、模板或模式，进入临时视图，以及保存或执行模板撤销前，都先处理当前字段输入：普通即时字段的合法待提交值提交一次；非法值保留并就近提示，允许明确取消后继续原动作，不能静默取消、强行提交或把值写入新对象。草稿已提交但未保存的保护与字段尚未提交的保护分别处理，不能用一次 dirty 检查替代两者。

上述收尾也覆盖切换“设计/页面开放范围”和收起当前字段组。需要显式确认的比例、布局转换或跨端复制预览必须明确完成或取消，不能以合法失焦冒充确认。多选身份更名不使用通用批量属性入口；节点名称与页面字段名称仍按单选规则分别编辑。

8% 结构区不在每行堆放多个图标、计数和按钮。深层结构使用查找、聚焦分支、父级路径和“返回全树”，不删除真实层级。完整名称、路径和不可执行原因由属性面板承载；截断名称仍可通过键盘聚焦获得详情。

查找仅改变树的展示，显示匹配对象及必要祖先；聚焦分支保留父级返回路径，不改变真实层级、选择身份或画布结构。压缩缩进、隐藏装饰图标不能消除展开、对象菜单和非拖拽移动入口；长名省略后仍能辨认对象类型及获取全名，不能仅依赖悬停提示完成操作。窄屏抽屉的打开、关闭和跨断点返回同样保留当前对象与未提交输入；没有有效返回触发器时回到所属区域入口。

20% 属性区采用单列为主，只在标签和值仍清楚时并排。对象身份和作用范围固定可见，正文按当前任务分组，使用一个主要纵向滚动容器，避免每个字段组嵌套滚动；错误靠近字段，跨对象问题集中在检查视图并能回到对象。

### 7.3 运营步骤与四区响应

模板设计的具体点击、浮层、字段和返回行为只维护在第 4 节。第一区稳定承载目录；第二区承载结构添加与管理；第三区承载构图及预览；第四区在对象属性、模板设置、页面字段查看和发布检查之间切换。临时视图不修改四区比例，也不创建永久的第五区。

页面装修延续相同空间记忆，但功能围绕页面实例和真实内容变化：

| 页面装修步骤 | 模板组件库 | 图层面板 | 画布 | 属性面板 |
| --- | --- | --- | --- | --- |
| 选择模板版本 | 筛选、查看状态并打开只读预览 | 页面原结构不变 | 预览不写入页面 | 显示用途、版本与可用性，不出现母模板结构表单 |
| 添加到页面 | 保持所选模板和版本 | 在明确位置新增并选中页面实例 | 显示实例及待填写状态 | 直接进入当前实例的内容任务 |
| 填写内容 | 目录不抢占焦点 | 内部对象仅用于字段定位 | 实时显示真实内容 | 按媒体、文字、业务引用和行动目标填写 |
| 排序与实例调整 | 保持上下文 | 管理页面实例顺序、显隐和固定区限制 | 同步显示落点与结果 | 只显示模板开放的实例覆盖和恢复入口 |
| 预检/发布页面 | 保持已用模板身份 | 问题实例可定位 | 编辑预览、草稿预览与线上查看明确区分 | 临时进入页面检查；失败能返回字段且内容不丢失 |

同一动作即使在画布和图层各有就近入口，也必须调用同一命令、权限和校验；不得为方便摆放而维护两套结果不同的业务逻辑。

### 7.4 视觉与信息密度

- 画布是唯一主要视觉焦点；工具区使用克制的中性表面和清楚边界，不与珠宝页面内容争夺注意力。
- 每个区域首屏突出当前任务的主要动作，同时保留常用操作；创建时突出当前步骤预设和方案预览，生成后选中对象突出对应属性；手动删空或已有空区域提供添加恢复入口，错误状态突出修正与定位。
- 不给每个字段套卡片、阴影和重复标题。一个属性组只解决一个问题，标签贴近控件，单位与值放在一起。
- 图标用于辅助识别，关键模式、对象、状态和动作保留文字；不能在空间紧张时只留下无名称图标。
- 顶部状态、对象身份和发布影响持续可见；解释性长文只在首次空态、帮助或明确失败时出现，不占用日常编辑空间。
- 直接编辑边界、插入线、选中框和手柄避开正文与主要视觉内容；工具遮挡时应调整位置，而不是缩小点击目标。

## 8. 交互、反馈与可访问性

- 首次创建按七步呈现决策，可返回修改，选择即更新临时画布，确认后生成；进入编辑后“添加 → 选中 → 调整 → 查看结果”可以反复进行，不按向导完成度锁住工具，也不要求重走向导才能局部调整。
- 添加、排序、缩进、尺寸和位置调整都必须有可点击的非拖拽完成方式，并独立检查键盘路径；仅有快捷键不等于单指针替代。拖拽与点击命令使用同一合法性判断。
- 指针操作目标及间距遵守 UI_GUIDE 和适用 WCAG；主要动作不能只依赖悬停出现。
- 选中、悬停、锁定、隐藏、已修改、错误和焦点状态不能只用颜色区分。
- 聚焦控件不会自动切换模式、打开模板、插入页面或触发发布；需要用户明确激活。
- 数值输入允许暂时不完整的编辑态。Enter 或有效失焦提交一次，Esc 恢复本次输入前值；非法值就近说明并保留可修正输入。
- Esc 优先结束最内层操作：字段输入、进行中的手势或临时浮层先处理，不能同一次按键又取消输入又退到父级。输入控件聚焦时，Delete、方向键和文本撤销遵守输入语义，不能同时删除/移动模板对象；离开输入后模板撤销按第 9 节执行。
- loading、empty、error、success、无效引用、并发冲突和发布阻断分别表达，不能用空白或通用“失败”覆盖。
- 正常编辑不堆叠“结构正确”“合同通过”等成功说明；保存状态集中在顶部，字段问题就近，跨对象问题进入检查视图。

## 9. 操作语义

| 动作 | 明确结果 |
| --- | --- |
| 撤销/重做 | 只作用于当前模式的当前模板草稿或页面草稿历史；不按选中的节点分成私有历史。切换节点后仍能撤销上一节点的最近操作；选择、搜索、展开、缩放和只读预览不占模板撤销记录 |
| 模板“恢复最近保存值” | 恢复当前模板最近一次成功保存的草稿基线；没有基线时不伪造默认值 |
| 页面“恢复模板值” | 删除所选实例覆盖，重新读取页面锁定版本；不清内容、不升级版本 |
| 复制另一端所选设置 | 只复制已选择的适用设计组；不复制真实内容，不建立隐式继承 |
| 移除节点或实例 | 只改变当前草稿并可撤销；不删除目录记录或历史版本 |
| 新建模板 | 七步选项与临时画布预览，明确确认后产生独立身份的完整未保存草稿，不自动保存或发布 |
| 复制模板 | 将明确选定的普通模板草稿/版本复制为独立身份的新草稿，来源不变，不复制页面实例真实内容 |
| 发布模板 | 创建不可变模板版本并更新模板目录；不改变页面 |
| 替换模板 | 先展示内容、布局和开放范围差异；确认后只改变页面草稿 |
| 升级模板版本 | 从当前精确版本迁移到所选新版本；取消零副作用，确认后仍需保存和发布页面 |
| 查看线上版本 | 只读比较，返回原编辑会话；不自动恢复或覆盖草稿 |

普通可撤销调整不重复确认；丢弃修改、覆盖目标、跨版本迁移、归档和发布等具有明显后果的动作才使用与风险相称的确认。确认文案必须写清对象、版本和影响，不能只问“是否确定”。

## 10. 可观察验收

验收分成三条独立业务轨道和一条交互轨道，不能用一条混合脚本替代。

### 10.1 模板设计轨道

- 新建先通过[创建细则 §11](template-creation-rules.md#11-最低质量与可观察验收)验证全部选项、操作次数、实时预览、生成质量与可编辑性；未命名的合法编辑草稿可主动保存，查看检查不自动记为完成，未满足发布要求仍被阻止。
- 上下排列、左右两栏、左图右文、三列卡片生成合法且具名的原生结构；后两项同步生成对应页面字段。生成保留整体规则、稳定模板身份和空内容来源，一次撤销完整还原。
- 常用布局在不接受其首节点的父级明确禁用；目标失效、上级锁定或会话变化后不改投别处。取消选择零内容写入，手机/平板查看不增加历史。
- 交付字段预览与实际页面描述符的顺序、标签和编辑规则一致，定位不会改写样例。制作建议与顶部发布入口都能打开明确的版本检查，首次点击零发布写入。

按第 4 节逐项核对触发入口、点击后的界面、作用对象、退出与写入结果。下列场景用于专用测试模板，不触碰用户未保存草稿，也不要求每个生产模板具有相同构图。

| 场景 | 必须证明的结果 |
| --- | --- |
| 七步新建与未保存切换 | 预设选择更新方案画布，确认前不创建；生成完整基础结构且不自动持久化；取消与失败保护来源，编辑草稿按基础校验保存 |
| 添加到两个不同区域 | 浮层目标与实际父级一致；连续添加留在所选区域；根下有多个区域时不自动选择第一个；非法落点取消零写入 |
| 左图与文字组 | 从原生节点建立两组，文字组容纳标题/正文/按钮；移动槽位无需旧模板角色；切排列不重建内容身份 |
| 分组/移动失败 | 拒绝循环、非法嵌套、锁定目标；不留下空包装和半次操作；一次撤销回到原结构 |
| 不同对象的属性 | 选区域、组、图片、文字、锁定和隐藏对象时各显示适用字段；非法数值不丢失，不提交到新对象；锁定可定位并解开 |
| 页面开放范围 | 可一步进入相关规则；必填/可填/可隐藏冲突有明确处理；改字段标签不改稳定身份；页面字段查看与实际页面适配器一致 |
| 三端与示例 | 桌面左右、移动上下，平板按当前规则参与继承；结构变更影响共同结构，样式写入明确目标端并按继承链影响下游；示例/缩放不进入保存请求或历史 |
| 空内容责任边界 | 缺必填的系统示例不因为“缺真实内容”阻断模板发布；缺必填的真实页面实例按页面发布门禁处理 |
| 发布前确认 | 打开检查零发布写入；保存并发布使用同一已检查草稿；检查后修改令结果失效；固定业务区限制与角色权限保持 |
| 保存、发布与重试 | 重开数据一致；保存成功发布失败清楚区分；不确定响应先查证；确认成功且目录刷新失败不重复发布 |
| 再次迭代 | 发布版本不可变；v1 与同一模板的新草稿并存；历史版本只载入当前身份；页面继续锁旧版直到显式升级 |
| 目录与编辑对象分离 | 搜索排除当前模板、目录读取失败或另一模板加载失败时，现有草稿、选择和未提交输入仍保留；查看已发布版本不载入覆盖草稿 |
| 整体尺寸与空容器 | 根比例、固定/随内容、尺寸上限、长文和不同媒体比例符合 4.4.1；越界提示可定位，空容器可选且辅助命中区不进入公开布局 |
| 直接操作中断 | 在缩放与嵌套容器下操作，预览与提交一致；Esc、指针取消及切换前取消不留下半次修改；普通有效手势提交一次、撤销一次，显式预览以整次完成为一个事务，取消零提交 |
| 三端来源与恢复 | 分别改桌面基础、平板覆盖、手机覆盖，检查所有下游结果；恢复手机继承后读取有效上游，跨端复制的预览与写入一致 |
| 多选与锁定混合 | 显示总数/可修改数、混合值和排除原因；约束交集为空不能提交；合法批量操作一次撤销恢复各对象原值 |
| 全局与本端显隐 | 全局隐藏、本端隐藏、祖先隐藏分别能识别和恢复；只恢复一层不虚报已可见；隐藏对象仍可从结构区定位 |
| 未提交输入与历史 | 非法值下尝试切对象/端/临时视图/保存均可修正或明确取消；有效提交一次；先改 A 再选 B，模板撤销仍还原 A 的最近操作 |
| 普通手势与显式取景 | 普通间距拖动松开提交一次；图片取景中松开不提前提交，内部切换选择器不取消，完成一次提交，取消恢复外框未变的原取景 |
| 操作模式与尺寸意图 | 空白框选、平移、对象移动互不竞争；对象拖宽转固定有提示且取消恢复原方式；拖预览外边缘不改根尺寸或 dirty；不同缩放下手柄热区和落点仍可操作 |
| 比较与只读返回 | 三端使用同一系统场景；比较内不写设计值，聚焦某端才进入相应编辑上下文；从只读预览比较返回仍只读；切视图不丢待处理输入 |
| 默认与示例内容边界 | Schema 3 默认图文可编辑、撤销、保存与重开；系统示例/试排不进入模板或页面；页面显式值、缺省与清空按版本规则分别验证 |

### 10.2 页面装修轨道

- 打开具体页面与语言，正确区分草稿、线上、空和读取失败。
- 目录只允许插入可用发布版本；预览不写入，添加位置明确。
- 填写图片、文字、业务引用和链接；条件切换不丢合法输入。
- 页面图层只能管理页面实例；模板内部对象只定位开放字段。
- 恢复模板值不丢真实内容，固定区与权限在所有入口一致。
- 保存/重载、预检、发布、公开 Renderer、失败恢复和并发冲突具有对应证据。

### 10.3 模板到页面交接轨道

- 发布一个不在旧内置清单中的专用模板 v1，并在页面目录定位该精确版本。
- 页面插入 v1、填写真实内容并发布；模板系统示例没有泄漏到页面。
- 模板发布 v2 后，原页面继续使用 v1。
- 升级检查展示内容映射、双端布局、开放范围和覆盖变化。
- 取消升级零副作用；确认只改变草稿，页面重新发布后才使用 v2。
- 模板归档或目录暂不可用时，历史页面仍按精确版本和公开门禁读取，不伪报“最新”。

### 10.4 交互和界面轨道

在工作区净宽 1200px 与 1600px，以及 `<1200px` 适用抽屉状态下检查：

- 固定四区比例没有因模式、选中或错误状态变化；
- 空白、选区域、选图片、选文字、隐藏、锁定、深层结构和发布失败均可操作；
- 连续添加不丢目标，完整名称和返回路径可获得；
- 长标签不裁切关键含义，属性组不会横向溢出；
- 键盘、点击和非拖拽路径能完成添加、定位、排序、调整和恢复；
- 选中与焦点持续可见，操作目标不因密集排列产生误触。

窄栏验收以完整任务为准：在固定比例下找到至少五层嵌套的长中文名称对象、查看全名及父级、移动到合法目标、恢复隐藏和锁定，并返回全树；不能用“名称宽度大于某个像素值”或单行不换行代替可用性结论。属性区约 240px 时必须能完成数值与单位输入、错误修正和来源查看；短模板靠近顶部，长模板滚动到底仍能继续编辑，工具条和浮层不遮住主要操作。

另检查 1199/1200px 界面切换边界与当前合同的内容断点边界、浏览器文字放大及抽屉开关；四区比例不变，布局切换不改变模板规则，不丢当前输入或上下文。以上是功能验收，不通过时修复布局与操作路径，不缩小点击目标或降低断言掩盖问题。

邀请实际运营人员使用专用草稿完成“七步选项与方案预览 → 确认生成 → 属性/画布精调 → 重复添加图片或文字 → 检查双端与开放字段 → 保存发布 → 页面插入 → 填内容 → 发布页面”，记录入口发现、停顿、误点、错误恢复、返回修改与协助需求；重点检查是否能理解调整范围，不要求先学习从零拖拽。没有真实实操证据时只能称为设计规格，不能称为已证实易用。

本地、真实联调和生产证据按 [WORKFLOW](../../WORKFLOW.md) 第 5 节分别记录；代码、Mock、构建、单个截图或历史 PASS 不能单独证明完整轨道通过。

### 10.5 两个运营任务走查

使用专用测试草稿，给出下面的目标而非逐步操作答案；观察入口是否可发现、是否选对对象、是否理解影响及能否恢复。界面观察、字段规则、保存联调和公开消费继续按 10.1–10.4 分别留证，不能以一次走查代替全部门禁。

| 任务 | 制作与返修动作 | 必须观察的结果 |
| --- | --- | --- |
| 左图右文工艺区 | 七步选择左图右文、主图与标题/正文/按钮，确认生成；调列宽与取景，手机改上下排列。再重复添加说明文字，通过结构树找到文字组，移动按钮、取消错误拖动、恢复隐藏对象，检查长文/缺图并继续精调 | 预设结果可用；新增与修改结果可区分，父级和顺序可预测；整体、容器和图片外框无混淆；错误可取消，三端继承与选择一致 |

## 11. 首屏测试样例与退役模板兼容原则

- 活动合同与页面装修内置测试目录只保留 `hero` 首屏测试样例；它只用于显式测试，不进入模板设计目录，也不是新模板默认内容或固定起点。
- 旧固定模板的合同、适配器、Renderer、Inspector、设计卡和专用验收均不再保留；其数量、完成比例和固定批次不构成产品目标。
- 数据库既有页面、历史版本和不可变记录不由代码清理自动删除；若仍引用已删除类型，应明确显示为不受支持，而不是静默恢复旧兼容行为。
- 新模板只消费 V2 注册节点、合法嵌套、页面角色和统一实例能力，不要求新增内置 key、专属 Puck 组件或设计卡。
- 归档文档保留证据价值，但其数量、阶段、旧截图和 PASS 不定义当前状态。

只有修改兼容链时才验证受影响旧来源；修改 Shared Editor Core、Renderer、开放字段或版本逻辑时验证所有受影响的新旧消费者。不得为“清理干净”批量删除合同、历史版本、归档证据或读取适配器。
