# 页面装修与模板设计

> 功能规格，2026-09-08 整理。本文描述目标行为；是否已实现、验证到哪一层见 [CURRENT_STATE](../CURRENT_STATE.md)。
> 四区框架按 [PROJECT_RULES](../../PROJECT_RULES.md) §7；通用交互与文案按 [UI_GUIDE](../UI_GUIDE.md) 附录 A、[ADMIN_COPY_GUIDE](../ADMIN_COPY_GUIDE.md)。配套文档见[导航](README.md)。

## 1. 产品目标与固定边界

让设计者能制作可复用模板，让页面编辑者能用模板完成真实页面，并准确知道正在改什么、保存到哪里、何时影响公开网站。

页面装修和模板设计共用四区基础框架。四区的顺序和桌面固定比例由上述硬规则唯一维护，模式切换、工具增加、面板内容优化都不改变它。四区内的分类、控件、展开方式、快捷操作和提示由实际任务决定，不是永久固定的产品要求。

主流程是从零设计模板，再通过页面装修使用。新模板不依赖旧 24 模板的名称、数量、固定构图或批次进度，也不需要加入旧模板清单才能保存、发布和选用。旧模板及图文组合只保留为可选快捷起点和兼容来源。

本项目服务于珠宝作品、工艺叙事与顾问服务。模板用途遵守 [PROJECT_GUARDRAILS](../PROJECT_GUARDRAILS.md) 第 2 节的页面职责；页面根内容、固定业务区和首屏／导航角色约束继续有效，旧内置 key 白名单不构成新母模板准入条件。四区比例约束后台工作区，不限制模板内部构图。

## 2. 数据模型与实现来源

| 对象 | 职责与来源 |
| --- | --- |
| 母模板定义 | `TemplateDefinitionV2` 保存结构、槽位、布局、样式、响应式和页面允许覆盖的范围；能力由 [template-definition.schema.json](../../contracts/page-builder/template-definition.schema.json)约束 |
| 实际模板 | `DynamicTemplate` 草稿、不可变版本与 Repository 保存身份、目录状态和版本；Schema 不是模板记录库 |
| 页面实例 | Puck `PageDocument` 保存所选模板的精确版本、真实内容和允许的实例覆盖 |
| 内置兼容集合与页面规则 | [content-templates.contract.json](../../contracts/page-builder/content-templates.contract.json)；不作为全部未来母模板目录 |

目录、画布、属性面板、公开 Renderer 和校验器消费对应来源。共享的是模型、渲染结果和通用编辑能力，两种模式可以使用适合自身任务的控件与会话，不要求所有区域功能逐项相同。

现行结构使用注册节点和受控配置，不接受任意 HTML/CSS 或可执行组件上传；数据操作与权限仍按 [AGENTS](../../AGENTS.md) 和当前服务端合同执行。

## 3. 运营使用过程与四区交互设计

### 3.1 工作方式：持续编辑，按选择提供工具

同一个运营人员可以先设计母模板，再使用它编辑页面；这是两种任务，不假定两名不同人员。模板设计解决“怎样组织和呈现可替换的内容”，页面装修解决“这次具体展示什么”。界面使用“区域、图片、标题、正文、按钮、左右排列、间距”等任务语言；Section、Slot、nodeId、flow 等实现术语不作为开始设计的前置知识。

设计是“添加 → 选中 → 调整 → 看结果”的反复循环。下文步骤描述首次完成任务的路径，不做强制九步向导，不按完成进度锁住后续工具。布局、双端、填写范围可随时返回调整；只有真实保存、权限或发布条件产生阻断。

四区回答四个稳定问题：**组件库——加什么；图层——选哪个；画布——结果怎样；属性——具体怎么改。** 同一命令可有就近快捷入口，但只有一套行为；同一字段只在属性区完整编辑，不在图层和工具栏再复制一份表单。

### 3.2 固定外壳内的空间分配

比例仍由 PROJECT_RULES §7 唯一维护。下表宽度是编辑器工作区净宽的算例，不是浏览器视口或新令牌；实际需扣除后台导航、边界与间距再测量。

| 工作区净宽 | 组件库 12% | 图层 8% | 画布 60% | 属性 20% |
| --- | --- | --- | --- | --- |
| 1200px | 144px | 96px | 720px | 240px |
| 1600px | 192px | 128px | 960px | 320px |

**既有顶部工具栏**是四区共用动作入口，不新增第五个常驻功能区：左侧为模式、模板名称、“新建模板”和保存状态；中部为撤销／重做、设备与预览；右侧保留“保存草稿”“发布模板”和“更多”。正常编辑突出保存，发布保持明确可见的次级入口；进入发布检查后，该检查视图的主要动作才是发布。模板资料、另存、版本历史与导入导出进入有名称的菜单；对象的字号、间距等不放顶部。拥挤时工具组换行，不能缩小文字、仅剩无名称图标或挤掉保存状态。

| 区域 | 模板设计的常驻内容与摆放 | 页面装修的差异 |
| --- | --- | --- |
| 组件库 | 顶部短标签“添加／打开”；默认“添加”，单列排列区域、图片、标题、正文、按钮等常用项；空白时突出可执行的区域入口，内容项就近说明需要先有合法区域，其余在有明确名称的类型分组中。每项短名称配一致图标；组合骨架为可选项。“打开”才显示模板搜索、状态筛选与单列预览 | 主体改为可用模板版本目录；先预览再添加。模板名称、版本与可用性保持可见，不把母模板节点工具混入页面目录 |
| 图层 | 顶部“图层”与查找入口；下方是实际节点关系。点击行选择，展开箭头只展开；选中行才出现一个对象菜单。隐藏或锁定状态可辨，完整名称与原因在属性区同步展示 | 以页面区块为结构操作对象；内部字段用于定位，不开放母模板结构改写 |
| 画布 | 顶部局部工具只放适合画布、缩放与示例状态；内容区居中显示当前设备画面。空白时一个“添加区域”主入口；选中后呈现边界、合法插入线与适用手柄；工具不挡住被编辑内容 | 展示真实内容。编辑态点击定位内容，预览态才体验链接等公开交互；进入只读预览后保留返回入口与未保存状态 |
| 属性 | 顶部固定显示当前对象完整名称、类型、路径及修改作用范围；正文按“设计／页面填写”组织。设计随对象显示常用字段；页面填写显示对运营开放的规则。恢复、错误定位紧邻相关字段 | 内容填写在前，允许的设计覆盖在后；不要求运营理解母模板结构或切回模板模式才能完成普通换图改字 |

图层的窄宽度需要特别处理：不在每行同时摆放多枚状态图标、计数和多个操作按钮，也不无限叠加缩进挤掉名称。深层对象可从查找或“聚焦此层级”进入当前分支，保留父级路径与“返回全树”，不省略或改写真实层级。完整路径由属性区承载；名称截断时仍可通过键盘聚焦的详情获取。不能通过缩小功能字号或改变 8% 宽度解决问题。

对象菜单按能力提供重命名、复制、显隐、锁定与移除，并展示不可执行原因。复制区域时带上子结构但生成新的稳定身份，不与原对象共享可写槽位；移除只改变当前草稿并可撤销。锁定与隐藏分开表达：锁定不能只禁用右侧而仍允许快捷键改写，隐藏对象仍可从图层恢复。涉及多个对象时，只有共同支持的批量动作才能出现，混合值不能伪装成相同值。

各区标题位置、分隔线与内边距对齐；库、树和属性各自滚动，顶部动作与属性对象身份保持可见。画布缩放只改变查看尺度，不改模板尺寸；编辑区变窄也不自动写入移动端规则。小屏按现有抽屉合同承载面板，不改变桌面比例。

### 3.3 从空白到可用：逐步推演四区响应

以从零建立一个工艺图文模板为例；它只是操作演练，不能成为所有模板的固定结构。每一步都可退出或返回调整。

| 运营想完成什么 | 主要入口与四区响应 | 完成反馈与防错 |
| --- | --- | --- |
| 开始一个新模板 | 顶部“新建模板”进入独立会话；库默认添加，图层只有必要根节点，画布为空；属性显示模板范围及可修改名称，不先弹出分类或结构配置长表单 | 显示“未命名模板／尚未保存”。画布给出添加区域入口。离开已有脏会话按既有保护处理，不将两份编辑混合 |
| 放置第一块内容区域 | 点画布“添加区域”或库中的区域项；图层增加“区域 1”，画布出现可选边界，属性立即显示排列、宽度、内容高度、内边距和元素间距 | 新区域被选中；下一次添加的目标可见。第一步不要求选择 HTML 标签或输入坐标 |
| 放入图片与文字 | 在已选区域点击库中的图片、标题、正文；三处选择同步到新对象。普通点击是完整路径，拖拽只是快捷方式 | 合法容器选中时添加到末尾；叶对象选中时优先预示其后方同级插入，只有合法才执行。没有合法父级则先选择目标，不静默转移到远处或自动生成不可见包装层 |
| 调整左右／上下关系 | 选区域，属性显示左右排列、上下排列及当前支持的分列方式；画布即时重排。新增或重排由实际结构决定，复用现有布局命令 | 切换只改变布局规则，不重建槽位或清空内容。移入另一容器先显示落点；非法目标拒绝并恢复。复杂重构不伪装成普通切换 |
| 调整图片或文字 | 点画布对象或图层行；属性切到该对象的常用设计字段。画布只显示当前布局允许的调整方式 | 标题字号变化可见；图片比例、适配和焦点变化可见。流式节点不展示会产生自由定位结果的拖移手柄；数值输入与直接操作结果一致 |
| 检查移动端 | 顶部切设备；画布换查看尺寸，图层与选中对象不丢失；属性清楚标出当前端并显示差异与恢复入口 | 看“上下排列／自然高度”等真实结果。检查长文、缺图等系统示例，不手填真实文案。复制另一端设置先选范围，再确认差异，不建立隐式继承 |
| 决定页面可以改什么 | 当前对象属性切到“页面填写”；设置内容名称、必填／可选、可隐藏、允许调整的设计项和限制。模板整体可查看填写范围摘要并逐项定位 | 页面会看到“主图／标题”等业务名称；系统标出必填但无可用填写来源等冲突。此视图只读使用示例，不创建真实页面实例 |
| 保存与发布模板 | 编辑过程中随时保存合法草稿。发布时属性区暂时进入模板检查视图，问题列表可定位对象；返回属性保留选择与滚动上下文 | 草稿不要求满足全部发布条件。检查失败保留输入；通过后明确发布的是母模板版本。成功显示可用版本及“去页面装修使用”，不自动插入或发布页面 |
| 把模板用于页面 | 页面模式下库定位新模板版本；预览后添加，图层新增页面区块，画布出现待填写对象，属性直接显示真实内容字段 | 图片上传、正文和行动目标在这里填写。页面单独保存、预检和发布；查看公开结果。返回模板编辑不带入页面真实内容，也不自动升级旧页面 |

“模板已发布 → 去页面装修使用”只负责切换到页面选择并定位该版本。若页面有未保存工作，保留其上下文并遵守离开保护；不能默认覆盖当前页面、丢弃草稿或重复添加。没有插入目标时先由运营选位置。

### 3.4 属性面板：由当前对象决定内容

属性区不把 Schema 全量翻译成一张长表单。上部对象身份始终可辨，顺序为完整名称与路径 → 当前设备与作用范围 → 设计／页面填写 → 字段组。字段组显示修改摘要，恢复入口紧邻可恢复的组；无基线时不显示可成功恢复的假动作。中部先显示能完成当前调整的字段，低频精确项放到明确命名的一层展开区；错误与修改摘要仍可一步定位。默认“设计”，切换对象时保持用户正在使用的页签；该对象不适用的页签需说明范围，不自动跳到其他任务。

| 当前选择 | 设计页默认显示 | 进一步展开 | 页面填写页 |
| --- | --- | --- | --- |
| 无选中／模板根 | 模板名称、整体宽度与内容高度语义；提示如何选择对象 | 模板资料、页面用途与导航兼容等适用设置；仅暴露合同可表达能力 | 全模板开放字段摘要、缺项定位 |
| 区域／布局容器 | 左右／上下／分列、宽度、自动或固定高度、对齐、元素间距、区域内边距 | 四边分别设置、支持的细分尺寸；仅适用容器显示自由叠放设置 | 该区域下的开放内容摘要，不提供虚假的“区域正文” |
| 图片 | 宽度、比例、完整显示／裁切填满、焦点；以可理解的当前值呈现 | 自定义比例、适用尺寸与边界限制 | 内容名称、必填与显隐、允许的实例调整；模板模式不出现上传真实图片 |
| 标题／正文 | 字体角色、字号、字重、行高、对齐；高度默认语义可辨 | 最大行数、溢出方式等适用设置，截断会影响内容时就近提示 | 内容名称、必填与长度限制；不提供真实正文输入 |
| 按钮／业务对象 | 当前合同支持的外观与排版字段 | 与该对象有关的设计细节 | 页面需填写的行动或业务引用要求；真实 URL、商品、门店等在页面模式填写 |

“设计／页面填写”分开的是任务，不分成两套数据来源。页面模式右侧改为“内容优先、设计覆盖其次”；同一控件复用同一字段与校验，不因布局不同产生第二份配置。

尺寸先让人选“填满可用宽度／随内容变化／固定尺寸”等语义，再显示相应数值和单位；不默认展示 CSS 属性、无效百分比或多个意思相近的输入。左右／上下排列、列宽、元素间距、区域内边距各有明确作用对象；图片内焦点不与整个图片节点的位置混用。能力不存在或组合不合法时说明原因，不能展示可编辑但保存无效的控件。

数值编辑保留输入中的暂时状态；Enter 或离开有效输入后提交一次，Esc 恢复本次输入前值。非法值就近说明并保留可修正输入，不悄悄吞掉字符或恢复成看似成功的旧值。拖动过程即时预览，结束产生一次历史；取消不提交。切换对象与设备前妥善处理未完成输入，不能把值提交给新选中的对象。

### 3.5 界面清晰与视觉秩序

视觉数值沿用 UI_GUIDE 附录 A；此处只决定它们怎样服务任务，不建立新的主题或品牌令牌。

- 工具区使用中性背景、清楚边界与无衬线文字；画布表面与编辑器背景可区分，真实画面是主要视觉焦点。避免给每个字段套卡片、加阴影或重复标题。
- 一个属性组对应一个问题：尺寸、排列、图片显示、文字样式、页面填写。标签紧邻控件，单位与数值在一起，说明只在影响选择或恢复时出现。
- 属性区约 240px 时采用单列字段，宽高等简单成对值才并排；长选项改纵向或下拉。不能把“左右／上下／分列”三张图文卡强塞一行。
- 选中、悬停、锁定、隐藏、已修改和错误各有可辨状态；不能只用颜色。选中边界持续可见，操作按钮可在选中或键盘聚焦后出现；必要操作不依赖悬停。
- 正常编辑不堆“结构正确”“合同通过”“尚无错误”等成功说明。保存状态集中在顶部；字段错误靠近字段，跨对象问题集中于检查视图，并能跳回实际对象。
- 检查视图、版本差异等临时任务须有明确返回位置；不连续打开抽屉或弹窗遮住对象。普通可撤销布局修改不反复确认，跨版本替换和丢弃修改才按实际后果处理。

### 3.6 页面填写与空态的区别

页面模板目录按用途、构图和实际可用版本选择，草稿与已发布版本可同时存在，不能因新草稿出现隐藏仍可使用的 v1。预览与添加分开；目录无结果、加载失败、权限不足和没有正式版本采用不同反馈。

页面中新插入实例的真实内容为空时，以明确的编辑提示帮助填写；这些提示不进入公开 Renderer。可选内容为空按合同处理，必需内容不齐明确列入相应校验；系统示例不能作为已填写内容或发布成功的证据。

字段因选择、设备或条件变化而暂不显示，不因此清空输入。保留编辑上下文不等于把无权限或不适用值写入请求；合法性和持久化继续由当前合同与服务端裁决。

## 4. 内容、设计与调整反馈

**母模板定义、系统示例、页面真实内容分开。** 示例按槽位临时生成，经同源 Renderer 展示，不写入模板内容或页面实例，也不解析真实经营数据。新定义的 `defaultContent` 为 `{}`，`previewContent` 省略或为空；旧值仅兼容读取，不静默复制到新身份。

中性示例不等于只有一种展示状态。可提供系统生成的短文、长文、不同媒体比例和缺失内容检查，以发现构图问题；这些仍是只读临时测试状态，不引入运营上传、真实文案保存或业务引用。当前是否具备这些状态列入状态文档，不把目标当作既有能力。

页面保存文字、媒体、链接与稳定业务引用。商品、门店等经营事实仍从业务源解析，不在模板或页面中复制价格、库存、客户、订单或支付数据。

属性面板先提供当前任务需要的字段。修改和错误摘要应可见，并能展开、定位对应字段；不要求所有必填、已改或进阶控件同时展开。显示当前设备、修改影响和可恢复对象，不能只用颜色或“默认”二字解释来源。

| 动作 | 明确语义 |
| --- | --- |
| 撤销／重做 | 作用于当前模式与对象的编辑历史，不串用页面和模板会话 |
| 页面设计字段“恢复模板值” | 删除该字段的实例覆盖，读取页面所锁模板版本；不清空真实内容或升级版本 |
| 模板字段“恢复最近保存值” | 回到当前模板最近一次成功保存的草稿基线；新节点或未保存新模板没有该基线时不可伪造，仍可使用撤销 |
| 复制另一端所选设置 | 按适用的尺寸、排列间距、图片显示、文字样式分组选择并预览差异；一次确认和一条历史，未选字段保留，不建立自动继承或复制真实内容 |
| 移除当前区块／节点 | 修改当前草稿并可撤销；不等于删除目录记录或历史版本 |
| 替换模板／升级版本 | 分别预览内容映射、双端布局变化、页面可编辑范围变化；以稳定身份与合同判断，不能凭标签相同迁移内容。无法映射项明确列出，取消保持原版本、内容和覆盖；确认只修改草稿 |

有权限的设计反向提取只把当前合同能无损表达的设计字段载入独立未保存模板草稿；先说明差异、冲突与排除项，真实内容和业务引用不进入定义。它与保存、发布及页面升级是不同动作。

## 5. 保存、预览、发布与恢复

保存对象始终可辨：页面保存页面草稿；模板覆盖更新同一身份的草稿，另存建立新身份。模式切换不自动合并、保存或丢弃会话。迟到回包不能覆盖新对象，也不能把后续修改误标成已保存；具体实现沿当前调用链处理，不规定所有请求都使用同一组内部字段。

| 查看方式 | 数据与可用操作 |
| --- | --- |
| 当前编辑预览 | 包含本会话未保存修改；切设备与预览不触发保存 |
| 独立草稿预览 | 读取服务端已保存页面草稿；没有草稿与读取失败分开反馈，不用 seed 或线上内容替代 |
| 查看线上版本 | 只读比较已发布版本，返回时恢复原编辑上下文，不把线上副本直接保存成草稿 |

模板发布创建不可变版本，页面实例继续锁定 `templateId + templateVersion`。新版本出现时既有页面不变；页面显式升级草稿并重新发布后，公开结果才更新。兼容来源可读取、重放和载入统一模板会话，不重建旧格式写入口，不改写原记录。

检查升级时，区分“已核实为最新”“发现新版本”“目录当前未提供可升级版本”和“检查失败”。目录没有某模板不证明已是最新版，也不证明历史引用已失效；只有取得状态证据才能标为已归档或停用，旧页面继续按精确版本与公开读取门禁判断。

发布前用户能判断对象、版本／语言、影响与阻断；具体用内联反馈还是弹窗由风险和任务决定，不固定增加确认次数。创作提示、待完善摘要和真实发布错误应区分；当前服务端严重级与界面提示的差异见状态文档，文档整理不替代该行为裁决。

失败保留输入并提供具体恢复动作。冲突不能自动覆盖他人修改；校验问题能定位字段，权限问题说明不可执行的动作。历史载入、显式保存和线上回滚分开，当前页面行为见[操作清单](../acceptance/puck-published-content-audit.md)第 2.3 节。普通打开、预览或规则整理不改写历史版本与未保存草稿。

## 6. 可观察验收

按受影响能力选择场景，不为局部控件修改强制执行完整产品矩阵；本地、真实联调和生产证据按 [WORKFLOW](../../WORKFLOW.md)第 5 节分别说明。

- **开始与身份**：能新建、打开、另存并继续设计；最后一个节点删除后有恢复或继续添加路径，原模板不被另存覆盖。
- **编辑与双端**：添加、选择、调整和属性反馈同步；连续操作不丢焦点，取消零提交，单次手势进入一次历史，两端按各自规则呈现。
- **内容与恢复**：能分辨内容与设计覆盖；重置、复制另一端、替换和撤销的作用范围清楚，不丢真实内容。
- **模板到页面**：保存重开、模板发布、目录可选、页面填内容、页面发布及公开结果对应同一身份与精确版本。
- **版本与失败**：模板 v2 不改变锁 v1 的页面；升级取消无副作用，冲突和保存／发布失败能恢复，历史载入不直接切换线上。
- **界面稳健性**：固定四区保持，适用窄屏可操作；空、长文、缺图、错误、键盘和非拖拽路径有证据。

**贯通示例：工艺图文模板。** 设计者开放主图、标题、说明与合同允许的行动，检查长文／缺图及双端后发布 v1；页面编辑者插入 v1，填写获准的真实内容并发布页面。设计者修改布局发布 v2 后，原页面仍使用 v1；页面升级检查展示内容、外观和开放范围变化，取消不改变页面。若目录暂不提供该模板，应给出可用性说明，不能伪报“已是最新”。此场景用于专用测试草稿，不操作用户现有未保存内容。

**交互方案的具体检查**：在工作区净宽 1200px 与 1600px、默认空白、选区域、选图片、选文字、隐藏对象、深层对象、发布失败这些状态逐项检查：第一步入口可发现；添加后立即知道新增对象在哪里；三次连续添加不丢目标；完整名称和返回路径可获得；240px 属性区长标签不裁切；键盘与点击均能完成添加、定位、调整和恢复。宽度算例不替代真实浏览器测量。

邀请实际运营人员用专用模板完成“空白开始 → 两个区域 → 图片与文字 → 桌面左右、移动上下 → 开放填写 → 保存发布 → 页面选用”，记录停顿、误点、找不到的入口和返回修正次数。没有实操证据时称为设计方案，不称为已证实易用；不能用主观美观评分、固定点击次数或自动化绿色替代运营完成任务。

验收还须证明：交付检查列出的字段在页面侧确实可用；跨端只复制所选组，其他值不变；条件切换不丢输入；系统示例不进入持久化请求。已有版本升级和目录刷新能力应复用，不能因本规格补充验收就按“从零缺失”重建。

## 7. 维护与设计依据

旧 24 模板的逐项设计卡、数量门禁、固定对象及“只允许选择”的规则不用于从零设计验收；新母模板消费 V2 注册节点与统一实例能力。修改兼容链时才验证其受影响旧来源，修改共享能力仍须覆盖受影响消费者。功能规格不保存临时员工数量、派发指令、固定修复顺序或全仓命令清单。当前缺口与证据只维护在 [CURRENT_STATE](../CURRENT_STATE.md)，实现路径见[页面边界](../architecture/page-builder-boundary.md)。旧文档和实现都可以暴露问题，不能仅凭“现行”二字证明其设计合理。
