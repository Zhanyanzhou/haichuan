# 模板设计规则

（2026-08-18 制定；2026-08-19 按立法体例整理修订）

---

## 第一章 总则

**第一条（目的）** 为规范海川珠宝项目内容模板的设计、编辑、验收与退役活动，保证模板的可编辑性、视觉质量与实施一致性，制定本规则。

**第二条（适用范围）** 本规则适用于页面模板与图片物料的设计活动。下列活动不适用本规则：

（一）内容变更，即不涉及结构、槽位、权限、比例与合同字段的内容替换与预设调整；

（二）品牌规范的制定与修改，该等活动适用 `docs/UI_GUIDE.md`。

**第三条（规则性质）** 本规则为覆盖性框架。设计人应当逐项回答本规则规定的必答事项；各事项的答案由该模板的设计卡确定。本规则不预设任何数值、构图与风格。

**第四条（文件关系）** 本规则与配套文件按下列分工适用；本规则援引配套文件内容的，以配套文件为准：

| 文件 | 职责 |
| --- | --- |
| 本规则 | 规定模板设计的必答事项与程序 |
| `design-library/06-jewelry-template-system.md` | 方法论依据 |
| `design-library/03-quantitative-baselines.md` | 量化参考（仅供参考，不具约束力） |
| `docs/UI_GUIDE.md` | 品牌规范（品牌层面以该文件为准） |
| `contracts/page-builder/` | 设计答案的机器执行载体 |
| `docs/page-builder/design-cards/` | 设计卡存档 |

**第五条（用语解释）** 本规则所称"应当"为义务性规定，"不得""禁止"为禁止性规定，"可以"为授权性规定。

## 第二章 定义

**第六条（定义）** 本规则下列用语的含义：

（一）**模板比例**，指根模块的整体比例关系，由宽度档、高度策略与分栏结构确定；

（二）**图片槽位比例**，指单个图槽内素材的裁切建议，由契约派生；

（三）**三体**，指整体比例、图片构图与文字设计三者的合称；

（四）**设计卡**，指记录单模板设计答案的文档，存放于 `docs/page-builder/design-cards/<templateKey>.md`；

（五）**方向稿**，指用于确认设计方向、允许被否决的设计卡初稿；

（六）**实施稿**，指经方向确认后、用于进入实施的完整设计卡；

（七）**结构验收**，指以中性占位状态执行、不依赖真实素材的验收；

（八）**终验收**，指素材就绪后执行的验收；

（九）**素材委托清单（photo brief）**，指按图槽输出的素材规格说明，每槽一份；

（十）**占位**，指图槽未填充真实素材时的中性视觉载体。

## 第三章 基本规范

**第七条（比例声明义务）** 模板比例与图片槽位比例应当分别声明，不得混同或相互替代：

（一）模板比例应当依照第十一条、第十三条声明；

（二）图片槽位比例应当挂靠具体图槽，仅作该槽素材的裁切建议；

（三）图片槽位比例不得决定模板整体结构；

（四）变更模板比例的，构成模板变更，应当适用第十九条规定的程序。

**第八条（主舞台唯一）** 每页至多设置一个 primary-stage 模板。

**第九条（编辑边界）** 模板编辑权限应当划分为固定项、受控预设与可编辑内容三档，具体划分适用第十七条。禁止提供自由布局、自由字号、自由颜色与任意 HTML 编辑。

**第十条（强制范围）** 本规则的强制事项以第七条至第九条为限。

## 第四章 构图比例

**第十一条（三体同答）** 模板构图比例由三体共同定义。三体应当在同一张设计卡内一并作答：

| 体 | 定义 | 必答内容 |
| --- | --- | --- |
| 整体比例（即模板比例） | 根模块的宽度档、高度策略、分栏结构 | 图区、字区、留白区的主次与承托关系 |
| 图片构图 | 图与图槽的关系 | 素材适配要求（构型方向、主体位置、密度）与焦点区 |
| 文字设计 | 文字的位置与形态 | 文字区位置、宽度、对齐及其与图区的关系 |

**第十二条（关系律）** 三体答案应当符合下列规定：

（一）**同答律**：三体不得拆散单独作答；

（二）**主次律**：应当声明图主导、字主导或均衡，并与第十五条第（一）项叙事主角一致；

（三）**三端律**：三体关系应当按桌面、平板、手机分别声明演变，不得表述为"同桌面缩小"；

（四）**验证律**：三体关系应当可检验——以眯眼验证面积关系、换图验证图区适配、换字数验证字区弹性。

**第十三条（设计推导）** 三体答案应当由模板的叙事特点推导，不得与模板名称所承载的叙事角色脱节：

（一）模板比例的宽度档、高度策略与分栏结构应当与模板承担的叙事任务一致；

（二）各图槽的数量、位置、占比与主次关系应当与叙事主角、配角的分工一致；

（三）文字区的位置、宽度与对齐应当与文字在叙事中的职责（解说、呼应或让位）一致；

（四）设计卡应当体现从模板名称与叙事到三体结论的推导过程，三体结论不得无依据成立。

## 第五章 设计卡

**第十四条（必答义务）** 设计卡应当逐层回答第十五条规定的九层事项；不适用的应当注明"不适用"并说明理由，不得留空。违反本条与第七章规定的实施稿不得进入实施。

**第十五条（九层事项）** 设计卡应当包含下列九层事项：

（一）**角色与叙事**：叙事需求三问（让用户知道什么、感受什么、做什么）；叙事主角（作品、系列、工艺、人、空间之一）；视觉角色（primary / feature / support）；模式（Brand / Commerce）；用途、不适用场景与建议页面位置；

（二）**整体比例与构图**：依第四章三体作答；

（三）**槽位**：图槽的数量、语义命名、素材建议比例与焦点策略；氛围图槽应当声明影像语言意图（产品图与氛围图分轨、底色语言、多图同屏光源一致性），产品图槽声明"继承商品系统影像语言"；文字槽层级序列；行动槽数量上限与位置；留白的角色与档位；

（四）**美学**：排印方案（级距、字重、语气）；色调与明暗定位；节奏定位（高潮、停顿、过渡）；影像语言与站点既有语言的关系（延续或刻意对比）；可以附禁忌清单。**涉及配色与排印的，应当对照 `design-library/03` 第八节实证基线与 `04` 第六节十家实测证据作答**；

（五）**权限**：依第六章三档划分；文字预算三件套（字符数、预期行数、溢出行为）；

（六）**数据**：引用的单一事实来源，模板不得复制第二份业务事实；无业务对象的应当声明"无"；

（七）**状态**：素材状态覆盖（空、继承、上传中、失败、比例不符）；无素材时公开态行为（静默隐藏、中性占位、阻止发布，三选一）；素材授权状态（自有拍摄、已获授权、待核查）；失败保护与双端素材继承策略；

（八）**合同**：挂靠母版与契约 key；比例走契约派生管道；改前影响盘点（本次改动影响哪些已发布页面、是否接受）；回退方式；

（九）**验收**：依第八章作答。

## 第六章 编辑权限

**第十六条（操作范围）** 运营操作仅限于内容替换与受控预设调整，不得改变版式结构。

**第十七条（三档划分）** 编辑权限默认按下表划分：

（一）**固定项**：

| 项 | 说明 |
| --- | --- |
| 模板身份 | 视觉角色、模式、叙事骨架、槽位数量与语义 |
| 结构 | 三端构图、栅格分栏、根高度策略、图槽比例（契约派生） |
| 排印系统 | 字阶、字体、行高、字距、级距 |
| 文字层级与预算 | 级数、字符数、行数、溢出行为 |
| 色彩纪律 | tone 预设内部色值成对固定，只可选预设，不得改色值 |
| 行动规范 | 行动槽数量上限、位置语义、CTA 形态 |
| 间距系统 | 留白档位、间距刻度、分隔线语言 |
| 素材适配机制 | 焦点裁切、比例适配、双端继承、替换保护、状态机 |

（二）**受控预设**：

| 项 | 选项 |
| --- | --- |
| 镜像 | 图左 / 图右 |
| 文字对齐 | 左 / 中（居中仅限宣言、仪式、尾章类模板） |
| 色调 | 模板合同声明可选集（母版默认四调，模板可以收窄），成对切换底色与文字色 |
| 留白档位 | compact / normal / spacious / grand，档位值固定 |
| 遮罩档位 | 无 / 轻 / 深，默认值由影像语言意图确定 |
| 数量与列数 | 模板合同声明范围 |
| 内容项排序 | 范围内拖拽 |
| 动效开关 | 开 / 关（reduced-motion 始终生效） |

（三）**可编辑内容**：

| 项 | 说明 |
| --- | --- |
| 图片 | 桌面与移动端上传、焦点选择（安全区 15%–85%）、替代文字；素材原始比例不必等于槽位比例，由模板裁切适配 |
| 文字 | 眉题、编号、标题、副标题、正文、行动文字 |
| 链接 | 行动目标（商品、页面、外链选择器） |
| 业务对象 | 选择商品、门店、活动、证书；事实字段只读 |
| 显隐 | 可选元素开关，依赖项联动 |

**第十八条（偏离）** 第十七条所列划分为默认参照。设计卡可以偏离单项，但应当注明理由；未注明理由的偏离无效。

## 第七章 程序

**第十九条（变更分级）** 内容变更（换图、改字、选受控预设、调焦点、换链接）不触发设计程序，在编辑器内直接完成。涉及结构、槽位、权限、比例或合同字段的变更为模板变更，应当依本章程序执行。

**第二十条（流程）** 模板设计程序如下：

```text
变更分级 → 0 复用闸门 → 1 方向稿 → 2 用户确认 → 3 实施稿
→ 4 结构实施（占位状态）→ 5 结构验收 → 6 素材委托清单
→ 7 素材填充（即插即用）→ 8 终验收
```

**第二十一条（复用闸门）** 新增模板应当说明现有母版为何不能承载；可以挂靠现有母版的，应当调整配置，不得新增模板。紧急时效需求可以复用最接近的模板并记录偏航理由，事后复盘是否转正。

**第二十二条（方向稿）** 方向稿应当符合下列规定：

（一）先写叙事，不超过五行，说明给谁看、传达什么、期待什么反应；

（二）作答第十五条第（一）至（四）项；

（三）附视觉锚点至少一张，来源可以为竞品参考图、现状截图或自绘线框，不依赖自有素材；

（四）篇幅以一屏为限；经用户确认方向后方可编制实施稿。

**第二十三条（分类纪律）** 模板应当按叙事角色分类与命名，不得按图片数量定义模板。

**第二十四条（实施稿与存档）** 实施稿应当按第十五条九层固定结构逐层作答，附合同映射（母版、契约 key、派生比例字段）与回退方式。设计卡一模板一卡，方向稿与实施稿同文件演进；退役模板的设计卡应当保留并标注"已退役"及日期。

**第二十五条（实施路径）** 实施应当先契约、后生成产物、再 UI；比例只可以修改契约，禁止手写比例字面值。首次插入只写入安全空骨架与中性占位，示例图与演示文案不得进入草稿。

**第二十六条（完成定义）** 结构验收应当以占位状态执行。模板设计完成的判定标准为结构验收通过且素材委托清单已发出，不以素材到位为前提。

**第二十七条（占位体系）** 占位应当正确表达槽位契约比例、该模板的明暗调性与真实文字层级。

**第二十八条（素材委托清单）** 每个图槽应当输出一份 photo brief，包含比例、明暗调性、主体内容、光源方向、底色语言与分辨率。

**第二十九条（素材填充）** 素材填充应当以替换占位方式执行，版式结构不变；应当按素材重新校准焦点。

**第三十条（退役）** 模板停止提供新增时，应当声明存量页面数据的处理方式（保留只读渲染、迁移至替代模板、阻止发布，三选一）与编辑器是否从插入面板移除；不得删除旧数据的渲染能力。

## 第八章 验收与一致性

**第三十一条（结构验收）** 结构验收包括：检验三问（眯眼、换尺寸、删减）；五宽度核对（1920 / 1440 / 1024 / 768 / 390）；构图、比例、排印、留白与节奏的逐项核对。

**第三十二条（终验收）** 终验收包括：真实影像效果与焦点；模板专属验收点 1–3 条；无障碍与性能（对比度、键盘焦点、`prefers-reduced-motion`、大图多尺寸加载）；页面级检查（每页一个 primary；feature 模板不连续同密度；明暗节奏与相邻关系）。

**第三十三条（画布一致性）** 模板在插入面板缩略图、拖拽预览、画布占位、聚焦预览与公开渲染各形态中的模板比例与图片槽位比例应当一致，并均由契约派生；禁止为任一形态另行维护示意或比例。

## 第九章 诊断

**第三十四条（诊断提示）** 下列排查顺序为提示性质，症状可能多因：

| 症状 | 先查 | 再查 |
| --- | --- | --- |
| 焦点涣散 | 第十五条第（三）项槽位 | 第十五条第（四）项美学 |
| 换尺寸构图崩 | 第十五条第（二）项构图 | 图片槽位比例 |
| 换图后页面垮 | 第十五条第（五）项权限 | 第十五条第（七）项状态 |
| 单屏合格、整页腻 | 页面级组合约束 | 节奏定位 |
| 改一处坏一处 | 第十五条第（八）项合同 | — |
| 素材授权纠纷 | 素材授权状态 | — |

## 第十章 协作

**第三十五条（AI 义务）** AI 产出设计卡应当附现状证据（代码路径或截图）；图片生成仅限用户明确要求时执行。

## 第十一章 诚实条款与能力缺口

**第三十六条（引用核实义务）** 本规则援引任何机制（门禁、字段、脚本）前应当核实其实现存在；未实现的机制只能以目标态或能力缺口形式表述，不得表述为现状事实。

**第三十七条（当前缺口）** 截至本规则修订日：

（一）实例级版本快照未实现——契约变更立即生效于全部存量页面，改契约前应当完成改前影响盘点并写明回退方式；

（二）mode 页面门禁未证实——Brand 页拦截 Commerce 模板目前仅见于规则文字，未见实现；

（三）素材授权字段与门禁未实现——授权核查依赖发布前人工确认；

（四）模板层 srcset 降载未实现——2K/4K 素材移动端直载；

（五）页面级组合检查未自动化——重大内容变更发布前应当人工执行组合检查。

## 第十二章 附则

**第三十八条（生效与修订）** 本规则自 2026-08-18 起施行；本次修订（2026-08-19）按立法体例整理全部条款，规则实质未变。修订应当记录日期与变更内容；旧规则（8 比例骨架图片模板规则）已于 2026-08-18 废止并删除。
