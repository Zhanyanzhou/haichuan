# 设计卡 · 通栏图（fullBleed）

> 状态：**方向稿**（待确认）· 母版：immersive-image · 契约 key：fullBleed · 风格：白盒画册

## 第 1 层 · 角色与叙事

- 叙事三问：知道=一段氛围或工艺的意境；感受=舒展、呼吸；做=带着印象继续往下
- 叙事主角：空间 / 氛围（不是单件、不是系列）
- 视觉角色：support-stage（过渡屏）；模式：Brand
- 位置：主叙事段之间、画廊前后的呼吸点；不适用：信息传达、商品陈列、促销

## 第 2 层 · 整体比例与构图（三体）

- 面积关系：**图绝对主导**（21:6 超宽横幅全宽）；文字=图下独立说明带，不叠图
- 三体主次：图主导
- 图片构图适配：超宽横构图氛围图（空间、工坊、远景），主体偏一侧留呼吸；禁竖构图、多件堆叠
- 文字设计对话：图下一条窄说明带（≤720px），解说而非竞争
- 三端演变：桌面 21:6 全宽；平板 16:7 收紧；移动改竖图 4:5 + 图下说明（同构，不做图文并排）

## 第 3 层 · 槽位

- 图槽 ×1：主影像 21:6（3360×960 级起）；平板 16:7；移动 4:5（1500×1875，默认继承，超宽→竖图风险高提示独立上传）
- 文字槽 ×2 级：标题（衬线 h2）+ 一句说明（≤48 字）
- 行动槽 ×1：可选，纯文字下划线
- 留白槽：说明带与图的间距 + 横幅上下留白

## 第 4 层 · 美学

- 排印：标题衬线细体；说明无衬线 15px/1.8
- 色调：纯白底 + 亮调横幅；遮罩仅「无 / 极轻提白」两档
- 节奏定位：过渡——前一屏高潮，本屏舒展，后一屏恢复
- 禁忌：深色遮罩、图下堆长文、把横幅当首屏用

## 第 5 层 · 权限

| 档 | 内容 |
|----|------|
| 固定 | 21:6 通栏结构；图主导；说明带在图下不叠图；CTA≤1 |
| 受控 | 遮罩（无/极轻提白）；移动独立图；焦点（15–85%） |
| 可编辑 | 桌面图/移动图/altText；标题（≤12 字）、说明（≤48 字 1–2 行）、CTA 文字+链接 |
