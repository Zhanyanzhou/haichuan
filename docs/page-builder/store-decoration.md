## 1. 两个工作，一个产品

店铺装修是运营把已审核内容放到六个公开页上的工作。它包含两个相互衔接、彼此独立的工作空间：

| 工作 | 回答的问题 | 日常是否必须 | 写入对象 |
| --- | --- | --- | --- |
| **页面装修** | 当前页面展示什么、用哪个模板版本、何时对外发布 | 是。换图、改字、选作品、调整已开放属性、预检和发布 | `PageDocument` |
| **模板设计** | 区块结构如何组织、怎样呈现、允许页面改什么 | 否。只在需要新构图或改母版时进入 | `TemplateDefinitionV2` 草稿与不可变版本 |

日常主路径是页面装修。运营在组件库选择已发布模板、填写本页内容并发布。成品图只需在合适的图片槽上传本页图片，并填写信息图替代文本（D.52）。

D.53 的首批通用预设是首页首屏、作品网格和左右图文。在适用页面的模板组件库优先显示，可直接预览并添加。它们与已发布母模板共用正式目录、精确版本与页面实例规则。预设只提供版式与槽位，文字、图片和链接由当前页面填写。

```text
已发布模板版本
  → 打开具体中文页面
  → 插入或沿用精确版本
  → 上传本页图片；文字和按钮按需填写
  → 按页面职责检查整页是否成篇
  → 保存草稿，有权限后发布页面
```

需要维护母模板时进入模板设计。打开或复制已有模板，经过四区精调、保存模板草稿、独立发布模板版本，再回到页面装修选用。D.54 退役模板设计中「从首发母版开始」「添加区域」「添加槽位」三个动作及其等效入口。两种模式共享外壳和 Renderer，但隔离会话、历史、未保存状态和发布结果。顶部必须让人能回答：我正在改当前页面，还是母模板。

### 1.1 五条日常流程

换图、改字和使用已发布模板都在页面装修完成。从零新建入口与七步向导按 D.53 退役。查看预览、插入页面和进入模板设计是三个独立动作。

下列每条都规定运营结果。点击、撤销和迟到请求的编辑器做法见[从属细则](template-design-framework.md) §4–§6；画幅、含字图片和兼容分级见[区块模板标准](section-template-standard.md) §4.3、§6、§11。本轮只定规则，不表示界面已经做到。

**流程 1 · 找到并选用模板**

| 项 | 规则 |
| --- | --- |
| 意图 | 先看懂这块适合放什么、桌面和手机大致怎么排，再决定插入或另做模板 |
| 入口 | 页面装修的模板组件库。卡片只显示辨认图、名称和一句状态 |
| 默认 | 可插入的只有已发布版本。未发布草稿可以看见，但标成不可插入，不能冒充正式模板 |
| 范围 | 「预览」不写页面。「插入」才新增页面实例并选中。「设计此模板」进入模板草稿，不改当前页面 |
| 反馈 | 页面装修点击模板卡片后，预览排在当前页面内容末尾，画布自动定位到预览，跟随编辑器的桌面或手机宽度，画布只显示模板本身，不另加说明条。图层面板把该模板标成当前图层，写明尚未加入页面，并提供与其他图层相同的隐藏和删除；删除只关闭预览。右侧显示当前预览的模板和版本。点击「添加到页面」或「添加并编辑」统一追加到页面末尾，选中并定位到新实例，同时打开实例属性。点选画布中已添加的模板也会打开对应实例属性。拖拽仍按明确落点插入。当前设备尚无页面内容时，编辑画布沿用锁定模板的双端构图与画幅，在画幅内保留可选择的待填提示，填写后显示实际内容，不把模板示例写入页面。关闭预览、切换页面、离开页面装修或未明确添加时，画布和图层都不保留。模板设计的放大预览仍说明画幅和内容来源，以及这是草稿还是正式版本。人工封面标成「封面」，只帮助认出卡片；封面不承担验证 |
| 保存 | 预览和翻看目录不产生页面修改。插入后页面草稿变为未保存，直到运营保存页面 |
| 失败 | 目录读取失败保留已打开的页面和未保存修改，并提供重试。没有可用模板时呈现目录空态 |

**流程 2 · 换图、改字，并处理图片里已经有的字**

照片加真实标题、图片已含标题但仍要正文和按钮、完整海报、作品图加说明、同一节里只有其中一张图含字，都在页面装修完成。完整海报可以只上传这一张图：标题、正文、按钮、副图和 Logo 不填就收起，不阻断发布（D.52）。不因为图片含字就自动隐藏已经填写的正文、Logo 或按钮，也不要求运营理解槽位关联。勾选标题会使这一节的标题都不显示，勾选前写明（D.49）。

| 项 | 规则 |
| --- | --- |
| 意图 | 换上本页的图；字可填可不填。只在画面上已经有同样的字时，收起点名的那一段 |
| 入口 | 选中这一节后，在页面属性里换图、改字。收起重复文字按中文名称勾选，可以只对桌面或只对手机设置，不是全站开关 |
| 默认 | 标题、正文、Logo 和按钮都按模板显示。普通正文保持真实文本。不自动收起正文、Logo 或按钮 |
| 范围 | 勾选某一段后，这一节里的这段文字都不显示，包括旁边不含这些字的图片。原文留在页面里。读屏仍读这一次，替代文本不重复 |
| 反馈 | 勾选前写明范围，例如「这一节的标题都会不显示」。画布立刻收起它，不留空高、空距或底色。正文和按钮仍按模板显示 |
| 保存 | 这是当前页面实例的显示方式，不改母模板。「恢复继承」只去掉本端这项。取消勾选后原文照原样出现。这不是「清空内容」 |
| 失败 | 图片里画出来的按钮不是链接。只有整张图只有一个去处、且本节没有单独的真实按钮时，才允许整图前往该目标，并保留链接名称 |

**流程 3 · 切换桌面和手机**

| 项 | 规则 |
| --- | --- |
| 意图 | 检查同一节在两端的图和字，而不丢失正在改的内容 |
| 入口 | 顶部设备切换。它只改查看和当前写入端 |
| 默认 | 普通图片沿用桌面原图。需要时再设手机专用图和焦点，不强迫每张图上传两份 |
| 范围 | 属性写明这次改动只影响本端，还是会改到桌面基础、并影响到还没有单独设置的手机项。已有手机独立值不被桌面后续修改盖掉 |
| 反馈 | 横版含字图放进竖框、文字可能被裁掉时，提示换图或调整适配，不静默裁字。图片铺满哪个框、比例约束哪一个对象、文字是否单独占高，都在当前对象上写明 |
| 保存 | 切换设备本身不保存。「恢复继承」只去掉这一项的本端覆盖；「清空内容」是本页不要这段内容。两个入口和结果都分开 |
| 失败 | 切到手机再切回，模板、选中对象、输入和未保存修改都还在。对象在本端隐藏时说明原因，并让人定位到它或它的上级，不跳回默认选中 |

**流程 4 · 试用布局与预设**

左右互换、分栏比例、图片框比例、上下排列，以及该角色允许的网格，是模板设计里的预设和精调。页面运营只使用规格卡列出的设置（现有的是图片位置等，每角色不超过 4 项）、换图改字、焦点和流程 2 的收起重复文字。不把列宽、根比例和字号直接交给页面运营，也不为了面板简单而删掉模板设计里已经能完成工作的精调。

| 项 | 规则 |
| --- | --- |
| 意图 | 用预设得到可靠起点，再做适用的精调 |
| 入口 | 模板设计里选中区域或图片后的布局预设；页面装修里只有规格卡上的那几项 |
| 默认 | 预设写入当前模板草稿的设计值。打开和保存不重新跑创建配方 |
| 范围 | 兼容切换保留图文、链接、双端图源、焦点、显隐和仍然适用的覆盖。增减槽位、改变内容含义或类型、增加必填，单独说明，不包装成普通布局切换 |
| 反馈 | 不兼容变化先列出具体影响。取消后定义与未保存状态与打开确认前完全一致。兼容切换可以一步撤销 |
| 保存 | 只有「保存草稿」才写入母模板草稿。页面上的图片位置等设置写入当前页面实例 |
| 失败 | 确认前关闭或取消不留下半次布局。配方不会在后台重跑并盖掉精修 |

**流程 5 · 保存、重开、发布和返回**

四件事物分开：模板草稿、已发布模板版本、页面草稿、已公开页面。保存按钮写明写的是当前页面还是母模板草稿。

| 项 | 规则 |
| --- | --- |
| 意图 | 知道这次保存会影响谁，失败后还能回到刚才的输入 |
| 入口 | 页面装修的「保存草稿 / 发布页面」；模板设计的「保存草稿 / 发布模板」。发布成功后的「去页面装修使用」不自动插入 |
| 默认 | 沿用 D.43 与 D.49：能保留内容的页面草稿、语言草稿和装修方案改到新版本，页面上已填的内容保留。同一份里有一处保不住时，整份保持旧版本。无法保留的那些保持旧版本并逐项说明，其余仍沿用。已经公开的页面要等「发布页面」才更新。发布成功说明这三句，并写明没能沿用的对象；只有沿用失败的页面草稿才出现升级确认 |
| 范围 | 返回页面装修时，目录里的版本、该页已保存草稿和当前会话接在一起。有未保存输入时，不用整页刷新盖掉，也不静默写入刚被沿用的草稿。说明已保存草稿已沿用新版本、当前输入仍基于旧版本，并提供：把能保留的输入接到新版本、先留下这次输入、或放弃输入并打开已沿用草稿。接不上的字段不套用 |
| 反馈 | 目录刷新成功只说明目录更新了，不表示页面草稿或公开页已经同步 |
| 保存 | 保存失败留下输入和原因。并发冲突给出可选择的恢复，不能让后写入的人静默盖掉先写入的人 |
| 失败 | 慢请求或旧请求返回时，不覆盖用户后来选中的模板、设备或内容，也不把尚未核对的新输入标成已保存 |

## 2. 先落实页面目的，再谈模板类型

公开页不是通用海报墙。插入、推荐和发布都要先满足 GUARDRAILS 第 2 节的页面目的，再谈模板好不好看。下表只把那些目的翻译成装修约束，不改写品牌方向。

| 页面 | 装修时要完成的事 | 适合的区块 | 不得作为公开主内容 |
| --- | --- | --- | --- |
| `/` 首页 | 用已审核作品、系列、工艺或真实服务建立第一印象 | Hero、系列章节、工艺叙事、顾问服务入口 | 搜索筛选、购物车、价格轰炸、促销会场、巨大 Logo 当唯一主角 |
| `/products` 作品展陈 | 用海报与系列章节呈现可核验作品，而不是目录工具 | 系列章节、Lookbook、工艺说明 | 搜索筛选排序、未准备好的空墙、把装饰图伪装成可点商品 |
| `/catalog` 选款中心 | 查找比较；固定业务区承担筛选结果 | 固定业务区；克制导语或主视觉可选 | 用装修模块复制一套搜索结果 |
| `/custom` 定制 | 说明真实可提供的定制服务与下一步 | 服务叙事、工艺说明、克制作品入口 | 促销会场、结算、堆叠价格库存 |
| `/about` 关于 | 讲可核验的工艺与品牌事实 | 工艺/品牌说明、人物或工作室叙事 | 促销会场、资讯站、自我夸饰而无作品支点 |
| `/contact` 联系 | 通过微信或电话直接联系商家；从作品进来时保留来源作品上下文 | 克制导语。微信加好友码、微信号、电话和预约表单是固定业务区（D.45） | 默认展示长表单、促销会场、结算、把联系页做成会场倒计时 |

每个可装修页先回答四件事，再决定放哪些区块。答案只翻译 GUARDRAILS 第 2 节和上表，不另写页面目的，也不把六个页面套进同一组章节。

| 页面 | 访客主要任务 | 核心信息及真实依据 | 主要下一步 | 固定业务区与装修内容 |
| --- | --- | --- | --- | --- |
| `/` | 建立第一印象，并决定是否继续看作品或服务 | 已审核的具体作品、系列、工艺或真实服务 | 进入统一作品详情、系列，或预约、咨询中的一个 | 无目录、购物车或结算。装修承担叙事 |
| `/products` | 按编辑顺序理解作品 | 至少一组已审核作品或系列；没有则隐藏或改成有下一步的短页 | 进入统一作品详情 | 无搜索和筛选。装修是页面主体。装饰图不得假装是可点作品 |
| `/catalog` | 查找并比较款式 | 达到公开完整度的作品事实 | 进入统一详情继续决策 | 搜索、筛选、排序和结果是固定业务区。可单独发布，也可配一节克制导语 |
| `/custom` | 理解真实可提供的定制，并开始咨询 | 可核验的定制范围与工艺 | 预约或咨询 | 不嵌结算。装修讲服务，行动指向真实入口 |
| `/about` | 核对品牌与工艺事实 | 可核验的工艺、工坊或人物事实 | 查看作品，或前往联系 | 无促销。装修承担叙事 |
| `/contact` | 加微信、打电话，或留下预约 | 已保存的微信二维码、微信号、电话，以及现有预约表单（D.45） | 完成这三种联系中的一种 | 二维码、微信号、电话和预约表单是固定业务区。装修只作引导，不另做一套表单 |

区块从这四件事里长出来：前一节已经说明的，下一节只增加新的事实或画面。没有真实素材时缩短页面，不编造章节。[launch-template-set.md](launch-template-set.md) 第 4 节的配方只是编辑示例，不是准入，也不恢复 D.14 已退役的推荐序列、完成度评分、缺章节提示或自动补齐。

页面合同的 `pageRole`、固定业务区和 `root-only` 继续有效。`content-templates.contract.json` 里的 `allowedTemplateKeys: ["hero"]` 只登记当前活动的首屏**测试样例**，不定义未来母模板目录。页面可插入项以 Repository 中当前身份可用的已发布版本为准。页头叠加看首个可见主舞台与页面角色，不能把测试 key `hero` 当成唯一合法模板。

模板创建里的“类型”只是生成推荐，不构成页面准入，也不得覆盖上表。创建向导的“类型”一栏按**区块角色（sectionRole）**组织，不再按旧的“品牌故事/新品发布/新闻资讯/商品促销”母版名目分栏；运营界面按页面职责过滤推荐：

| 区块角色（sectionRole） | 在海川里的用途 | 可作为创建推荐的页面 | 不得推荐的页面 |
| --- | --- | --- | --- |
| `page-hero` 页面首屏 | 本页第一个可见主视觉，承担页面级标题与首图优先 | 首页、作品展陈、选款中心、关于、定制、联系 | 选款中心只用克制导语；无图导语优先用 `page-intro`（合同落地前仍用克制导语）。影像轮播变体只用于首页、作品展陈（D.42，落地前不能创建） |
| `collection-story` 系列叙事 | 当期系列或专题的叙事章节 | 首页、作品展陈 | 联系页不作为主视觉工厂 |
| `editorial-split` 左右图文 | 工艺、人物、品牌的分栏说明 | 首页、作品展陈、关于、定制、联系 | — |
| `craft-detail` 工艺细节 | 可核验的工艺步骤与细节 | 首页、作品展陈、关于 | 联系 |
| `editorial-media` 编辑媒体 | 已并入 `page-hero` 的非首屏影像变体（D.41） | 不再单独创建 | 合同枚举保留该值，只作历史读取 |
| `creation-grid` 作品网格 | 已审核作品的陈列卡片；可以用横向滑动变体（D.42，落地前不能创建） | 首页、作品展陈 | 不得伪装成商品网格或目录工具 |
| `maison-fact` 品牌事实 | 可核验的品牌/工坊事实与数据 | 关于、首页 | 促销会场 |
| `service-invitation` 服务邀请 | 顾问、定制、预约的真实下一步 | 联系、定制、首页 | 不得做成促销倒计时 |
| `video-story` 视频叙事 | 工艺或品牌视频叙事 | 首页、作品展陈、关于 | 视频槽位落地前不得发布模板 |
| `page-intro` 无图导语 | 标题加一两句导语，无图（D.41） | 六个页面，尤其是选款中心 | 合同落地前不能创建 |

本表是唯一的页面准入名单。槽位、字数、画幅、空态和验收只认[区块模板标准](section-template-standard.md)第 3 节，轮播与横向滑动只认它的第 4.7 节；标准规格卡里抄录的准入与本表不一致时，以本表为准。旧母版 key（`brand`、`newProduct`、`general`、`event`、`profile`、`news`、`productPromotion` 等）只作历史配方兼容读取。

### 模板治理：三层模型

一块模板是页面中的一节，按三层治理；模板设计只改变第三层的受控变化，不得越过前两层的职责与禁区。

| 层 | 是什么 | 由谁规定 |
| --- | --- | --- |
| 第一层 · 全站不变量 | 色值落 UI_GUIDE §4.1 共享底盘、标题字重 300–500、单页一套影像语言、桌面/手机两套内容端点 | UI_GUIDE、PROJECT_GUARDRAILS |
| 第二层 · 区块角色不变量 | 各角色的用途、槽位与禁区 | [区块模板标准](section-template-standard.md)第 3 节；页面准入仍是本表 |
| 第三层 · 受控变化 | 留白密度、影像权重、画幅、对齐、配色方案、图片形状。只引用 UI_GUIDE 令牌，不再使用风格名和圆角像素预设 | [区块模板标准](section-template-standard.md)第 2.3 节 |

首次上线只需要 6–8 个已发布区块模板覆盖最常用角色即可开始页面装修，不是 23 个旧固定模板，也不要求运营先走七步才能换图或发页。

价格、原价、折扣和优惠只决定如何呈现，数值来自绑定商品的业务事实源。没有绑定就不公开，并在发布检查中说明。品牌叙事页即使模板带了这些槽位也不公开。此条不改变交易或金价规则，细节见 D.38。

### 模块目录与店内分类

组件库先按本节的页面准入筛出可用模板，再按模块用途组织目录。目录分类和关键词搜索只影响查找。模板卡片、图层和属性面板沿用统一的模块显示名，显示名与目录分组不参与已发布版本的身份识别。卡片用名称、预览和状态帮助运营判断用途，具体可填项在选中区块后呈现。分组名称需要有可核实的运营含义，区块角色和页面准入仍按本节维护。旺铺的模块库和右侧配置表单可作流程参考。 [旺铺模块库](https://developer.alibaba.com/docs/doc.htm?articleId=120126&docType=1&treeId=776) · [旺铺配置应用](https://developer.alibaba.com/docs/doc.htm?articleId=120118&docType=1&treeId=785)

跨页复制使用目标页的同一份已发布目录，并按来源实例锁定版本的区块角色核对目标页。普通历史模板没有记录区块角色时，沿用原目录兼容规则。已有页面实例继续按其锁定版本读取。

| 对象 | 来源 | 页面装修中的用法 |
| --- | --- | --- |
| 模块目录分类 | 模板目录及区块角色 | 查找图片区块、作品区块和其他适合当前页面的模板。移动目录分组只影响后台查找。 |
| 店内商品分类 | 海川商品管理中的分类树 | 从既有分类选择器选择有效目标，以稳定标识链接到选款中心的相应分类。分类名称、层级和公开状态随业务来源读取。 |
| 本页展示顺序 | 当前页面实例 | 运营可以在允许的卡位内调整已选作品的呈现顺序。该顺序只属于当前区块。 |

淘宝公开接口分别定义卖家自建的展示分类和后台发布商品的标准类目。海川按同样的职责区分来理解店内导购与商品管理，海川业务系统是本店分类的来源。装修表单可引用既有作品或分类，选择动作不创建分类、不改变商品归属。分类失效时，发布检查指出具体区块和字段，运营可重新选择或清除跳转。 [淘宝官方能力清单](https://developer.alibaba.com/docs/doc.htm?articleId=121837&docType=1&treeId=837) · [标准商品类目接口](https://developer.alibaba.com/docs/api.htm?apiId=122)

模块属性从锁定版本允许编辑的槽位派生。单图海报优先放本页图片、取景与跳转，文字按该模板开放范围提供；左右图文优先放标题、正文和配图；作品区块优先放作品选择、图片和卡片顺序。通用的图片、作品、分类和页面选择复用工作台现有控件。分类入口负责把访客带到选款中心，分类筛选和结果由选款中心的固定业务区承担。

作品区块可从空卡位批量选择可公开展示的作品。按选中顺序填入尚未关联作品的可编辑卡位，空图带入作品主图，手动配置的配图保留。运营可以逐卡替换图片，排序时图片、取景和作品链接随卡片一起移动。

规则验收覆盖搜索和分组下的页面准入、按模块显示适用字段、分类改名与停用后的链接反馈，以及保存重开、双端预览与公开渲染的结果。独立分类导航、热区、营销或第三方互动模块的准入按本节页面职责评审；影像轮播与横向滑动沿用 D.42 的目标态和区块模板标准 §4.7。

## 3. 四层内容，不得混用

> 本节四层（系统示例、模板默认图文、页面真实内容、业务事实）说的是**内容来源与归属**；上一节的三层模型说的是**模板治理**。两者不在同一维度，不得混用。

| 层 | 是什么 | 可进模板定义 | 可进页面草稿 | 可进公开页 |
| --- | --- | --- | --- | --- |
| 系统示例 / 压力试排 | 中性短文、长文、缺图，只为检查布局 | 否 | 否 | 否 |
| 模板默认图文 | 设计稿用的合法固定文案和默认图 | 是，随 Schema 3 定义保存 | 不在插入时复制进页面实例 | 否。默认图和默认文案都只用于后台预览判断层级；公开必填只由页面自己的值满足（D.40 收窄 D.38 的对应子范围） |
| 页面真实内容 | 本页明确填写的文字、上传图片、显式清空 | 否 | 是 | 是，且优先于默认文案 |
| 业务事实 | 价格、库存、作品资格、联系资料 | 否 | 只保存稳定引用 | 由对应业务源实时解析 |

插入已发布模板时：

- 锁定 `templateId + templateVersion`，不复制系统示例，不把默认图写成页面图片。
- 页面字段从“尚未由本页填写”开始。后台预览可以按锁定版本显示默认文案，便于判断层级；这不是页面已保存的真实内容。
- 页面显式值优先；显式清空保持清空并按 D.38 隐藏或收起，不回填默认值。
- 公开必填只由页面自己的值满足。锁定默认文案即使在后台预览中显示，也不能在页面未填时充当公开内容（D.40）。必须由页面填写的字段缺页面自己的值就阻断，并给出可理解的下一步。

恢复分成三个可撤销动作，定义见 D.38：恢复模板文案、恢复模板样式、清空并隐藏。页面级“恢复模板值”不得升级版本，也不得清空无关真实内容。

## 4. 整页必须成篇，不只要单模块合法

UI_GUIDE 要求每次公开有一个叙事命题、一个主要视觉焦点、一套影像语言和一个主要行动。D.31 允许同一页有多个 `primary-stage`，数量不是结构门禁；这不取消整页艺术要求。

发布品牌页（首页、作品展陈、关于、定制、联系）时，除结构/权限/D.38 内容承诺外，发布检查还须让运营确认：

1. 本页当前命题是什么（已审核的作品、系列、工艺或服务，不是空泛口号）；
2. 哪一个区块是主焦点；多个主舞台时，只有首个可见主舞台承担页面级标题和首图优先；
3. 各区块的影像、字体和装饰没有互相打架；
4. 本页有一个主要行动目标，并指向真实可提供的服务或作品详情。同一目标可以在合适的首尾重复；指向具体作品的链接不算第二个目标；多个不同目标仍须确认（D.41、D.44、D.50）；
5. 未准备好的区块已隐藏或换成体面短页，没有大面积无解释空洞。

判断整页还看六件事：信息是否往前推进，视觉焦点是否分得出主次，影像权重和内容密度是否协调，留白是否帮人看清分组，背景和图片语言是否一致，主要行动是否连续。不以左右交替、浅深交替或固定节数代替这些判断。不要让每一节都同时用上最强的大图、深色背景、满屏高度和主按钮。节数和深色节数量仍是建议，理由与例外在区块模板标准 §10.1、§10.2。

机器无法可靠判断的命题、节奏和影像一致性标为“待人工核对”，不能自动变绿，也不能用纸面推演代替实图。单模板生成成功、对比度初检通过或有图，都不能代替本页成篇。

选款中心以固定业务区为任务主体；装修区块只做克制导语或主视觉，不得用模块堆出第二套目录。

### 一块模板是一节

页面由按顺序排列的模板实例组成。每一块只承担一个叙事节，不是按屏幕高度切出的海报片段。根画幅是这一节的高度规则，不是整页高度。顺序要能说明前一节已经讲了什么、这一节增加什么、下一节怎样承接。没有新增价值的重复应当精简。模板设计预览孤立的一节；页面装修预览排好序的多节，用同一 Renderer。

一节里应该有：

- 一个现行区块角色（第 2 节。`editorial-media` 已并入 `page-hero`，`page-intro` 在合同落地前不能创建），并因此走一种双端过渡：全幅主视觉、左右图文，或商品卡组。比例、栏数和首屏高度只认区块模板标准第 6 节。三处预览框的内容来源只认[模板设计标准第 3.1 节](template-creation-rules.md#31-双端呈现与预览图)。本节不另立一套“构图角色”。上图下文在手机上并入左右图文的过渡，不单立一种竖卡。
- 这一节新增的事实或画面，以及它实际需要的文字。标题、正文和按钮不是每节的必填套装。缺的可选内容收起，相关空白一起消失。
- 这一节自己的图片外框。纯文字能够成立的规格卡可以没有图。

主行动：

- 整页围绕一个主要行动目标。主按钮只出现在规格卡允许放按钮的角色上。
- 同一目标可以在合适的首尾各出现一次，文字和目标相同，并且不在同一屏里同时充当两个焦点（D.44）。
- 指向具体作品或系列的链接是内容链接，不是第二个主行动。
- 多个不同的主行动仍然触发两个及以上按钮的发布确认（D.41）。确认不放宽。

一节里不能出现：

- 站点页眉、页脚、主导航、搜索、购物车、结算、Cookie 同意和语言切换。这些属于页面外壳。
- 第二套页面级标题。只有首个可见主舞台使用页面级标题和首图优先；后面的节使用内容级标题。模板不记录“我是第几节”。
- 下一节才该承担的内容。一个模板不负责整页目录、筛选结果或联系渠道。选款结果区和联系页的微信、电话、预约表单仍是本页的固定业务区；原咨询表单只走 D.45 指定的兼容入口。
- 品牌叙事页上的价格、库存、加购、倒计时和促销会场。选款中心可以呈现已绑定的商品事实，数值仍来自业务事实源。
- 系统示例和模板默认图不能充当这一节的公开内容。任何语言的关键标题、说明和行动入口都按 [UI_GUIDE 第 5.2 节](../UI_GUIDE.md#52-图片硬规则) 落实为真实网页文字和可操作控件。没有来源的价格、库存、证书、年份或工艺数字同样不能公开。

节与节的最终距离只有一套算法，见区块模板标准 §10.2。页面不在两节之间再加一段间距，也不把两节的内边距无条件相加。桌面默认 5xl，手机 3xl，都是 UI_GUIDE §3.2 已有令牌。品牌叙事页若改用 UI_GUIDE 允许的 128px，整页只用这一档。相邻同角色或同构图先按区块模板标准 §10.4 检查内容是否重复、画面是否疲劳；名称相同本身不构成不合格（D.50）。影像、字体和装饰整页保持一套。

页面装修要让运营看见本页四件事、这一节新增了什么，以及各枚主按钮是不是同一目标。两个及以上按钮仍要确认。这些是提醒和确认，不显示缺章节、完成度或审美分数，也不自动补齐。

全幅竖向媒体框只给本页第一个可见的全幅主视觉，并且只在小于 `768px` 时使用。这只描述 `hero-media-frame` 的媒体框；未写 `geometryPolicy` 或值为 `paired-canvas` 的旧定义仍按 D.46 对换整节，不在这里改成 9:16 图片框。几何细节只认区块模板标准第 6 节。`768px` 及以上回到这一节的桌面宽幅，只做几何适配。竞品在 `1024px` 甚至 `1100px` 仍用竖幅，只说明要沿宽度阶梯检查主体有没有被裁切；那些像素不成为海川的第二内容断点。后面的全幅章节在手机上也不各占一个竖向视口。同一模板用在第一屏或用在后面，不另存第三套图。模板定义不记录“我是第几节”。

页面预览与模板设计使用相同的预览框，内容来源只认[模板设计标准第 3.1 节](template-creation-rules.md#31-双端呈现与预览图)。比例、栏数和首屏高度只认区块模板标准第 6 节。页面只把内容来源换成锁定版本上的本页字段，不另定根画幅，也不另做一套缩略图。不新增平板内容端点（D.36）。阅读顺序、文字与图片的关系、主行动是否可点，按第 3.1 节验收；这一节是否占用整屏竖幅，按本节的位置规则验收。

## 5. 色彩、语言与测试样例

- 模板风格可以改变留白密度、影像权重、对齐和配色方案。图片默认直角，圆形只用于人物头像和 Logo。**色值必须落在 UI_GUIDE §4.1 共享底盘**。不得因“活力”“科技”“品牌色”另建平行色盘或发明第二品牌色，也不再使用已取消的风格名和像素圆角档。深色只允许作为局部 Hero 承托或少量编辑章节，并使用底盘中的深色画布与反色文字。
- 公开网站只有简体中文（D.35）。页面装修上下文显示页面名称、草稿状态和设备，不再把语言切换当一等操作。历史 locale 字段只留兼容与审计；发布指针是当前中文页面的发布指针。
- `hero` 只出现在页面装修的显式测试入口，用于合同与 Renderer 回归。它不是新母模板默认内容，也不进入模板设计目录。

## 6. 保存、发布与空态

模板保存、模板发布和页面发布仍是独立动作。只有页面装修里的“发布页面”推进客户前台读取的 `publishedRevisionId`。整站上线准备不冻结日常页面发布。

页面发布不要求至少有一个可见装修模块。选款中心和联系页可以只发布固定业务区；有装修内容时，按页面根内容的顺序展示，业务区不必紧跟首个品牌模块（D.55）。固定业务区的数量、页面归属、根内容位置和锁定规则继续有效。

公开空态必须体面、可理解、有下一步：未准备好就隐藏入口或发布短页，不得用内部默认模板、系统示例或无说明的大空白冒充内容。D.38 的区块显隐（纯文字可展示、可选图收起、成立前提缺图则隐藏该区块）是模块级规则；整页被抽空后仍要满足本节的体面空态，不能只留下固定业务区却假装品牌页已经完整。

## 7. 页面装修最低验收

模板生成验收继续走模板设计标准第 11 节。下面只验收**页面装修这条日常轨道**，不能用七步通过代替。

| ID | 验收项 | 必须证明的结果 |
| --- | --- | --- |
| PB-UNI-001 | 打开页面 | 区分已保存草稿、线上版本、无草稿、读取失败、冲突与无权限；失败不用 seed 或线上副本顶上 |
| PB-TPL-001 | 选用模板 | 目录只插入已发布版本；测试样例 `hero` 不混入普通目录；预览不写页面；添加位置明确 |
| PB-RESP-001 | 双端与预览 | 页面预览使用锁定版本和本页内容；画幅与预览框服从模板设计标准第 3.1 节；页面不另定根画幅 |
| PB-MEDIA-001 | 填写内容 | 图文、作品引用和行动可填；系统示例未泄漏；默认图未当成页面图；价格未绑定时不公开 |
| PB-UNI-002 | 页面职责 | 品牌页未插入被本节禁止的促销主内容；选款中心未用模块复制业务区 |
| PB-VISUAL-001 | 整页成篇 | 发布检查能看到命题、主焦点、主要行动目标和待核对项。同一目标在首尾用同一文字、同一目标重复时，仍确认两个及以上按钮，但不把它当成第二个目标。不同的主行动必须确认。多主舞台时首个可见者承担页面级标题。后面的全幅章节不各占一个手机视口。节内没有页眉、页脚、导航、搜索、购物车或结算。相邻同角色或同构图先核对内容是否重复、画面是否疲劳；名称相同本身不判不合格。影像语言是否成套由人工核对，纸面推演不算视觉通过 |
| PB-PAGE-001 | 恢复 | 文案 / 样式 / 清空隐藏三种结果可区分、可撤销，不升级版本 |
| PB-PAGE-002 | 发布 | 草稿保存与页面发布分开；D.38 承诺生效；失败保留输入；公开结果与已发布 revision 一致 |
| PB-PAGE-003 | 中文单语 | 界面和发布不提供语言切换；不请求英文公开事实 |
| PB-PAGE-004 | 公开空态 | 未准备好就隐藏入口或发布短页；不用内部默认模板、系统示例或无说明的大空白冒充内容；整页被抽空后不只留下固定业务区却假装品牌页已经完整 |
| PB-FLOW-001 | 选用与换字 | 预览不写页面；只插入已发布版本；换图改字不进入创建向导；图片含字时只收起点名的重复文字，原文还在，旁边的正文和按钮仍在 |
| PB-FLOW-002 | 双端连续 | 切设备保留模板、选中、输入和未保存修改；恢复继承与清空内容结果不同；桌面修改不盖掉已有手机独立值 |
| PB-FLOW-003 | 保存身份 | 页面保存与模板保存分得开；模板发布不改写已公开页面；保存失败、冲突和迟到回包都不丢后来的选择 |
