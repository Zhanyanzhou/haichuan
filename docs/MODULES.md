### 已批准报价模块边界（目标，尚未实现）

> 以下仅把 `docs/DECISIONS.md` D.19 派生为模块职责导航；D.19 是产品业务决定源，字段和必要数值见 `docs/PRODUCT_DATA_CONTRACT.md`。这些不是当前路由、数据库表或已完成能力。精确模块归属、DTO、状态机和持久化结构需在实施阶段设计；本节不授权 migration、真实数据写入或资金开放。

- **标准零售固定价**：沿用产品/SKU、Inventory、购物车和订单边界；成交价继续读取 `ProductSKU.price`，`Product.price` 只作派生最低价。
- **高级定制报价**：承接“客户提交需求 → 后台形成/修订报价 → 已认证客户本人确认 → 事务转单”的版本化流程；后台不得代替客户确认。
- **合作商蜡模报价**：承接 3D 文件版本、红/紫蜡、确认蜡重、目标金重、有效克价解析和客户本人确认；确认蜡重为结算重量，十倍金重只作内部预计参考。
- **客户价格策略**：仅允许 `SUPER_ADMIN` / `ADMIN` 管理客户专属紫蜡与红蜡双克价、生效/失效、原因和审计；有效专属价优先，否则读取 D.19 确定的系统默认价。
- **附加费用配置**：目标支持固定、按克、按单三种方式以及适用客群、启停和说明；具体项目与金额以后配置。
- **资源门禁**：标准零售由 SKU/Inventory 裁决；高级定制由报价、产能、材料和工艺裁决；合作蜡模由报价、文件版本、蜡模产能和材料裁决。
- **事务转单与审计**：客户本人确认后，在同一服务端事务内复核身份、报价版本、资格、资源和金额，幂等生成订单与完整不可变快照；失败不得留下部分或重复订单，后续配置变化不得改写历史。
- `SalesMode` 只定义作品公开主行动，不承担客户身份、合作资格、专属价或排他报价通道；同一设计可以同时走零售、定制和合作报价。
- 报价和购买能力不绑定 `/catalog`。入口可以来自作品详情、定制服务、合作商流程、顾问跟进或其他获批页面，服务端规则是最终边界。
- **当前缺口**：客户本人确认、分通道资源门禁、事务转单和完整快照尚未统一实现，员工确认与报价转单当前安全暂停。新网关交易入口已消费安全默认关闭的服务端总门禁，但未做真实通道或资金闭环验收；模块、路由或代码级测试存在不等于交易已经开放。

## 已知问题

- 本地 Prisma 引擎 DLL 被开发服务占用时，`prisma generate` 可能失败；停止占用服务后重新生成即可
- 页面构建器前后端区块类型由 `npm run test:contracts` 校验，变更任一侧时必须同步更新另一侧
- `InventoryPolicy` migration 已生成但目标数据库与执行状态未确认；确认前不得据 schema 或生成文件推断运行数据库已经具备该字段
- 当前宿主机后端可能仍运行早于工作树构建的旧 `dist`；先核对运行版本和数据库兼容，再做真实接口验收
